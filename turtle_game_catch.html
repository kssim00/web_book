5단계로 직접 완성하기

먼저 스스로 짜 보고, 막히면 미션마다 있는 메서드 힌트 단추를 눌러요.

MISSION 01

게임 무대 만들기

목표: 창을 띄우고, 제목·배경색을 정하고, 잡을 메인 거북이의 모양·색을 준비합니다.

생각해 보기
  • 거북이 라이브러리와 무작위 라이브러리를 맨 위에서 불러와요.
  • 창을 만들고, 제목·배경색을 정해요. (영상의 배경색을 잘 보세요.)
  • 움직일 때 선이 안 그려지게 펜을 들고, 거북이 모양·색·속도를 정해요.
💡 메서드 힌트 보기
  • 창 크기→setup(가로, 세로)
  • 창 제목→title("제목")
  • 배경색→bgcolor("색")
  • 펜 들기→penup()
  • 모양 / 색→shape("모양") · color("색")
  • 빠른 속도→speed(0)

팁 · 가로·세로에 같은 값을 넣으면 정사각형 창이 돼요.

MISSION 02

점수 변수 + 점수 쓰는 거북이

목표: 점수를 저장할 변수를 만들고, 화면 위쪽에 점수 글씨를 써 주는 전용 거북이를 따로 만듭니다.

왜 거북이를 또 만들까?

잡으러 다니는 거북이는 계속 움직여요. 점수 글씨가 거기 붙어 있으면 같이 움직여 버리죠. 그래서 글씨만 담당하는 거북이를 한 마리 더 만들어 위쪽에 가만히 둬요. 역할 나누기가 핵심!

생각해 보기
  • 점수 변수를 0으로 하나 만들어 둬요.
  • 글씨 전용 거북이를 새로 만들어 펜 들고, 색 정하고, 위쪽으로 이동시킨 뒤 모양은 숨겨요.
  • 화면에 글씨를 써요. 글꼴은 '나눔고딕', 크기는 20. 변하는 점수는 f-문자열로!
💡 메서드 힌트 보기
  • 새 거북이→t.Turtle()
  • 위치 이동→goto(0, y)
  • 모양 숨기기→hideturtle()
  • 변하는 값→f"score: {score}"
  • 글씨 쓰기→write(내용, False, "center", ("나눔고딕", 20))

write의 4칸 · 쓸 내용 / 이동 여부 / 정렬 / (글꼴, 크기)

MISSION 03

랜덤 모양으로 랜덤 위치 이동

목표: 5가지 모양을 리스트에 담고, 그중 하나를 무작위로 골라 무작위 좌표로 이동시키는 함수 turtle_move 를 만듭니다.

생각해 보기
  • 모양 5개를 리스트에 담아요. (영상에 나오는 모양 이름들!)
  • 리스트에서 모양 하나를 무작위로, x·y 좌표도 무작위로 정해 그 자리로 이동해요.
  • 이 모든 건 turtle_move 함수 안에 묶어요.
💡 메서드 힌트 보기
  • 함수 만들기→def turtle_move():
  • 목록서 뽑기→random.choice(리스트)
  • 무작위 정수→random.randint(최소, 최대)
  • 이동→goto(x, y)

팁 · 화면이 500이면 좌표 범위는 대략 -230~230. 모양엔 choice, 좌표엔 randint!

MISSION 04

커졌다 작아지기 + 1초마다 반복

목표: 모양이 부풀었다 사라지는 효과를 주고, turtle_move 가 1초마다 스스로 다시 실행되게 만듭니다. (미션 3 함수에 이어서!)

생각해 보기
  • 크기를 반복문으로 조금씩 키웠다가, 다시 조금씩 줄여요. (거꾸로 반복은 증감 값을 떠올려요.)
  • 나타낼 땐 보이게, 다 줄면 숨겨요.
  • 핵심: 함수 맨 끝에서 자기 자신을 1초 뒤에 다시 예약해요(타이머).
💡 메서드 힌트 보기
  • 크기 바꾸기→shapesize(값)
  • 반복→for i in range(시작, 끝, 증감)
  • 보이기 / 숨기기→showturtle() · hideturtle()
  • 타이머 반복→ontimer(함수, 1000)

팁 · 1000은 1초(ms). 타이머에 넣는 함수는 이름만(괄호 X).

MISSION 05

클릭해서 잡기 + 게임 시작

목표: 화면을 클릭하면 점수가 1 오르게 만들고, 게임을 실제로 시작시킵니다.

생각해 보기
  • 클릭하면 부를 함수 catch 를 만들어요. (클릭 위치 x, y를 자동으로 받아요.)
  • 함수 안에서 바깥 점수를 바꾸려면 전역변수로 선언하고, 점수를 1 올린 뒤 이전 글씨를 지우고 다시 써요.
  • 마우스 클릭을 catch와 연결하고, 게임을 한 번 시작한 뒤 창을 유지해요.
💡 메서드 힌트 보기
  • 클릭 함수→def catch(x, y):
  • 전역변수→global score
  • 점수 올리기→score += 1
  • 글씨 지우기→clear()
  • 마우스 클릭→onclick(함수)
  • 창 유지→done()

아주 중요 · onclick(함수) 처럼 이름만! 괄호 붙이면 즉시 실행돼 버려요. / global 이 없으면 점수가 안 올라가요.

막혔을 때 점검표

에러가 났다고 실패가 아니에요 — 단서를 찾는 중!

점수 글씨가 안 보여요
점수 거북이의 이동 좌표가 화면 밖은 아닌지, 글씨 쓰기를 실제로 불렀는지 확인해요. 거북이를 숨겨도 글씨는 그대로 보입니다.
클릭해도 점수가 안 올라가요
클릭 연결에 함수 이름만(괄호 없이) 넣었는지, catch 안에 global 이 있는지, 연결하는 줄이 catch 함수를 만든 다음에 오는지 확인하세요.
거북이가 한 번만 나오고 멈춰요
함수 맨 끝에서 타이머로 자기 자신을 다시 예약했는지 보세요. 함수에 괄호를 붙이지 않았는지도 확인!
이동할 때 선이 그려져요
처음에 펜 들기를 했는지 확인하세요. 펜이 내려가 있으면 경로가 선으로 남아요.

완성 체크리스트

  • 01 파란 배경 창이 뜨고 제목이 보인다
  • 02 화면 위쪽에 "score: 0" 글씨가 (나눔고딕·크기 20으로) 잘 보인다
  • 03 모양과 위치가 매번 무작위로 바뀐다
  • 04 모양이 커졌다 작아지고, 1초마다 다시 나타난다
  • 05 클릭하면 점수가 1씩 올라간다
