코드로 만드는 화살 쏘기 게임!

움직이는 빨간 공을 마우스로 클릭해서 맞히는 게임을 파이썬으로 직접 만들어봐요.

1

오늘의 미션

오늘은 움직이는 빨간 공을 클릭해서 맞히는 화살 쏘기 게임을 만들어볼 거예요.

1
빨간 공이 화면에서 계속 왼쪽으로 움직여요.
2
화면 아무 곳이나 클릭하면 아래에서 화살이 그 방향으로 날아가요.
3
화살이 빨간 공에 맞으면 점수가 1점 올라가요.
4
공을 맞히면 공은 다시 오른쪽 위에서 나타나요.
미리 알아두기 — 이 게임에는 "움직이기", "방향 계산하기", "부딪혔는지 확인하기" 같은 새로운 기술이 필요해요. 하나씩 차근차근 배워봐요! 🎯
2

게임 창 만들기

게임 창을 만들고, 배경색을 예쁜 살구색으로 칠해요. 이번엔 색깔을 Hex(헥스) 코드라는 특별한 방법으로 지정해봐요.

import turtle as t t.setup(500, 500) t.bgcolor("#FFAB76") # 살구색을 코드로 표현! t.title("터틀 화살 쏘기 게임")
Hex 코드는 색깔을 #으로 시작하는 6자리 암호처럼 표현하는 방법이에요.
색깔 코드는 어디서 찾을까요? — 구글이나 네이버에 "컬러 피커" 또는 "색상 코드"라고 검색하면 원하는 색을 고르고 바로 코드(#으로 시작하는 글자)를 복사할 수 있어요!
3

점수판 만들기

게임을 시작하기 전에, 화면 왼쪽 위에 점수를 보여줄 자리를 만들어요. 점수를 저장할 변수도 함께 만들어요.

# 변수 초기화 score = 0 ready = True # 점수 표시하기 t.ht() # 화면 안내 화살표 숨기기 t.penup() t.goto(-220, 220) t.write(f"점수 : {score}")
새로운 표현: f-문자열 — f"점수 : {score}" 처럼 문자열 앞에 f를 붙이면, 중괄호 { } 안에 변수 값을 쏙 넣어서 보여줄 수 있어요. score가 3이면 "점수 : 3"이 돼요!
4

목표물(빨간 공) 만들기

이제 우리가 맞혀야 할 빨간 공을 만들고, 스스로 왼쪽으로 계속 움직이게 만들어봐요.

ball = t.Turtle() ball.penup() ball.speed(0) ball.shape("circle") ball.color("red") ball.goto(300, 200) ball.setheading(180) # 180도 = 왼쪽 방향 def ball_move(): if ball.xcor() > -270: ball.forward(10) else: ball.goto(300, 200) # 화면을 벗어나면 다시 오른쪽에서! t.ontimer(ball_move, 20) # 0.02초마다 이 함수를 다시 실행! ball_move()
t.ontimer로 함수가 계속 자기 자신을 부르면서 애니메이션처럼 움직여요.
ontimer가 신기해요! — ball_move() 함수의 마지막 줄이 t.ontimer(ball_move, 20)이에요. "20밀리초 뒤에 나(ball_move)를 다시 실행해줘!"라는 뜻이라서, 공이 끊임없이 움직이는 것처럼 보여요.
5

화살(플레이어) 만들기

이번엔 우리가 조종할 화살을 만들어요. 화면 아래쪽 가운데에서 위쪽을 바라보게 놓아요.

player = t.Turtle() player.shapesize(1, 2) # 몸통을 길쭉하게 늘려서 화살처럼! player.speed(0) player.penup() player.goto(0, -220) player.setheading(90) # 90도 = 위쪽 방향
알고 있었나요? — 파이썬 turtle의 기본 모양은 사실 화살표(▲)처럼 생겼어요! 그래서 shape를 따로 정하지 않아도 화살처럼 보이는 거예요. shapesize로 몸을 늘려주기만 하면 진짜 화살 같아져요.
6

화살 쏘기 — 방향 계산하기

화면을 클릭하면, 화살이 클릭한 방향을 스스로 계산해서 그쪽으로 날아가야 해요. 이때 towards()라는 아주 편리한 명령어를 사용해요.

def fire(x, y): global score, ready if ready: player.pendown() ang = player.towards(x, y) # 클릭한 곳까지의 각도 계산! player.setheading(ang) # 그 각도로 방향 바꾸기 while player.ycor() < 200: player.forward(30) # 화면 위쪽까지 조금씩 전진 t.onscreenclick(fire) # 화면을 클릭하면 fire() 실행!
클릭한 방향으로 화살이 쭉 날아가는 모습이에요.
towards가 하는 일 — player.towards(x, y)는 "지금 있는 곳에서 (x, y)까지 가려면 몇 도로 방향을 틀어야 하는지" 계산해줘요. 우리가 직접 각도를 계산하지 않아도 돼서 정말 편리해요!
7

명중 확인하기

화살이 날아가는 동안, 매 순간 공과 화살 사이의 거리를 확인해요. 거리가 아주 가까워지면 "명중!"이라고 판단해요.

while player.ycor() < 200: player.forward(30) if player.distance(ball) < 30: # 거리가 30보다 가까우면 명중! score += 1 t.clear() t.write(f"점수 : {score}") ball.goto(300, 200) # 공을 다시 오른쪽으로! break # 반복을 멈추고 화살 정리하기 player.clear() player.penup() player.setheading(90) player.goto(0, -220) ready = True
완성된 게임! 공을 맞힐 때마다 점수가 올라가요.
distance가 하는 일 — player.distance(ball)은 화살과 공 사이의 거리를 숫자로 알려줘요. 이 숫자가 30보다 작다는 건 둘이 거의 겹칠 만큼 가까워졌다는 뜻이에요 — 즉, 맞은 거예요!
