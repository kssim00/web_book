파이썬 클래스,
틀만 알면 끝!

클래스는 어떤 규칙적인 틀을 만드는 것이에요. 붕어빵 틀 하나로 붕어빵을 계속 찍어내듯, 클래스 하나로 같은 모양의 데이터를 계속 만들 수 있어요.

예) OO초등학교 1-1반 학생들의 특성(이름, 성별, 성적)을 틀로 짜서, 학생마다 그 틀에 데이터를 넣어요.
STEP 1 / 5

01클래스 뼈대 만들기

class 키워드로 시작해요.

class Student:
    pass
class 뒤에 클래스 이름을 적어요. 이름은 보통 대문자로 시작해요. 아직 안에 내용이 없어서 pass라고 적어둬요.
STEP 2 / 5

02__init__ 넣기

객체가 생길 때 자동으로 실행되는 함수예요.

class Student:
    def __init__(self, name):
        self.name = name
__init__은 객체가 만들어질 때 자동으로 실행돼요. self는 "이 객체 자신"을 뜻하고, self.name = name은 "이 객체의 name에 값을 저장해라"는 뜻이에요.
STEP 3 / 5

03특성 늘리기

매개변수를 늘리면 더 많은 정보를 담을 수 있어요.

class Student:
    def __init__(self, name, gender, score):
        self.name = name
        self.gender = gender
        self.score = score
특성을 더 받고 싶으면 매개변수와 self.속성 = 속성 줄을 그만큼 늘리면 돼요.
STEP 4 / 5

04메서드 추가하기

클래스 안에 있는 함수, 이걸 메서드라고 불러요.

class Student:
    def __init__(self, name, gender, score):
        self.name = name
        self.gender = gender
        self.score = score

    def show(self):
        print(self.name, "은(는)", self.gender, "학생이고, 총점은", self.score, "점입니다.")
메서드 안에서는 self.속성으로 이 객체의 값을 자유롭게 사용할 수 있어요.
STEP 5 / 5 · 완성

05객체 만들고 실행하기

클래스이름(값1, 값2, 값3)으로 객체를 만들고, 객체.메서드()로 실행해요.

# 위에서 만든 Student 클래스를 이용해요
s1 = Student("예은", "여", 790)
s1.show()
→ 예은은(는) 여 학생이고, 총점은 790점입니다.

06여러 개의 객체 만들기

같은 클래스로 여러 객체를 만들면, 각자 독립된 데이터를 가져요. 이름이 달라도 클래스(Friend) 하나면 충분해요.

class Friend:
    def __init__(self, name):
        self.name = name

    def say_hi(self):
        print(self.name, "이(가) 인사해요: 안녕!")

friends = [Friend("경록"), Friend("연경"), Friend("지우"), Friend("은지")]
for f in friends:
    f.say_hi()
한 친구의 이름을 바꿔도 다른 친구는 그대로예요. 객체마다 자기만의 값을 따로 갖기 때문이에요. 그래서 리스트 + 반복문으로 여러 객체를 한 번에 다룰 수 있어요.

09너의 차례!

지후(국어 78, 수학 85, 영어 80)의 성적표를 만들어 총점과 평균을 출력해보세요.

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def total(self):
        return sum(self.score.values())

    def ave(self):
        return self.total() / len(self.score)
