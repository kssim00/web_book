TURTLE PROJECT

크리스마스 눈송이,
내 손으로 애니메이션 만들기

turtle 모듈로 크리스마스트리를 그리고, 클래스로 눈송이를 여러 개 만들어서 끊임없이 내리는 눈 애니메이션을 완성해요.

미리보기

완성하면 이렇게 동작해요 — 눈이 계속 내려요.

실제 코드에서는 while True 반복문 안에서 눈송이 100개가 계속 아래로 움직여요.

STEP 1

01화면 준비하기

화면 크기, 배경색, 제목을 정하고, 그림을 그릴 펜(turtle)을 준비해요.

import turtle as t
import random

screen = t.Screen()
screen.setup(800, 600)
screen.bgcolor("midnight blue")
screen.title("Merry Christmas")
screen.tracer(0)          # 화면을 한 번에 그려서 애니메이션을 부드럽게

pen = t.Turtle()
pen.hideturtle()
pen.speed(0)
screen.tracer(0)은 그림을 실시간으로 그리지 않고 모아뒀다가 한 번에 보여줘요. 나중에 screen.update()를 불러야 실제로 화면에 나타나요.
미리보기

여기까지 실행하면 밤하늘색 배경만 보여요.

STEP 2

02트리 그리기

삼각형 3개를 아래에서 위로 겹쳐 그려서 트리 모양을 만들어요.

pen.color("green")

for y in [-150, -90, -30]:
    pen.up()
    pen.goto(-100, y)
    pen.down()

    pen.begin_fill()
    pen.goto(0, y + 80)
    pen.goto(100, y)
    pen.goto(-100, y)
    pen.end_fill()
리스트 [-150, -90, -30]의 y값마다 삼각형을 하나씩 그려요. begin_fill()과 end_fill() 사이에 그린 도형은 색이 채워져요.

여기까지 실행하면 이렇게 보여요.

STEP 3

03나무 줄기 그리기

forward와 right(90)을 반복하면 네모(직사각형)를 그릴 수 있어요.

pen.color("brown")
pen.up()
pen.goto(-20, -150)
pen.down()

pen.begin_fill()
for i in range(2):
    pen.forward(40)
    pen.right(90)
    pen.forward(60)
    pen.right(90)
pen.end_fill()
forward(40) → right(90) → forward(60) → right(90)을 2번 반복하면 시작점으로 정확히 돌아오면서 직사각형이 완성돼요.

STEP 4

04별과 문구 쓰기

트리 꼭대기에 별(노란 점)을 찍고, 화면 위쪽에 축하 문구를 적어요.

pen.up()
pen.goto(0, 50)
pen.dot(20, "yellow")

pen.up()
pen.goto(0, 250)
pen.color("white")
pen.write("Merry Christmas!", align="center",
          font=("Arial", 24, "bold"))
dot(20, "yellow")은 지름 20인 노란 점을 찍어요. write()로 화면에 글씨를 쓸 수 있고, align="center"로 가운데 정렬해요.

STEP 5

05눈송이 클래스 설계하기

눈송이 하나마다 반복되는 "모양 정하기 → 랜덤 위치 → 랜덤 속도" 과정을 클래스로 묶어요.

class Snow:

    def __init__(self):
        self.t = t.Turtle()
        self.t.shape("circle")
        self.t.color("white")
        self.t.shapesize(0.4)
        self.t.penup()

        self.t.goto(
            random.randint(-390, 390),
            random.randint(-300, 300)
        )

        self.speed = random.randint(1, 3)
눈송이를 만들 때마다(__init__) 화면 안 랜덤한 위치에 놓고, 1~3 사이 랜덤 속도를 하나씩 정해줘요. 그래서 눈송이마다 떨어지는 속도가 달라요.
STEP 6

06눈송이 움직이기

눈송이를 한 칸씩 아래로 내리고, 화면 밖으로 나가면 다시 위로 올려보내요.

    def move(self):
        self.t.sety(self.t.ycor() - self.speed)

        if self.t.ycor() < -300:
            self.t.goto(random.randint(-390, 390), 300)
y좌표에서 self.speed만큼 계속 빼면 아래로 떨어져요. 화면 아래(-300)를 벗어나면 위쪽(300)의 랜덤한 x위치로 되돌려서 눈이 끊임없이 내리는 것처럼 보여요.
STEP 7

07눈송이 100개 만들기

Snow() 객체를 100번 만들어서 리스트에 담아요.

snow_list = []

for i in range(100):
    snow_list.append(Snow())
snow_list 안의 눈송이 100개는 전부 서로 다른 위치·속도를 가진 별개의 객체예요. 리스트로 담아두면 나중에 한 번에 다룰 수 있어요.
미리보기

지금까지는 눈송이가 이렇게 멈춰있어요 (아직 움직이는 코드는 없어요).

STEP 8

08애니메이션 반복시키기

무한 반복문 안에서 눈송이 100개를 전부 움직이고, 화면을 새로 그려요.

while True:

    for snow in snow_list:
        snow.move()

    screen.update()
while True로 끝없이 반복하면서, 눈송이 100개를 각각 한 칸씩 움직인 뒤 screen.update()로 화면을 새로 그려요. 이게 반복되면서 눈이 내리는 애니메이션이 완성돼요.
미리보기

완성! 눈이 계속 내려요.
