PYTHON · 조건문

if문,
조건에 따라 갈라지는 코드

if문은 조건이 참(True)인지 거짓(False)인지에 따라 실행할 코드를 다르게 선택하는 구문이에요.

💡 왜 필요할까?프로그램이 사람처럼 상황을 판단하게 만들어주는 것이 if문이에요. if문이 없다면 프로그램은 항상 같은 코드만 위에서 아래로 실행할 뿐, 어떤 결정도 내릴 수 없어요. 예) 점수가 60점 이상이면 "합격", 아니면 "불합격" / 비밀번호가 맞으면 로그인, 틀리면 다시 입력받기.
CONCEPT 1

01if문의 기본 구조

조건이 True일 때만 들여쓰기 된 코드가 실행돼요.

if 조건식:
    실행할 코드
score = 85
if score >= 60:
    print("합격입니다!")
→
합격입니다!
💡 알 수 있는 것조건식 뒤에는 반드시 :(콜론)을 붙여요.
조건이 True인 코드는 들여쓰기(보통 스페이스 4칸)로 구분해요. 들여쓰기가 같은 줄까지가 if문 안의 코드예요.
⚠️ 들여쓰기가 다르면 오류(IndentationError)가 발생해요.파이썬은 중괄호 {} 대신 들여쓰기로 코드 블록을 구분하기 때문에, 들여쓰기 규칙을 꼭 지켜야 해요.
✏️ EXAMPLE · 짝수 판별기

변수 n이 짝수이면 "짝수입니다"를 출력하는 코드를 완성해봅시다. (짝수 판별: n % 2 == 0)

🎯 MISSION · 미성년자 알림

나이(age)가 19 미만이면 "미성년자입니다"를 출력하는 코드를 작성해보세요.

age = 15 인 경우 출력 → 미성년자입니다
정답 보기 
age = 15
if age < 19:
    print("미성년자입니다")

02비교 연산자와 조건식

if문의 조건식은 결과가 True 또는 False인 참/거짓 값(bool)이어야 해요. 이 값을 만들 때 비교 연산자를 사용해요.

연산자의미예시결과
==같다3 == 3True
!=다르다3 != 5True
>크다5 > 3True
<작다5 < 3False
>=크거나 같다5 >= 5True
<=작거나 같다4 <= 3False
⚠️ 가장 흔한 실수: = 와 ===는 "대입"(값을 저장), ==는 "비교"(같은지 확인)예요. if문 조건식에는 반드시 ==를 사용해야 해요.

CONCEPT 3

04if - else — 두 갈래로 나누기

조건이 True일 때와 False일 때 각각 다른 코드를 실행하고 싶다면 else를 사용해요.

if 조건식:
    조건이 참일 때 실행
else:
    조건이 거짓일 때 실행
score = 45
if score >= 60:
    print("합격")
else:
    print("불합격")
→
불합격
💡 알 수 있는 것if와 else는 항상 둘 중 하나만 실행돼요. 두 코드가 동시에 실행되는 일은 없어요.
else는 조건식을 따로 쓰지 않아요. (else 자체가 "그 외 나머지 모든 경우"라는 뜻)
✏️ EXAMPLE · 홀수/짝수 판별

정답 보기 
pw = "0000"
if pw == "1234":
    print("로그인 성공")
else:

CONCEPT 4

05if - elif - else — 여러 조건 검사하기

조건이 3개 이상일 때는 elif(else if)를 사용해요. 위에서부터 순서대로 검사하다가 처음으로 True인 조건을 만나면 그 블록만 실행하고 나머지는 검사하지 않아요.

if 조건식1:
    실행1
elif 조건식2:
    실행2
elif 조건식3:
    실행3
else:
    실행4 (모두 거짓일 때)
score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("D")
→
B
⚠️ elif 순서가 중요해요!조건은 위에서부터 검사되고, 하나라도 True이면 그 아래 elif/else는 검사하지 않아요. 90점을 90 이상 조건보다 먼저 60 이상 조건에 두면 항상 그 조건에서 멈춰버려요. 그래서 큰 범위(느슨한 조건)는 뒤에, 좁은 범위(엄격한 조건)는 앞에 두어야 해요.
✏️ EXAMPLE · 실행 순서 확인하기

아래 코드에서 score를 바꿔가며 실행해보고, 왜 그 결과가 나오는지 확인해보세요.

CONCEPT 5

07논리 연산자 — and, or, not

여러 조건을 동시에 검사하고 싶을 때 논리 연산자를 사용해요.

연산자의미참(True)이 되는 경우
and그리고두 조건이 모두 True일 때
or또는두 조건 중 하나라도 True일 때
not부정조건이 False일 때 (True를 False로 뒤집음)
age = 17
height = 160
if age >= 15 and height >= 150:
    print("탑승 가능")
else:
    print("탑승 불가")
→
탑승 가능
💡 알 수 있는 것age >= 15 and height >= 150 은 두 조건이 모두 True여야 전체가 True가 돼요.
조건이 헷갈릴 땐 괄호 ()로 묶어 우선순위를 명확히 하면 좋아요. 예: (a > 0) and (b > 0)
✏️ EXAMPLE · and / or / not 비교하기

같은 조건을 and와 or로 바꿔가며 결과가 어떻게 달라지는지 확인해보세요.

CONCEPT 6 · 심화

08중첩 if문 (심화)

if문 안에 또 다른 if문을 넣을 수 있어요. 바깥 조건이 True일 때만 안쪽 조건을 다시 검사해요.

if 바깥조건:
    if 안쪽조건:
        실행 (바깥도 True, 안쪽도 True)
    else:
        실행 (바깥은 True, 안쪽은 False)
else:
    실행 (바깥이 False)
weather = "비"
umbrella = True
if weather == "비":
    if umbrella:
        print("우산 챙겨서 외출")
    else:
        print("비 맞을 각오하고 외출")
else:
    print("그냥 외출")
→
우산 챙겨서 외출
💡 중첩 if문 vs and 연산자if a: if b: 는 if a and b: 와 결과가 같을 때가 많지만, 중첩 if문은 바깥 조건은 True인데 안쪽 조건은 False인 경우를 따로 처리할 수 있다는 차이가 있어요. (위 예시의 "비 맞을 각오" 같은 경우)
⚠️ 들여쓰기 단계에 주의하세요.중첩될수록 들여쓰기가 한 단계(스페이스 4칸)씩 더 깊어져요. 들여쓰기 단계가 어긋나면 의도한 것과 다른 if문에 코드가 속하게 돼요.
✏️ EXAMPLE · 놀이공원 입장료 계산
