연필꽂이 만들기

오늘은 책상 위를 깔끔하게 정리해 줄 연필꽂이를 만들어 볼 거예요. 상자에 구멍을 뚫어 칸을 나누는 방법과, 육각형 모양인 폴리곤을 이어 붙이는 방법, 두 가지를 배워요. 차근차근 따라오면 멋진 연필꽂이를 완성할 수 있어요!

1상자 두 개로 큰 틀 만들기
✏️ 따라하기
  1. 기본 도형에서 상자를 가져와요.
  2. 가로 27, 세로 30, 높이 32로 바꿔요.
  3. 상자를 하나 복사해서 더 작게 만들어요.
  4. 복사한 상자는 가로 24, 세로 27, 높이 29로 바꿔요.
  5. 작은 상자를 선택하고 구멍을 눌러요.
2정렬해서 속 비우기
✏️ 따라하기
  1. 큰 상자와 구멍 상자를 모두 선택해요.
  2. 정렬 기능을 눌러요.
  3. 가로 가운데를 눌러 맞춰요.
  4. 세로 가운데를 눌러 맞춰요.
  5. 높이 위쪽을 눌러 맞춰요.
3그룹화하고 평면도로 확인하기
✏️ 따라하기
  1. 도형을 모두 선택하고 묶기를 해요.
  2. 속이 뚫린 통 모양이 만들어져요.
  3. 화면을 평면도로 바꿔서 위에서 봐요.
  4. 통을 두 번 복사해서 모두 3개로 만들어요.
  5. 세 통을 나란히 줄 맞춰 붙여요.
4양옆 높이 바꾸기
✏️ 따라하기
  1. 가운데 통은 그대로 두어요.
  2. 양옆에 있는 통을 각각 선택해요.
  3. 높이를 자유롭게 바꿔봐요.
  4. 가운데보다 낮거나 높게 만들 수 있어요.
5구멍 도형 올려서 자를 자리 정하기
✏️ 따라하기
  1. 네모 모양 구멍 도형을 다시 가져와요.
  2. 가운데 통 위쪽에 올려놓아요.
  3. 크기를 조절해서 자르고 싶은 자리에 맞춰요.
  4. 회색으로 보이는 부분이 잘려 나가는 자리예요.
6여러 방향에서 자르는 모양 확인하기
✏️ 따라하기
  1. 구멍 도형의 각도를 조금씩 돌려봐요.
  2. 원하는 모양으로 잘리도록 맞춰요.
  3. 위, 옆, 앞 여러 방향에서 돌려서 확인해요.
  4. 모양이 자연스러운지 잘 살펴봐요.
7그룹화하고 크기 다듬기
✏️ 따라하기
  1. 도형을 모두 선택해요.
  2. 묶기를 눌러 하나로 합쳐요.
  3. 전체 크기를 원하는 만큼 조절해요.
  4. 연필꽂이 모양이 깔끔하게 완성돼요.
8캐릭터로 꾸미기
✏️ 따라하기
  1. 기본 도형 옆 화살표를 눌러봐요.
  2. 여러 가지 캐릭터 모양을 가져올 수 있어요.
  3. 귀나 눈 같은 장식을 연필꽂이에 더해요.
  4. 모든 방향에서 보면서 위치를 잘 잡아요.
  5. 나만의 개성 있는 연필꽂이가 완성돼요.
9폴리곤으로 육각형 통 만들기
✏️ 따라하기
  1. 기본 도형에서 폴리곤을 가져와요.
  2. 가로 26, 세로 30, 높이 25로 바꿔요.
  3. 폴리곤을 복사해서 더 작게 만들어요.
  4. 복사한 도형은 가로 23, 세로 27, 높이 22로 바꿔요.
  5. 작은 도형을 선택하고 구멍을 눌러요.
  6. 두 도형을 가로 가운데, 세로 가운데, 높이 위쪽으로 정렬해요.
10육각형 통 여러 개 배치하기
사진이 없어요.
설명을 잘 읽고 따라해 봐요!
✏️ 따라하기
  1. 정렬한 두 도형을 모두 선택해 묶기를 해요.
  2. 속이 빈 육각형 통이 만들어져요.
  3. 화면을 평면도로 바꿔서 위에서 봐요.
  4. 육각형 통을 여러 개 복사해요.
  5. 키보드 방향키로 조금씩 움직여서 벌집처럼 딱 맞게 붙여요.
  6. 자리를 맞추면서 크기도 원하는 대로 바꿔요.
11완성하고 출력하기
✏️ 따라하기
  1. 맞춰 놓은 육각형 통을 모두 선택해요.
  2. 묶기를 눌러 하나의 연필꽂이로 완성해요.
  3. 작업판 위에서 완성된 모습을 잘 확인해요.
  4. 완성한 작품은 3D프린터로 출력할 수 있어요.
