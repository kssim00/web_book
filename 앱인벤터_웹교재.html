📚 시계 · 변수 · 리스트

주사위·풍선·MP3 앱을 만들기 전에 꼭 필요한 세 가지 기초를 익혀요. 한 번 이해하면 모든 앱에 두루 쓰여요.

⏰ 시계 — 일정 시간마다 ‘똑딱’ 신호를 줘요

시계가 하는 일

휴대전화 안의 시계를 사용해, 정해진 시간 간격마다 자동으로 이벤트를 발생시켜요. 주사위가 빠르게 굴러가거나, 풍선 시간이 줄어드는 것 모두 시계 덕분이에요.

  • 타이머 간격: 몇 밀리초마다 작동할지 (1000 = 1초)
  • 타이머 활성화 여부: 참=켜기 / 거짓=끄기

📦 변수 — 값을 담아두는 상자

변수란?

점수, 시간 같은 값을 담아두는 상자예요. 상자에 이름을 붙이고 값을 넣었다 꺼냈다 해요.

  • 전역변수: 앱 어디서든 쓸 수 있는 상자
  • 지역변수: 정해진 부분에서만 쓰는 상자
변수 만들고 1만큼 늘리기
전역변수 만들기점수초기값0

📋 리스트 — 값을 여러 개 ‘순서대로’ 담는 상자

변수와 리스트의 차이

변수는 값을 한 개만 담아요. 리스트는 한 상자에 값을 여러 개 순서대로 담아요. 각 값의 자리는 번호(1, 2, 3…)로 구분하고, 가운데 항목을 지우면 뒤 항목들이 한 칸씩 당겨져요.

  • 시작 값 전달하며 다른 스크린 열기
