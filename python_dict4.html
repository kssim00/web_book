1. 딕셔너리란?

💡 학습 포인트
딕셔너리는 데이터를 Key(키) : Value(값) 형태로 저장하는 자료형입니다. 리스트처럼 여러 데이터를 저장하지만, 번호(Index)가 아니라 Key를 이용해서 데이터를 찾습니다.

리스트와 비교해 보기

같은 데이터를 저장해도 찾는 방법이 다릅니다. 리스트는 순서 번호로 찾고, 딕셔너리는 이름인 Key로 찾습니다.

animals = ["멍멍", "야옹"] print(animals[0])
실행 결과
멍멍
animals = { "강아지": "멍멍", "고양이": "야옹" } print(animals["강아지"])
실행 결과
멍멍
리스트딕셔너리
순서가 중요할 때이름으로 찾을 때
Index 사용Key 사용
animals[0]animals["강아지"]

2. 딕셔너리 만들기

딕셔너리 만들기

딕셔너리는 { } 중괄호를 사용하고, Key : Value 형태로 데이터를 넣습니다. 여러 쌍은 쉼표로 구분합니다.

animals = { "강아지": "멍멍", "고양이": "야옹" } print(animals)
실행 결과
{'강아지': '멍멍', '고양이': '야옹'}

3. Key로 Value 찾기

Key로 Value 찾기

딕셔너리는 Key를 대괄호 안에 넣어서 Value를 가져올 수 있습니다.

animals = { "강아지": "멍멍", "고양이": "야옹" } print(animals["강아지"])
실행 결과
멍멍

딕셔너리에 없는 Key를 사용하면 오류가 발생합니다.

animals = { "강아지": "멍멍", "고양이": "야옹" } print(animals["토끼"])
실행 결과
KeyError: '토끼'
⚠️ 주의!
없는 Key를 대괄호 []로 찾으면 오류가 발생합니다.

4. 데이터 추가 · 수정 · 삭제

4-1. 데이터 추가

새로운 Key와 Value를 넣으면 데이터가 추가됩니다.

animals = { "강아지": "멍멍", "고양이": "야옹" } animals["오리"] = "꽥꽥" print(animals)
실행 결과
{'강아지': '멍멍', '고양이': '야옹', '오리': '꽥꽥'}

4-2. 데이터 수정

이미 존재하는 Key에 새로운 Value를 넣으면 데이터가 수정됩니다.

animals = { "강아지": "멍멍", "고양이": "야옹" } animals["고양이"] = "냐옹" print(animals)
실행 결과
{'강아지': '멍멍', '고양이': '냐옹'}

4-3. 데이터 삭제

del을 사용하면 원하는 데이터를 삭제할 수 있습니다.

animals = { "강아지": "멍멍", "고양이": "야옹" } del animals["고양이"] print(animals)
실행 결과
{'강아지': '멍멍'}

4-4. 딕셔너리 전체 삭제

clear()를 사용하면 모든 데이터를 삭제할 수 있습니다.

animals = { "강아지": "멍멍", "고양이": "야옹" } animals.clear() print(animals)
실행 결과
{}
💡 기억하기
없는 Key → 추가
있는 Key → 수정

5. 딕셔너리에서 자주 사용하는 함수

5-1. get()으로 데이터 가져오기

대괄호 [] 대신 get()을 사용하면 없는 Key를 찾았을 때 오류를 피할 수 있습니다.

animals = { "강아지": "멍멍", "고양이": "야옹" } print(animals.get("강아지")) print(animals.get("토끼"))
실행 결과
멍멍 None

위 예시에서 None은 찾는 Key가 없어서 반환된 값입니다. 즉, 저장된 값이 없다는 뜻입니다.

두 번째 값에 기본값을 지정할 수도 있습니다.

animals = { "강아지": "멍멍", "고양이": "야옹" } print(animals.get("토끼", "정보 없음"))
실행 결과
정보 없음

5-2. in으로 Key가 있는지 확인하기

animals = { "강아지": "멍멍", "고양이": "야옹" } print("강아지" in animals) print("토끼" in animals)
실행 결과
True False

5-3. len()으로 데이터 개수 확인하기

animals = { "강아지": "멍멍", "고양이": "야옹" } print(len(animals))
실행 결과
2

6. 딕셔너리 사용할 때 주의할 점

6-1. Key는 아무거나 사용할 수 있을까요?

딕셔너리의 Key에는 사용할 수 있는 자료형과 사용할 수 없는 자료형이 있습니다. 변경할 수 없는 자료형은 Key로 사용할 수 있지만, 리스트나 딕셔너리처럼 변경할 수 있는 자료형은 사용할 수 없습니다.

✅ Key로 사용할 수 있는 예

animals = { 1: "강아지", "cat": "고양이", (1, 2): "오리" } print(animals)
실행 결과
{1: '강아지', 'cat': '고양이', (1, 2): '오리'}

❌ Key로 사용할 수 없는 예

animals = { ["강아지", "고양이"]: "동물" } print(animals)
실행 결과
TypeError: unhashable type: 'list'

6-2. 같은 Key를 여러 번 사용하면?

같은 Key를 여러 번 사용하면 마지막에 넣은 Value가 남습니다.

animals = { "강아지": "멍멍", "강아지": "왈왈" } print(animals)
실행 결과
{'강아지': '왈왈'}

8. keys()와 values()

8-1. keys()

keys()는 딕셔너리의 모든 Key를 가져옵니다.

animals = { "강아지": "멍멍", "고양이": "야옹", "오리": "꽥꽥" } print(animals.keys())
실행 결과
dict_keys(['강아지', '고양이', '오리'])

8-2. values()

values()는 딕셔너리의 모든 Value를 가져옵니다.

animals = { "강아지": "멍멍", "고양이": "야옹", "오리": "꽥꽥" } print(animals.values())
실행 결과
dict_values(['멍멍', '야옹', '꽥꽥'])
💡 기억하기
keys()와 values()는 리스트가 아니라 dict_keys와 dict_values 자료형을 반환합니다. 리스트로 사용하고 싶다면 list()로 변환하면 됩니다.
animals = { "강아지": "멍멍", "고양이": "야옹", "오리": "꽥꽥" } animal_keys = list(animals.keys()) animal_values = list(animals.values()) print(animal_keys) print(animal_values)
실행 결과
['강아지', '고양이', '오리'] ['멍멍', '야옹', '꽥꽥']

9. items()

items()로 Key와 Value 함께 가져오기

items()를 사용하면 Key와 Value를 한꺼번에 가져올 수 있습니다. 이후 반복문과 함께 사용하면 더욱 편리합니다.

animals = { "강아지": "멍멍", "고양이": "야옹", "오리": "꽥꽥" } print(animals.items())
실행 결과
dict_items([('강아지', '멍멍'), ('고양이', '야옹'), ('오리', '꽥꽥')])
💡 결과 읽기
items()의 각 항목은 (Key, Value)가 한 쌍으로 묶인 튜플입니다. 예를 들어 ('강아지', '멍멍')에서 '강아지'는 Key, '멍멍'은 Value입니다.

10. for문과 딕셔너리

10-1. Key를 하나씩 꺼내기

딕셔너리 자체를 for문에 넣으면 Key를 하나씩 꺼낼 수 있습니다.

animals = { "강아지": "멍멍", "고양이": "야옹", "오리": "꽥꽥" } for key in animals: print(key)
실행 결과
강아지 고양이 오리

반복문에서 꺼낸 Key를 딕셔너리에 넣으면 연결된 Value를 찾을 수 있습니다.

animals = { "강아지": "멍멍", "고양이": "야옹", "오리": "꽥꽥" } for key in animals: print(key, ":", animals[key])
실행 결과
강아지 : 멍멍 고양이 : 야옹 오리 : 꽥꽥

10-2. Value를 하나씩 꺼내기

values()와 for문을 함께 사용하면 Value를 하나씩 꺼낼 수 있습니다.

animals = { "강아지": "멍멍", "고양이": "야옹", "오리": "꽥꽥" } for value in animals.values(): print(value)
실행 결과
멍멍 야옹 꽥꽥

10-3. Key와 Value를 함께 꺼내기

items()와 for문을 함께 사용하면 Key와 Value를 동시에 사용할 수 있습니다.

animals = { "강아지": "멍멍", "고양이": "야옹", "오리": "꽥꽥" } for key, value in animals.items(): print(key, ":", value)
실행 결과
강아지 : 멍멍 고양이 : 야옹 오리 : 꽥꽥

▶ 출력 예시

MISSION 02
단어 투표 집계 (Word Counter)
과일 이름이 담긴 리스트 fruits에서 각 과일이 몇 번 나왔는지 세어 딕셔너리로 만드세요.
📦 주어진 데이터
fruits = ['apple', 'banana', 'apple', 'apple']
▶ 출력
{'apple': 3, 'banana': 1}
정답 코드 확인하기
fruits = ['apple', 'banana', 'apple', 'apple'] counts = {} for f in fruits: if f in counts: counts[f] += 1 else: counts[f] = 1 print(counts)

MISSION 10
숫자 개수 세기
주어진 숫자 문자열에서 각 숫자가 몇 번 나왔는지 세어 딕셔너리로 만드세요. 숫자의 종류와 가장 많이 나온 숫자도 출력하세요.
📦 주어진 데이터
data = '1231231231'
▶ 출력
{1: 4, 2: 3, 3: 3}

사용한 숫자는 3개입니다.
가장 많이 나온 숫자는 1입니다.
정답 코드 확인하기
data = '1231231231' counts = {} for ch in data: n = int(ch) if n in counts: counts[n] += 1 else: counts[n] = 1 print(counts) print(f'\n사용한 숫자는 {len(counts)}개입니다.') most_used = max(counts, key=counts.get) print(f'가장 많이 나온 숫자는 {most_used}입니다.')

가장 많이 판매된 물건: 사과

정답 코드 확인하기
items = '사과 바나나 사과 포도 바나나 사과'.split() counts = {} for item in items: if item in counts: counts[item] += 1 else: counts[item] = 1 print(counts) most_sold = max(counts, key=counts.get) print(f'\n가장 많이 판매된 물건: {most_sold}') print(f'판매량: {counts[most_sold]}개')
MISSION 12
우리 반 성적 분석하기
학생 점수를 이용해 학생 수, 최고 점수와 학생, 최저 점수와 학생을 출력하세요.
📦 주어진 데이터
scores = {'민수': 80, '지우': 95, '철수': 70, '수빈': 90, '영희': 85}
▶ 출력
학생 수: 5명
최고 점수: 95점
최고 점수 학생: 지우
최저 점수: 70점
최저 점수 학생: 철수
정답 코드 확인하기
scores = {'민수': 80, '지우': 95, '철수': 70, '수빈': 90, '영희': 85} best_name = max(scores, key=scores.get) worst_name = min(scores, key=scores.get) print(f'학생 수: {len(scores)}명') print(f'최고 점수: {scores[best_name]}점') print(f'최고 점수 학생: {best_name}') print(f'최저 점수: {scores[worst_name]}점') print(f'최저 점수 학생: {worst_name}')
