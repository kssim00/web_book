STEP 2

탐색기, 로블록스 게임의 지도예요

탐색기(Explorer)는 게임 안의 모든 것을 종류별로 정리해서 보여줘요. Workspace 아래에 블록이 있다면, 블록은 Workspace의 자식이에요.

실제 로블록스 스튜디오 홈 탭 — 탐색기 · 속성 버튼 위치
화살표를 눌러 펼치면 안에 들어있는 것들이 보여요. 스크립트를 쓰기 전에 탐색기부터 익혀야 "이 코드가 어떤 블록을 가리키는지" 알 수 있어요.
실제 탐색기 화면 — Workspace, Lighting, ServerScriptService 등
오늘 자주 쓸 서비스는 ServerScriptService예요. 서버 스크립트를 여기 넣어요.
STEP 3

블록과 친해지기 — 복제로 첫 점프맵 만들기

STEP1에서 만든 블록을 복제(Ctrl+D)해서 이어 붙이면, 오늘의 점프맵 기본 경로가 완성돼요. 아직 스크립트는 없어도 괜찮아요 — 경로부터 설계하는 거예요.

  1. 1

    STEP1에서 만든 블록을 선택하고 Ctrl+D로 복제합니다.

  2. 2

    이동(Move) 도구로 복제한 블록을 다음 자리로 옮깁니다.

  3. 3

    이 과정을 반복해서 최소 6~8개 블록으로 시작 지점부터 도착 지점까지 경로를 이어 붙입니다.

  4. 4

    블록 사이 간격을 뒤로 갈수록 조금씩 넓히면 난이도가 자연스럽게 올라가요.

실제 플레이 화면 — 여러 개 이어 붙이면 이런 느낌의 경로가 만들어져요
복제된 블록은 지금 전부 같은 모양이에요. 잠시 후 이 중 하나에 색깔이 바뀌는 스크립트를 만들고, 그다음엔 몇 개를 골라 스크립트만 크기 변경·폭발·순간이동·점프 부스트로 바꿔치기하면서 맵을 점점 재미있게 만들 거예요.

HIGHLIGHT · 06

색깔 블록 만들기 — Touched로 색 바꾸기

오늘의 첫 하이라이트! STEP1에서 만든 블록을 밟으면 색이 바뀌는 블록으로 완성해요.

  1. 1

    STEP1에서 만든 블록을 이동(Move) 도구로 바닥에서 살짝 위로 띄웁니다. 바닥에 닿아있으면 재생하자마자 Touched가 먼저 실행돼버려요.

  2. 2

    속성 → Anchored를 체크합니다. (안 하면 블록이 떨어져요)

  3. 3

    ⊕ 버튼(우클릭도 가능)을 눌러 Script를 추가합니다.

Script를 더블클릭해서 열고 아래 코드를 작성합니다.

local part = script.Parent -- 이 스크립트가 들어있는 블록
part.Touched:Connect(function(hit) -- 블록에 뭔가 닿을 때마다 실행됨
    part.Color = Color3.new(1, 0.6, 0) -- 블록 색을 주황색으로 바꿈
end)
⚠ 재생하자마자 이미 주황색인가요?

블록이 바닥에 닿아있으면 재생 순간 Touched가 먼저 실행돼요. Position의 Y 값을 올려보세요.

Color3.new(1, 0.6, 0)의 세 숫자(빨강·초록·파랑)를 바꾸면 다른 색이 나와요.
  1. 1

    재생 버튼을 누릅니다.

  2. 2

    W·A·S·D로 걸어서 블록을 밟습니다. 색이 바뀌면 성공!

  3. 3

    확인 후 정지 버튼을 누릅니다.

이 스크립트를 STEP3에서 만든 점프맵 블록들에도 그대로 복사해 넣으면 점프맵 전체가 색깔 블록으로 완성돼요. 잠시 후 이 중 몇 개를 골라 스크립트만 하나씩 바꿔서 크기 변경·폭발·순간이동·점프 부스트 같은 다양한 블록으로 발전시킬 거예요.
HIGHLIGHT · 07

크기 변경 · 사라지는 발판

복제해둔 색깔 블록 중 몇 개를 골라, 스크립트만 바꿔치기해요. 크기가 커졌다 작아지는 블록과, 밟으면 사라지는 발판을 만들어봐요.

커졌다 작아졌다
  1. 1

    점프맵에서 블록 하나를 선택합니다.

  2. 2

    안에 있는 Script를 열고, 아래 코드로 통째로 바꿔 씁니다.

local part = script.Parent -- 이 스크립트가 들어있는 블록
local originalSize = part.Size -- 원래 크기를 미리 기억해둠
local triggered = false -- 중복 실행을 막는 잠금장치

part.Touched:Connect(function(hit) -- 블록에 뭔가 닿을 때마다 실행됨
    if triggered then return end -- 이미 작동 중이면 무시
    triggered = true -- 잠금장치 걸기

    part.Size = originalSize * 1.6 -- 원래 크기의 1.6배로 커짐
    wait(1) -- 1초 대기
    part.Size = originalSize -- 다시 원래 크기로

    wait(0.5) -- 0.5초 뒤
    triggered = false -- 잠금장치 풀기(다시 밟을 수 있게)
end)
triggered 잠금장치가 필요한 이유 — 없으면 밟고 있는 동안 Touched가 계속 겹쳐 실행돼서 크기가 이상하게 튀어요. originalSize를 미리 저장해두는 이유는, part.Size에 숫자를 계속 곱하면 원래 크기를 까먹어버리기 때문이에요.
  1. 1

    재생 버튼을 누르고 블록을 밟아봅니다. 커졌다가 1초 뒤 원래 크기로 돌아오면 성공!

  2. 2

    확인 후 정지 버튼을 누릅니다.

1.6을 0.3처럼 1보다 작은 숫자로 바꾸면 커지는 대신 작아지는 블록이 돼요.
크기 변경 응용 — 사라지는 발판

크기 대신 Transparency·CanCollide를 바꾸면, 밟으면 아예 사라지는 발판도 같은 원리로 만들 수 있어요.

  1. 1

    다른 블록 하나를 더 고릅니다.

  2. 2

    안에 있는 Script를 아래 코드로 바꿔 씁니다.

local part = script.Parent -- 이 스크립트가 들어있는 블록(발판)
local triggered = false -- 중복 실행을 막는 잠금장치

part.Touched:Connect(function(hit) -- 발판에 뭔가 닿을 때마다 실행됨
    if triggered then return end -- 이미 작동 중이면 무시
    triggered = true -- 잠금장치 걸기

    wait(1) -- 1초 대기
    part.Transparency = 1 -- 발판을 투명하게 만듦
    part.CanCollide = false -- 더 이상 밟고 설 수 없게 만듦

    wait(3) -- 3초 뒤
    part.Transparency = 0 -- 다시 보이게
    part.CanCollide = true -- 다시 밟고 설 수 있게
    triggered = false -- 잠금장치 풀기(다시 밟을 수 있게)
end)
⚠ 잊지 마세요 — Transparency만 바꾸면 안 보여도 여전히 밟을 수 있어요. CanCollide = false도 꼭 같이 써야 진짜로 통과돼요.
둘을 합치면? — 크기 변경 + 사라지는 발판 이어 붙이기

완전히 새 코드가 아니에요. 방금 만든 커졌다 작아졌다 코드는 그대로 두고, 아래 노란 점선 상자 부분만 그 사이에 이어 붙이면 돼요. 지우는 줄은 하나도 없어요.

  1. 1

    커졌다 작아졌다 블록의 Script를 다시 엽니다.

  2. 2

    part.Size = originalSize 줄 바로 다음, wait(0.5) 줄 바로 위에 노란 상자 안의 6줄을 그대로 붙여 넣습니다.

local part = script.Parent -- 이 스크립트가 들어있는 블록
local originalSize = part.Size -- 원래 크기를 미리 기억해둠
local triggered = false -- 중복 실행을 막는 잠금장치

part.Touched:Connect(function(hit) -- 블록에 뭔가 닿을 때마다 실행됨
    if triggered then return end -- 이미 작동 중이면 무시
    triggered = true -- 잠금장치 걸기

    part.Size = originalSize * 1.6 -- 원래 크기의 1.6배로 커짐
    wait(1) -- 1초 대기
    part.Size = originalSize -- 다시 원래 크기로 (원래 있던 줄, 그대로)
-- ▼ 추가 : 여기서부터 사라지는 발판 코드를 그대로 이어 붙이기
    wait(1) -- 1초 대기
    part.Transparency = 1 -- 발판을 투명하게 만듦
    part.CanCollide = false -- 더 이상 밟고 설 수 없게 만듦

    wait(3) -- 3초 뒤
    part.Transparency = 0 -- 다시 보이게
    part.CanCollide = true -- 다시 밟고 설 수 있게

    wait(0.5) -- (원래 있던 줄, 그대로)
    triggered = false -- 잠금장치 풀기(다시 밟을 수 있게) (원래 있던 줄, 그대로)
end)
순서가 중요해요 — triggered = false는 맨 마지막에 딱 한 번만 있어야 해요. 노란 상자를 wait(0.5) 위에 끼워 넣으면, 커졌다 작아진 뒤에 이어서 투명해졌다 다시 나타나는 순서로 자연스럽게 이어져요.
HIGHLIGHT · 08

폭발 블록 — 밟으면 터짐

이번엔 밟으면 3초 뒤 터지는 블록이에요. Instance.new("Explosion")으로 폭발 효과를 새로 만들어서 화면에 등장시켜요.

  1. 1

    또 다른 블록 하나를 고릅니다.

  2. 2

    안에 있는 Script를 아래 코드로 바꿔 씁니다.

local part = script.Parent -- 이 스크립트가 들어있는 블록(트랩)
local triggered = false -- 한 번만 터지게 막는 잠금장치

part.Touched:Connect(function(hit) -- 블록에 뭔가 닿을 때마다 실행됨
    if triggered then return end -- 이미 터졌으면 아무것도 안 함
    triggered = true -- 잠금장치를 걸어서 중복 실행 방지

    wait(3) -- 3초 대기

    local explosion = Instance.new("Explosion") -- 폭발 효과 생성
    explosion.Position = part.Position -- 터질 위치 = 블록의 위치
    explosion.BlastRadius = 10      -- 폭발 범위
    explosion.BlastPressure = 500000 -- 폭발 힘
    explosion.Parent = workspace -- 게임 화면에 등장시킴

    part.Transparency = 1 -- 블록을 안 보이게 함
    part.CanCollide = false -- 밟고 설 수 없게(통과되게) 함

    wait(5) -- 5초 뒤
    part.Transparency = 0 -- 다시 보이게
    part.CanCollide = true -- 다시 밟고 설 수 있게
    triggered = false -- 잠금장치 풀기(다시 터질 수 있게)
end)

킬파트 · 리스폰 — 떨어지면 다시 시작

폭발하거나 사라지는 발판을 밟고 바다에 빠지면, 자동으로 시작 지점에서 다시 시작하게 만들어요. 바다 아래에 안 보이는 블록 하나만 깔면 끝이에요.

  1. 1

    바다 수면보다 낮은 곳에 새 블록을 추가하고, Anchored를 체크합니다.

순간이동 블록

밟으면 정해둔 위치로 순간 이동하는 블록이에요. 지름길로 써도 되고, 짓궂은 함정으로 써도 돼요.

  1. 1

    점프맵에서 블록 하나를 고릅니다.

  2. 2

    안에 있는 Script를 아래 코드로 바꿔 씁니다.

local part = script.Parent -- 이 스크립트가 들어있는 블록
local targetPoint = Vector3.new(0, 5, 0) -- 이동할 위치 좌표
local triggered = false -- 중복 실행을 막는 잠금장치

part.Touched:Connect(function(hit) -- 블록에 뭔가 닿을 때마다 실행됨
    if triggered then return end -- 이미 작동 중이면 무시
    triggered = true -- 잠금장치 걸기

    local character = hit.Parent -- 닿은 물체의 부모(캐릭터)
    character:MoveTo(targetPoint) -- 캐릭터를 targetPoint 위치로 이동
    print("순간이동!") -- 출력 창에 메시지 표시

    wait(1) -- 1초 대기
    triggered = false -- 잠금장치 풀기(다시 밟을 수 있게)
end)
Vector3.new(x, y, z)는 3차원 좌표예요. 원하는 위치를 클릭한 뒤 속성 창의 Position 값을 참고해서 targetPoint 숫자를 바꿔보세요.

점프력 부스트 블록

밟으면 잠깐 동안 훨씬 높이 뛸 수 있게 되는 블록이에요. Humanoid.JumpPower 값을 올렸다가, 시간이 지나면 원래대로 되돌려요.

  1. 1

    또 다른 블록 하나를 고릅니다.

  2. 2

    안에 있는 Script를 아래 코드로 바꿔 씁니다.

local part = script.Parent -- 이 스크립트가 들어있는 블록
local triggered = false -- 중복 실행을 막는 잠금장치

part.Touched:Connect(function(hit) -- 블록에 뭔가 닿을 때마다 실행됨
    if triggered then return end -- 이미 작동 중이면 무시
    triggered = true -- 잠금장치 걸기

    local character = hit.Parent -- 닿은 캐릭터
    local human = character:FindFirstChild("Humanoid") -- 점프력을 다루려면 Humanoid가 필요함
    if human then
        local originalPower = human.JumpPower -- 원래 점프력을 미리 기억해둠
        human.JumpPower = originalPower * 2 -- 점프력을 2배로 올림

        wait(4) -- 4초 동안 부스트 유지
        human.JumpPower = originalPower -- 다시 원래 점프력으로
    end

    wait(0.5) -- 0.5초 뒤
    triggered = false -- 잠금장치 풀기(다시 밟을 수 있게)
end)
originalPower를 저장해두는 이유는 크기 변경 블록의 originalSize와 같아요. 계속 곱하면 원래 값을 까먹어버리기 때문이에요.

다섯 블록으로 점프맵 완성하기

색깔 · 크기 변경 · 폭발 · 순간이동 · 점프 부스트, 다섯 가지 블록이 모두 준비됐어요. 이제 지금까지 만든 점프맵 블록들에 자유롭게 배치해서 나만의 점프맵을 완성해요.

  1. 1

    점프맵에서 블록을 하나 고릅니다.

  2. 2

    안에 있는 기존 Script 내용을 지우고, 원하는 스크립트(크기 변경 / 사라지는 발판 / 폭발 / 순간이동 / 점프 부스트)를 붙여넣습니다.

  3. 3

    나머지 블록에도 원하는 만큼 반복해서, 다섯 가지를 자유롭게 섞어봅니다.

  4. 4

    처음부터 끝까지 걸어보면서 막히는 구간이 있는지 확인합니다.

  5. 5

    너무 어려운 구간은 블록 간격을 줄이거나 블록 종류를 바꿔서 조정합니다.

실제 플레이 화면 — 완성하면 이런 느낌의 점프맵이 만들어져요
모든 블록을 다 바꿀 필요는 없어요. 색깔 블록도 몇 개 남겨두면 난이도에 완급 조절이 생겨요.

직접 에러 고쳐보기

아래 코드를 새 스크립트에 붙여넣고 재생을 눌러보세요. 일부러 오타를 심어뒀어요.

local part = script.Parent

part.Touched:Conenct(function(hit) -- 오타가 숨어있어요

    재생 버튼을 눌러 출력 창(빨간 글씨)에 뜨는 에러 메시지를 확인합니다.

  2. 2

    에러가 난 코드를 드래그해서 선택합니다.

  4. 4

    AI 답변을 참고해 오타를 고치고, 다시 재생해서 에러가 사라졌는지 확인합니다.
