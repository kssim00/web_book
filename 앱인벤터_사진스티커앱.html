오늘 만들 앱, 어떤 모습일까요?

앱을 만들기 전에, 우리 앱에 어떤 기능이 들어가는지 먼저 살펴봐요.

📸

사진찍기

버튼을 누르면 카메라가 켜지고, 사진을 찍어서 화면에 보여줘요.

🎭

이모티콘 꾸미기

사진 위 자리를 콕 찍고 이모티콘 버튼을 누르면 그 자리에 스티커가 나타나요.

💬

말풍선 넣기

자리를 콕 찍고, 하고 싶은 말을 써서 버튼을 누르면 글자가 나타나요.

💾

저장 · 취소

완성한 사진은 저장 버튼으로 저장하고, 마음에 안 들면 취소로 다시 시작해요.

준비하기

시작하기 전에 준비해요

  1. 1ai2.appinventor.mit.edu 사이트에 접속해요.
  2. 2구글(Google) 계정으로 로그인해요.
  3. 3화면 오른쪽 위 언어 메뉴에서 한국어를 골라요.
  4. 4왼쪽 위 [프로젝트] → [새 프로젝트 시작하기]를 눌러요.
  5. 5프로젝트 이름을 PhotoSticker 처럼 정해요. 영어·숫자만 가능, 띄어쓰기 불가!
Tip. 이 슬라이드는 한국어 화면을 기준으로 설명해요. 메뉴 이름이 영어로 보이면 3번을 다시 해 봐요.
1단계

화면 꾸미기 (디자이너)

왼쪽 팔레트에서 부품을 찾아 뷰어로 끌어다 놓아요. 다음 장부터 순서대로 배치해요.

먼저 알아두기 ① 이름 바꾸는 법 — 컴포넌트 목록에서 이름 클릭 → 이름 바꾸기 클릭 → 새 이름 입력 → 확인

먼저 알아두기 ② 속성 바꾸는 법 — 컴포넌트 목록에서 부품 클릭 → 오른쪽 속성 표에서 값 변경
1단계 · 배치 1 / 5

1사진찍기 버튼 놓기

  • 사용자 인터페이스 서랍 → 버튼을 화면 맨 위로 끌어다 놓아요.
  • 이름을 TakePictureButton 으로 바꿔요.
  • 속성에서 텍스트를 📸 사진찍기 로 바꿔요.
1단계 · 배치 2 / 5

2사진을 보여줄 캔버스 놓기

  • 그리기 & 애니메이션 서랍 → 캔버스를 버튼 아래에 놓아요.
  • 이름은 캔버스1 그대로 둬요.
  • 너비는 부모에 맞추기, 높이는 300 픽셀 정도로 정해요.
  • 글꼴 크기를 40 으로 정해요. 스티커와 글자가 이 크기로 그려져요. (그대로 두면 너무 작아요!)
1단계 · 배치 3 / 5

3이모티콘 버튼 4개 놓기

  • 레이아웃 서랍 → 수평배치를 캔버스1 아래에 놓아요. 이름: EmojiRow
  • 사용자 인터페이스 서랍 → 버튼 4개를 EmojiRow 안에 나란히 놓아요.
  • 이름: BtnStar / BtnHeart / BtnCrown / BtnSmile
  • 텍스트: ⭐ ❤️ 👑 😀, 글꼴 크기: 24
1단계 · 배치 4 / 5

4말풍선 입력 칸 놓기

  • 레이아웃 서랍 → 수평배치를 EmojiRow 아래에 놓아요. 이름: SpeechRow
  • 텍스트박스를 SpeechRow 안에 놓아요. 이름: SpeechBox, 힌트: 말풍선 글자 입력
  • 버튼을 오른쪽에 놓아요. 이름: SpeechButton, 텍스트: 넣기
1단계 · 배치 5 / 5

5저장 · 취소 버튼과 알림 놓기

  • 레이아웃 서랍 → 수평배치를 SpeechRow 아래에 놓아요. 이름: BottomRow
  • 버튼 2개를 BottomRow 안에 놓아요: SaveButton(텍스트: 💾 저장), CancelButton(텍스트: ❌ 취소)
  • 사용자 인터페이스 서랍 → 알림 (화면에 안 보임) → 이름 알림1 그대로
  • 미디어 서랍 → 카메라 (화면에 안 보임) → 이름 카메라1 그대로
실수 조심! 표에 적힌 이름 그대로 지어야 2단계 블록에서 부품을 쉽게 찾을 수 있어요.

2단계

블록으로 기능 만들기 (블록)

오른쪽 위 블록 버튼을 눌러 블록 화면으로 이동해요.

블록 조립하는 법
  • 왼쪽 Screen1 목록에서 컴포넌트 이름을 클릭하면 블록 서랍이 열려요.
  • 블록을 끌어서 오른쪽 작업 공간에 놓아요.
  • 가까이 가져가면 딸깍 소리와 함께 자동으로 붙어요.
  • 블록에서 마우스 오른쪽 → 복제하기로 복사할 수 있어요.
2단계 · 블록 준비

⓪ 위치를 기억할 변수 만들기

🟧 변수 서랍
전역변수 만들기 TouchX · 초기값 0
전역변수 만들기 TouchY · 초기값 0

🧠 이모티콘이나 말풍선을 어디에 그릴지 기억해 둘 상자 두 개를 미리 만들어요.

2단계 · 블록 1 / 5

① 사진찍기 기능

🔴 TakePictureButton🔴 카메라1🔵 캔버스1
언제 TakePictureButton.클릭했을때
실행 → 호출 카메라1.사진찍기
언제 카메라1.사진찍은후 (이미지)
실행 → 지정하기 캔버스1.배경이미지 값 ← 가져오기 이미지

📸 버튼을 누르면 카메라가 켜지고, 찍은 사진이 캔버스1의 배경이 돼요.

2단계 · 블록 2 / 5

② 콕 찍은 위치 기억하기

🔵 캔버스1🟧 변수
언제 캔버스1.터치했을때 (x, y, …)
실행 → 지정하기 전역변수 TouchX 값 ← 가져오기 x
그리고 → 지정하기 전역변수 TouchY 값 ← 가져오기 y

👆 사진 위를 콕 찍으면 그 위치가 TouchX·TouchY에 저장돼요.

2단계 · 블록 3 / 5

③ 이모티콘 스티커 붙이기

🔴 BtnStar 등 4개🔵 캔버스1🟩 텍스트
언제 BtnStar.클릭했을때
실행 → 호출 캔버스1.텍스트그리기 (텍스트: "⭐", x: 가져오기 TouchX, y: 가져오기 TouchY)

🎭 이 블록을 복제하기로 복사해서 나머지 3개를 만들고, 이벤트와 글자만 ❤️·👑·😀 로 바꿔주면 끝이에요.

2단계 · 블록 4 / 5

④ 말풍선 넣기 기능

🔴 SpeechButton🔴 SpeechBox🔵 캔버스1
언제 SpeechButton.클릭했을때
실행 → 호출 캔버스1.텍스트그리기 (텍스트: SpeechBox.텍스트, x: 가져오기 TouchX, y: 가져오기 TouchY)

💬 자리를 콕 찍고 글자를 쓴 뒤 버튼을 누르면 그 자리에 글자가 나타나요.

2단계 · 블록 5 / 5

⑤ 저장하기 · 취소하기 기능

🔴 Save/CancelButton🔵 캔버스1🔔 알림1🟤 제어

실행 → 평가하지만 결과 무시하기 ( 호출 캔버스1.저장하기 )
그리고 → 호출 알림1.경고창보이기 (알림: "사진이 저장되었어요! 📸")

💾 저장하기는 값을 돌려주는 블록이라 제어 서랍의 평가하지만 결과 무시하기로 감싸야 해요.

3단계

테스트해요! ✅

스마트폰에 MIT AI2 Companion 앱을 설치하고, 위쪽 메뉴 [연결] → [AI 컴패니언]을 눌러 나오는 QR코드를 찍어요.

🔧 잘 안 될 때는?

이모티콘이나 글자가 안 나타나요.

사진 위를 먼저 콕 찍었는지 확인해요. 안 찍으면 TouchX·TouchY가 0이라 왼쪽 위에 그려질 수 있어요.

스티커나 글자가 너무 작아요.

디자이너에서 캔버스1의 글꼴 크기를 40쯤으로 키워요. 더 크게 하고 싶으면 숫자를 더 올려요.

저장 버튼을 눌러도 메시지가 안 떠요.

저장하기 블록을 평가하지만 결과 무시하기로 잘 감쌌는지 확인해요.

블록에 빨간 느낌표(⚠)가 보여요.

빈 소켓이 있거나 모양이 다른 블록이 끼워진 거예요. 하나씩 확인해요.
