🎨 파이썬 터틀 학습지 · 실습형

코드로 만드는 추상 화가 터틀!

방향키로 터틀을 조종하면서, 화면 위에 무작위로 나타나는 물감을 먹으면 속도가 빨라지고 색과 굵기가 바뀌는 나만의 몬드리안풍 추상화를 파이썬으로 직접 그려봐요.

도망 게임에서 배운 것들을 활용해서, 새로 나오는 부분(while, random 등)은 이미 채워져 있어요. 이번엔 한 단계씩 실행해보면서 결과를 눈으로 확인할 수 있도록, 기능을 하나씩 쌓아가는 순서로 배워요.

🖼 오늘 완성하게 될 작품 미리보기 — 이 그림을 직접 코드로 그려볼 거예요!

1

오늘의 미션

오늘은 화면 위를 계속 스스로 움직이는 터틀이 방향키로 조종되면서, 무작위로 나타나는 물감을 먹을 때마다 색과 굵기가 바뀌는 그림을 그리는 추상화 그리기 게임을 만들어볼 거예요. 오늘은 특별히, 기능을 하나 만들 때마다 바로 실행해서 결과를 눈으로 확인하면서 한 단계씩 쌓아 올라가요.

1
터틀이 화면 위에서 스스로 계속 앞으로 나아가요.
2
방향키(↑↓←→)를 누르면 터틀이 바라보는 방향만 바뀌어요.
3
화면 가장자리(벽)에 닿으면 게임이 끝나고 "오늘의 작품 완성!!"이 나타나요.
4
화면 위 아무 곳에나 물감(paint)이 무작위로 나타나요.
5
물감에 닿으면 색이 바뀌고, 물감이 다시 무작위 위치로 옮겨가요.
6
마지막으로, 물감을 먹을수록 속도가 점점 빨라지고 펜이 점점 굵어져요.
미리 알아두기 — 이 게임에는 "조건이 참인 동안 계속 반복하기(while)", "무작위로 값 고르기(random)", "여러 조건을 한 번에 확인하기(or)" 같은 새로운 도구가 필요해요. 새로 나오는 문법은 필요한 단계에서 이미 코드로 완성해 뒀으니, 여러분은 도망 게임에서 배운 것들을 적용하는 데 집중하면 돼요! 🎨

🎮 미리 체험해보기 — 코딩을 시작하기 전에, 오늘 완성할 게임을 먼저 플레이해보세요. 방향키로 터틀을 조종해서 물감을 먹으며 나만의 추상화를 그려보세요!

계속 앞으로 전진하기

🎯 미션 · 직접 코딩

목표: while 반복문으로 터틀이 화면 위에서 끊임없이 앞으로 나아가게 만듭니다. 지금 만든 반복문은 앞으로 여러 단계에 걸쳐 계속 내용이 추가될 거예요.

🆕 새로 배우는 문법 · while True: 와 무한 반복
while 조건:은 조건이 참인 동안 계속 안의 코드를 반복해요.
while True:는 조건이 항상 참이라서, 사실상 "멈추지 않고 계속" 반복하라는 뜻이에요. (멈추려면 나중에 배울 break가 필요해요.)
도망 게임은 screen.ontimer()로 "0.1초 후 다시 실행"하는 방식이었다면, 이번엔 while로 "계속 반복"하는 다른 방식을 써요.
speed = 3 # 터틀이 앞으로 나아가는 속도 while True: # 여기에 코드를 작성하세요 (현재 방향으로 speed만큼 전진)
생각해 보기
  • 이번엔 딱 한 줄이면 돼요 — 도망 게임에서 배운 forward()와 똑같아요.
  • while True: 아래는 반드시 들여쓰기를 맞춰야 안쪽 코드로 인식돼요.
  • 지금 당장은 방향키가 없어서 터틀이 한쪽으로만 계속 가겠지만, 다음 단계에서 방향을 바꾸는 기능을 추가할 거예요. 지금은 "계속 전진"이 잘 되는지만 확인해보세요.
💡 메서드 힌트 보기
  • 앞으로 이동→t.forward(speed)

기억하기 · 이 while 반복문은 오늘 만들 게임 전체의 뼈대예요. 다음 단계부터는 이 반복문을 지우지 않고, 안쪽에 코드를 한 줄씩 더해가요.

방향키로 터틀 조종하기

🎯 미션 · 직접 코딩

목표: 방향키 4개에 각각 함수를 연결해서, 누른 방향으로 터틀의 머리 방향만 바꿉니다.

도망 게임과 다른 점 하나 — 여기서는 방향키를 눌러도 그 자리에서 바로 이동하지 않아요. 방향만 바뀌고, 실제로 앞으로 가는 건 3단계에서 만든 반복문이 항상 자동으로 계속 해줘요.

def move_up(): t.setheading(90) # 위쪽(90도)을 바라보기 # 여기에 move_down(), move_right(), move_left() 함수를 move_up()처럼 만드세요 # (아래=270도, 오른쪽=0도, 왼쪽=180도) # 키보드 이벤트 연결 t.onkeypress(move_up, "Up") # 여기에 move_down, move_right, move_left도 각각의 방향키와 연결하세요 t.listen() # 키보드 입력을 받기 시작해요
생각해 보기
  • move_up()과 완전히 같은 모양으로, 각도만 바꿔서 move_down(270도), move_right(0도), move_left(180도)를 만들어요.
  • 이 함수들은 forward()를 부르지 않아요 — 방향만 바꾸고, 실제로 앞으로 가는 건 항상 자동으로 실행되는 반복문(3단계)이 담당해요.
  • 함수 4개를 다 만들었다면, 각 방향키와 연결하는 onkeypress() 줄도 4개 필요해요.
  • 맨 마지막 t.listen()은 한 번만 있으면 돼요.
💡 메서드 힌트 보기
  • 방향 딱 정하기→setheading(각도)
  • 키와 함수 연결→onkeypress(함수이름, "Down")

팁 · 방향 키 이름은 "Up", "Down", "Right", "Left"예요. onkeypress()에 함수 이름을 넣을 때는 괄호를 붙이지 않아요.

벽에 닿으면 게임 끝내기

🎯 미션 · 코드 읽고 이해하기

목표: 터틀이 화면 가장자리(벽)에 닿으면 while 반복문을 멈추고 게임을 끝냅니다. 3단계에서 만든 반복문 안에 이어서 코드를 씁니다.

🆕 새로 배우는 함수 · xcor(), ycor(), or로 조건 잇기, break
t.xcor()과 t.ycor()은 지금 터틀의 x좌표, y좌표를 숫자로 알려줘요.
조건A or 조건B는 "둘 중 하나라도 참이면" 전체가 참이 돼요. 네 방향(오른쪽·왼쪽·위·아래) 벽 중 아무거나 닿아도 게임이 끝나야 하니까, 네 조건을 or로 모두 연결해요.
break는 반복문(while)을 그 자리에서 바로 멈추고 빠져나가는 명령이에요. while True:는 원래 영원히 반복되지만, break를 만나면 그 즉시 멈춰요.
이 세 가지는 오늘 처음 배우는 문법이라 코드에 이미 완성되어 있어요. 코드를 천천히 읽으면서 "왜 이렇게 쓰는지" 이해해보세요!
speed = 3 while True: # (아래 전진 코드는 3단계에서 이미 완성했어요) t.forward(speed) # 벽에 닿으면 게임 종료 if (t.xcor() > 230 or t.xcor() < -230 or t.ycor() > 230 or t.ycor() < -230): break
생각해 보기
  • 이번 단계는 빈칸이 없어요! 대신 코드를 천천히 읽고, or로 연결된 네 조건이 각각 어떤 벽(오른쪽·왼쪽·위·아래)을 확인하는지 짚어보세요.
  • 지금 실행해보면, 방향키로 조종하다가 벽에 닿는 순간 프로그램이 멈추는 걸 바로 확인할 수 있어요. (아직 물감은 없지만, "벽에 닿으면 끝난다"는 동작 자체는 이미 완성이에요!)
  • 숫자 230을 100으로 바꾸면 어떻게 될까요? 게임이 더 빨리 끝날까요, 천천히 끝날까요? 직접 바꿔서 실험해보세요.
💡 메서드 힌트 보기
  • x좌표 구하기→t.xcor()
  • y좌표 구하기→t.ycor()
  • 여러 조건 중 하나라도→조건A or 조건B
  • 반복문 즉시 멈추기→break

xcor()/ycor()가 하는 일 · 터틀이 지금 있는 위치의 x, y 좌표를 각각 숫자로 알려줘요. 이 값이 -230보다 작거나 230보다 크면 화면 밖(벽)으로 나가려는 거예요.

6

물감 터틀 만들고 무작위로 움직이기

🎯 미션 · 직접 코딩

목표: paint라는 이름의 동그란 거북이를 만들어 펜을 들게 하고, 색상 목록에서 무작위로 색을 골라 물감을 화면 아무 곳에나 이동시키는 함수를 완성합니다.

🆕 새로 배우는 함수 · random.choice(), random.randint()
random.choice(리스트)는 리스트 안에 있는 값 중 하나를 무작위로 골라줘요. random.choice(color_list)라고 쓰면 색상 목록에서 색 하나를 무작위로 뽑아요.
random.randint(최소, 최대)는 그 범위 안(양 끝 포함)에서 무작위 정수 하나를 돌려줘요. random.randint(-230, 230)이면 -230부터 230 사이의 아무 정수예요.
이 두 함수를 조합하면, "화면 안 아무 곳"에 물감을 놓거나 "색상 목록 중 아무 색"을 고를 수 있어요.
# 맨 위 첫 줄에 코드를 추가하세요 (import random) color_list = [ "red", "green", "orange", "pink", "brown", "skyblue", "violet" ] color = "black" # 현재 사용할 펜 색 # ----------------------- # 물감 객체 만들기 # ----------------------- # 여기에 코드를 작성하세요 (paint라는 이름으로 거북이를 만들고, 모양은 "circle", 펜은 들기) # ----------------------- # 물감을 새로운 위치로 이동 # ----------------------- def paint_move(): global color # 함수 밖의 color 변수를 사용 # 색상 목록에서 색을 하나 랜덤으로 선택 (새로 배우는 random.choice()) color = random.choice(color_list) # 여기에 코드를 작성하세요 # (물감의 색을 color로 바꾸고, 물감을 (random.randint(-230,230), random.randint(-230,230))로 이동) paint_move() # 처음 물감 위치 정하기
생각해 보기
  • 오늘 처음으로 random 모듈을 쓰기 때문에, 파일 맨 위 첫 줄에 import random을 추가해야 해요. (import turtle as t 바로 위나 아래 줄이면 돼요.)
  • paint = t.Turtle()로 새 거북이를 만들고, 모양은 "circle", 그리고 펜은 들어요(up()) — 도망 게임의 enemy를 만들 때와 순서가 같아요.
  • 물감 색을 바꾸는 명령(color())과 위치를 옮기는 명령(goto())도 도망 게임에서 이미 배운 것들이에요.
  • 좌표 자리에 random.randint(-230, 230)을 x, y 각각에 한 번씩 넣으면 화면 안 무작위 위치가 돼요.
  • 이 단계까지 실행해보면, 물감이 화면에 나타나긴 하지만 아직 터틀이 물감을 "먹는" 반응은 없어요. 그건 다음 단계에서 만들어요.
💡 메서드 힌트 보기
  • 새 거북이 만들기→t.Turtle()
  • 모양 정하기→shape("circle")
  • 펜 들기→up()
  • 색 바꾸기→color(색이름)
  • 이동하기→goto(x, y)
  • 무작위 값 고르기→random.choice(리스트) / random.randint(최소, 최대)

기억하기 · global color가 맨 위에 있어서, 함수 안에서 color = random.choice(color_list)처럼 바깥 변수 값을 바꿔도 잘 동작해요. 도망 게임의 global playing과 같은 이유예요.

물감 먹으면 처리하기

🎯 미션 · 직접 코딩

목표: 터틀과 물감 사이의 거리를 계산해서 가까워지면 물감을 먹은 것으로 처리합니다. 펜 색을 물감 색으로 바꾸고, 물감을 새로운 자리로 옮겨요. 3단계에서 만든 반복문 안, 전진 코드와 벽 검사 코드 사이에 이어서 씁니다.

speed = 3 while True: t.forward(speed) # (이미 완성) # 터틀과 물감 사이의 거리가 20보다 작으면 물감을 먹은 것 if t.distance(paint) < 20: # 여기에 코드를 작성하세요 (펜 색을 color로 바꾸기) # 여기에 코드를 작성하세요 (물감을 새로운 위치로 이동시키는 함수 호출) # 벽에 닿으면 게임 종료 (이미 완성) if (t.xcor() > 230 or t.xcor() < -230 or t.ycor() > 230 or t.ycor() < -230): break
생각해 보기
  • if t.distance(paint) < 20:은 이미 완성되어 있어요. 그 안의 빈 곳엔 색 바꾸기(color())와, 물감을 다시 배치하는 함수 호출(paint_move())만 채우면 돼요.
  • t.color(color)의 color는 6단계에서 paint_move()가 랜덤으로 골라둔 바로 그 색이에요. 함수 이름 color가 아니라 변수 color를 그대로 넣는 거예요.
  • 지금 실행해보면, 물감에 닿을 때마다 펜 색이 바뀌고 물감이 다른 자리로 옮겨가는 걸 확인할 수 있어요. 속도가 빨라지거나 펜이 굵어지는 건 마지막 단계에서 추가해요.
💡 메서드 힌트 보기
  • 거리 구하기→t.distance(paint)
  • 색 바꾸기→t.color(color)
  • 함수 호출하기→paint_move()

마지막 단계 · 속도 점점 빠르게, 펜 점점 굵게

🎯 미션 · 직접 코딩

목표: 물감을 먹을 때마다 speed를 조금씩 늘리고, 펜 굵기를 무작위로 바꿔서 그림이 점점 크고 대담해지게 만듭니다. 7단계에서 완성한 물감 처리 코드 안에 이어서 씁니다.

🆕 새로 배우는 문법 · 복합 대입 연산자(+=), pensize(random.randint())
speed += 0.5는 speed = speed + 0.5와 같아요. 지금 값에 0.5를 더해서 다시 저장하는 복합 대입 연산자예요.
t.pensize(굵기)는 펜 굵기를 정해요. 굵기 자리에 random.randint(3, 10)을 넣으면 3~10 사이 무작위 굵기가 돼요.
speed = 3 while True: t.forward(speed) if t.distance(paint) < 20: t.color(color) # (7단계에서 이미 완성) # 여기에 코드를 작성하세요 (speed에 0.5를 더해서 다시 저장하기) # 여기에 코드를 작성하세요 (펜 굵기를 3~10 사이 무작위 정수로 바꾸기) paint_move() # (7단계에서 이미 완성) if (t.xcor() > 230 or t.xcor() < -230 or t.ycor() > 230 or t.ycor() < -230): break
생각해 보기
  • speed += 0.5 한 줄이면 속도가 물감을 먹을 때마다 0.5씩 계속 늘어나요.
  • t.pensize(random.randint(3, 10))처럼 pensize() 안에 바로 random.randint()를 넣을 수 있어요.
  • 이제 실행해보면, 물감을 많이 먹을수록 터틀이 점점 빨라지고 그림선도 점점 굵어지는 걸 확인할 수 있어요 — 오늘 만든 게임의 핵심 재미 포인트예요!
💡 메서드 힌트 보기
  • 값 더해서 저장→speed += 0.5
  • 펜 굵기 바꾸기→pensize(random.randint(3, 10))

기억하기 · +=는 "지금 값 + 오른쪽 값"을 다시 왼쪽 변수에 저장해요. speed = speed + 0.5라고 풀어 써도 똑같이 동작해요.

게임 종료 처리하기

🎯 미션 · 직접 코딩

목표: 이제 게임의 모든 기능이 완성되었어요! 마지막으로 게임이 끝나면(벽에 닿아 while 반복문을 빠져나오면) 물감을 숨기고, 화면 아래쪽에 완성 메시지를 씁니다.

🆕 새로 배우는 함수 · t.done()
t.done()은 도망 게임의 turtle.mainloop()과 같은 역할을 해요 — 창을 닫지 않고 계속 열어둬요.
모듈 스타일(import turtle as t)에서는 mainloop() 대신 done()이라는 이름을 더 자주 써요. 맨 마지막 줄에 이미 완성해 뒀어요.
# ----------------------- # 게임 종료 (while 반복문을 빠져나온 뒤 실행됨) # ----------------------- # 여기에 코드를 작성하세요 (물감(paint) 숨기기) # 여기에 코드를 작성하세요 # (펜을 들고 (0, -220)으로 이동한 뒤, "오늘의 작품 완성!!"을 가운데 정렬로 크게 쓰기) t.done() # 창을 닫지 않고 계속 열어두기 (turtle.mainloop()과 같은 역할 · 이미 완성)
생각해 보기
  • 물감을 숨기는 명령은 도망 게임의 pen.ht()와 같아요. hideturtle() 또는 줄임말 ht()를 쓰면 돼요.
  • 펜 들기 → 이동하기 → 글씨 쓰기 순서도 이미 배운 그대로예요. 글자는 "오늘의 작품 완성!!", 위치는 (0, -220), font는 ("나눔바른펜", 20, "normal")을 쓰세요.
  • 드디어 완성! 이제 방향키로 조종하며 물감을 먹고, 벽에 닿으면 완성 메시지가 뜨는 나만의 추상화 게임이 끝까지 동작해요.
💡 메서드 힌트 보기
  • 거북이 숨기기→hideturtle() / ht()
  • 펜 들기→penup() / up()
  • 이동하기→goto(x, y)
  • 글씨 쓰기→write("글자", align="center", font=(...))

기억하기 · t.penup()으로 펜을 들지 않으면, 글씨를 쓸 위치로 이동하는 동안에도 선이 그려져서 그림을 망칠 수 있어요.
