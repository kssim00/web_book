1

사전이 뭐예요?

국어사전을 펼치면 단어가 있고, 그 옆에 뜻이 적혀 있어요. 파이썬 딕셔너리도 똑같아요!

📖 국어사전

사과빨갛고 동그란 과일
기린목이 아주 긴 동물
우산비 올 때 쓰는 물건

🐍 파이썬 사전(딕셔너리)

"사과": "빨갛고 동그란 과일"
"기린": "목이 아주 긴 동물"
"우산": "비 올 때 쓰는 물건"
기억하기 — 딕셔너리에서는 단어를 키(key)라고 부르고, 뜻을 값(value)이라고 불러요. 키와 값은 항상 짝꿍으로 붙어 다녀요!
2

사전 만들기 — 중괄호 { }

파이썬에서 사전을 만들 때는 중괄호 { } 를 사용해요. 그 안에 "키: 값"을 콤마(,)로 이어서 써요.

animal = {"강아지": "멍멍", "고양이": "야옹"}
읽는 법 — "animal이라는 사전을 만드는데, '강아지'의 뜻은 '멍멍'이고, '고양이'의 뜻은 '야옹'이야!" 라고 읽으면 돼요.
3

단어 찾기 — 대괄호 [ ]

사전에서 단어를 찾듯이, 딕셔너리에서도 키를 이용해서 값을 찾을 수 있어요. 이때는 대괄호 [ ] 를 사용해요.

animal = {"강아지": "멍멍", "고양이": "야옹"} print(animal["강아지"])
실행 결과멍멍
주의! 사전에 없는 단어를 찾으면 파이썬이 "그런 단어 없어요!" 라고 에러를 내요. 꼭 있는 단어만 찾아보세요.
4

새 단어 추가하기

사전에 없던 새 단어를 추가하고 싶다면, 그냥 새로운 키에 값을 넣어주면 자동으로 추가돼요!

animal = {"강아지": "멍멍"} animal["오리"] = "꽥꽥" print(animal)
실행 결과{'강아지': '멍멍', '오리': '꽥꽥'}
5

단어의 뜻 바꾸기

이미 있는 단어의 뜻을 바꾸고 싶다면, 같은 방법으로 값을 다시 넣어주면 돼요. 이번엔 새로 생기는 게 아니라 덮어써져요.

animal = {"강아지": "멍멍"} animal["강아지"] = "왈왈" print(animal)
실행 결과{'강아지': '왈왈'}
비교하기 — 새 키를 넣으면 추가, 있던 키를 넣으면 수정! 파이썬이 알아서 구분해줘요.
6

단어 지우기 — del

사전에서 단어를 지우고 싶을 땐 del 이라는 명령어를 써요. del은 "지워라!"라는 뜻이에요.

del animal["강아지"] print(animal)
실행 결과{'오리': '꽥꽥'}
7

사전 전부 보기 — for 반복문

사전에 있는 모든 단어와 뜻을 하나씩 보여주고 싶다면 for 반복문을 사용해요.

animal = {"강아지": "멍멍", "고양이": "야옹", "오리": "꽥꽥"} for word in animal: print(word, ":", animal[word])
실행 결과강아지 : 멍멍 고양이 : 야옹 오리 : 꽥꽥
기억하기 — for문은 사전 안에 있는 단어(키)들을 한 번씩 순서대로 꺼내줘요. 마치 사전을 처음부터 끝까지 넘겨보는 것처럼요!
8
