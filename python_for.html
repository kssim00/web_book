PYTHON · 반복문

for문,
값을 하나씩 꺼내 반복하기

for문이란?

값을 하나씩 꺼내면서 같은 코드를 반복할 때 사용해요.

예를 들어 출석부의 이름 30개를 차례대로 읽을 수 있어요.

for문의 핵심 구조

반복변수에 목록의 다음 값이 들어갈 때마다 코드 1과 코드 2를 순서대로 실행해요.

for 반복변수 in 목록:
    실행할 코드 1
    실행할 코드 2
CONCEPT

01for문의 기본 구조

가장 많이 사용하는 range() 함수로 숫자를 반복하는 기본 형태입니다.

for i in range(3):
    print(i)

# 반복문이 끝난 후 실행됩니다. (들여쓰기 없음)
print("끝!")

04숫자 범위 다루기: range()

range(시작, 끝, 간격)을 사용해요. 끝 숫자는 포함되지 않아요.
간격을 생략하면 기본값은 1이에요.

시작값과 끝값만 지정하기

range(5, 10)은 5부터 1씩 세고, 10에 도달하기 전에 멈춰요.

for i in range(5, 10):
    print(i, end=" ")

2씩 건너뛰며 세기

range(1, 11, 2)는 1부터 2씩 커져요.

for i in range(1, 11, 2):
    print(i, end=" ")

5부터 1까지 거꾸로 세기

range(5, 0, -1)은 5부터 1씩 작아져요.

for i in range(5, 0, -1):
    print(i, end=" ")

05누적 합계

for문으로 숫자를 하나씩 더해서 합계를 구할 수 있습니다. 합계를 담을 변수를 먼저 0으로 준비하는 게 핵심입니다.

total = 0             # 합계를 담을 변수, 반드시 0으로 시작

print(total)          # 15

07별 찍기

for문과 print()를 조합하면 다양한 패턴을 만들 수 있습니다. '*' * n은 별이 n개 들어 있는 문자열을 만들어요.

1. 계단 모양 별 찍기

★ ★★ ★★★ ★★★★ ★★★★★
for i in range(1, 6):
    print('*' * i)
💡 별이 한 개씩 늘어나는 이유 계단 모양에서는 한 줄에 찍는 별이 1개부터 5개까지 하나씩 늘어나요. 그래서 range(1, 6)으로 i가 1부터 5까지 증가하도록 했어요.

2. 역삼각형 별 찍기

★★★★★ ★★★★ ★★★ ★★ ★

역삼각형은 반대로 i가 감소해야 합니다. range()의 세 번째 인자를 음수로 사용합니다.

🔍 핵심 비교

모양 range() i의 변화 출력
계단 ▲ range(1, 6) 1 → 2 → 3 → 4 → 5 * → ** → *** → ****→ *****
역삼각형 ▽ range(5, 0, -1) 5 → 4 → 3 → 2 → 1 ***** → **** → *** → ** → *

실행 결과를 확인하고, range() 값이 어떻게 바뀌는지 관찰해보세요:

# i가 5부터 1까지 -1씩 줄어듭니다
for i in range(5, 0, -1):
    print(f"i={i} → ", '*' * i)

08break & continue

반복 중간에 흐름을 제어할 수 있습니다. break는 반복을 즉시 끝내고, continue는 이번 반복에서 남은 코드를 건너뛰고 다음 반복으로 넘어가요.

break — 3을 만나면 반복이 끝나요.

for i in range(1, 6):
    if i == 3:
        break
    print(i, end=" ")

continue — 3을 건너뛰고 다음 반복으로 넘어가요.

for i in range(1, 6):
    if i == 3:
        continue
    print(i, end=" ")

break 동작 원리 이해

break는 반복문을 즉시 탈출시킵니다. 원하는 것을 찾았을 때 더 이상 탐색을 계속할 필요가 없을 때 사용합니다.

🔍 break가 없을 때 vs 있을 때

❌ break 없이 전부 탐색

시도: 1234 ❌
시도: abcd ❌
시도: secret ✅
시도: hello ← 불필요한 탐색!

✅ break로 즉시 탈출

시도: 1234 ❌
시도: abcd ❌
시도: secret ✅
→ 즉시 반복 종료!

코드에서 break가 어느 시점에 실행되는지 확인해보세요:

passwords = ['1234', 'abcd', 'secret', 'hello']
answer = 'secret'

for pw in passwords:
    print('시도:', pw)
    if pw == answer:
        print('✅ 비밀번호 일치! 탐색 종료')
        break               # ← 여기서 반복문 탈출
print('반복문 이후 코드')   # break 후에도 이 줄은 실행됨
