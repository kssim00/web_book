CHAPTER 02. 입출력과 자료형

3. 입력 input()

input()으로 사용자에게 값을 입력받아요.
입력받은 값의 자료형은 문자열(str)이에요.

1) input() 사용하기

사용자에게 입력 받을 메세지를 넣고, 그 대답을 변수에 저장합니다.

1. 입력받고 출력하기

사용자가 입력한 값을 name 변수에 저장합니다.

name = input("이름을 입력하세요: ") # 사용자의 입력을 기다립니다. print(name, "님, 반가워요!")

2. 안내 메시지 비교하기

input()에 안내 문장을 넣으면 무엇을 입력할지 알려 줄 수 있어요. 괄호를 비워도 입력은 받아요.

안내 메시지가 있는 경우

food = input("오늘 점심 뭐 먹었나요? ") print(food, "맛있었겠네요!")

안내 메시지가 없는 경우

color = input() # 안내 문장 없이 입력을 기다려요. print(color, "색을 좋아하시는군요.")

3. 입력값을 숫자로 바꾸기

숫자를 입력해도 input()은 문자열로 받아요.
age = input()에서 16을 입력하면, age에는 문자열 "16"이 저장돼요.

age = input("나이를 입력하세요: ") print(age + 1) # 에러 발생
❌ 왜 에러가 날까요?

age는 문자열이에요. 문자열과 정수 1은 바로 더할 수 없어요.

입력받은 나이에 1을 더하려면 int()로 정수로 바꿔요.

age = int( input("나이를 입력하세요: ") ) print("내년에는", age + 1, "살이 되네요!")

키는 165.5처럼 소수점이 있을 수 있어서 float()로 실수로 바꿔요.

height = float(input("키를 입력하세요: ")) print("당신의 키는", height, "cm입니다.")

2) 한 줄에 여러 값 입력받기

split()을 쓰면 한 줄에 입력한 값을 공백 기준으로 나눌 수 있어요.

1. split()로 여러 값 입력받고 정수로 변환하기

10 20을 입력하면 split()이 ['10', '20']으로 나눠요. 이렇게 값을 묶어 놓은 것을 리스트라고 해요. 두 값을 변수에 하나씩 담을 수 있어요.

# 예: 10 20 입력 a, b = input().split() print("a:", a, "/ b:", b) print(type(a)) print(a + b) # a, b는 문자열이라 숫자처럼 더해지지 않고 그대로 이어붙는다 (예: "10"+"20" → "1020")
⚠️ 값과 변수의 개수 맞추기

나눈 값의 개수와 변수의 개수가 같아야 해요. 10 20이면 변수 2개, 10 20 30이면 변수 3개가 필요해요.

이때 a, b에 저장된 값은 문자열(str)입니다. 숫자로 계산하려면 각각 int()로 변환해야 합니다.

# 예: 10 20 입력 width, height = input().split() width = int(width) height = int(height) print("가로:", width, "세로:", height) print("넓이:", width * height) # width, height를 int로 변환했으므로 문자열 연결이 아니라 실제 곱셈 계산이 된다

가로와 세로를 int()로 변환했기 때문에 width * height가 문자열 연결이 아니라 실제 숫자 곱셈으로 계산되어 넓이를 구할 수 있습니다.

2. map() 함수로 한 번에 형변환하기

map(int, input().split())을 쓰면 공백으로 나눈 모든 값에 int()를 적용해요.

# 예: 10 20 입력 a, b = map(int, input().split()) print(a + b)
💡 map()을 쓸 때도 같아요

map()으로 바꾼 값도 변수 개수만큼 입력해야 해요.
