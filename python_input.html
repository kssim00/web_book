3. 입력 input()

input() 명령어는 사용자로부터 데이터를 입력 받을 수 있다.

입력 받은 모든 데이터는 기본적으로 문자열(str)임을 주의해야 한다.

1) input() 사용하기

사용자에게 입력 받을 메세지를 넣고, 그 대답을 변수에 저장합니다.

1. 입력받고 출력하기

사용자가 입력한 값을 name 변수에 저장합니다.

name = input("이름을 입력하세요: ") # 사용자의 입력을 기다립니다. print(name, "님, 반가워요!")

2. 안내 메시지 없이 입력받기

괄호 안에 글자(안내 메세지)를 넣어 친절하게 안내를 할 수 있습니다. 하지만 괄호 안을 비워두면 아무런 메시지 없이 커서만 깜빡이며 입력을 기다리게 됩니다.

# 예시 1: 친절한 프로그램 print("--- 프로그램 A ---") food = input("오늘 점심 뭐 먹었나요? ") print(food, "맛있었겠네요!") # 예시 2: 불친절한 프로그램 print("--- 프로그램 B ---") color = input() # 아무 창도 뜨지 않지만 입력을 기다리고 있어요! print(color, "색을 좋아하시는군요.")

2) input()의 반환값은 '문자'다!

input()으로 들어온 것이 숫자인지 글자인지 구분하지 못하고 모두 문자열로 취급합니다.

age = input("나이를 입력하세요: ") print(age + 1) # ❌ 에러 발생! (문자와 숫자는 더할 수 없어요)

input()으로 숫자를 입력하면 정수형(int)으로 변환해야 계산할 수 있습니다.

# 정수로 바꾸기 age = int( input("나이를 입력하세요: ") ) print("내년에는", age + 1, "살이 되네요!") # 실수를 입력받을 때 height = float(input("키를 입력하세요: ")) print("당신의 키는", height, "cm입니다.")
