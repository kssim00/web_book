while문이란?

조건이 참인 동안 같은 코드를 반복할 때 사용해요.

예를 들어 비밀번호가 틀리는 동안 다시 입력받을 수 있어요.

while문의 핵심 구조

반복할 때마다 먼저 조건을 확인하고, 거짓이면 반복을 끝내요.

while 조건:
    실행할 코드

01while문의 기본 구조

i를 1부터 세어요. i가 4가 되면 조건이 거짓이라 멈춰요.

    i += 1

2

3

증가식

i += 1

매 반복마다 변수를 바꿔줌

⚠️ 주의하세요이 예제에서 i += 1을 빼면 i가 계속 1이라 반복이 끝나지 않아요.

02데이터의 끝을 알리는 보초값(Sentinel)

반복 횟수를 아는 경우"1부터 10까지 출력해" → 횟수가 정해져 있어서 while 조건으로 바로 제어할 수 있어요.
반복 횟수를 모르는 경우 → 보초값 필요!"점수를 계속 입력받아" → 몇 개 입력할지 몰라요. 특별한 값을 입력하면 멈추도록 약속해야 해요.

아래 코드는 몇 번 반복할지 미리 정해져 있지 않아요. 어떻게 동작할까요?

score = int(input("점수 입력(-1 종료): "))

while score != -1:
    print("입력된 점수:", score)
    score = int(input("점수 입력(-1 종료): "))

print("입력 종료!")
💡 기억해요반복 횟수를 미리 알 수 없을 때, 특별한 값을 입력하면 반복을 멈추도록 약속해요.
이 특별한 값을 보초값(Sentinel)이라고 해요. 보초값은 처리할 데이터와 겹치지 않는 값으로 정해요.

보초값을 선택하는 원칙을 정리하면 다음과 같아요.

상황실제 데이터 범위적합한 보초값
시험 점수 입력0 ~ 100-1 (범위 밖)
주사위 숫자 입력1 ~ 60 또는 7 (범위 밖)
상품 가격 입력0 이상-1 (음수)
⚠️ 왜 while 전에 먼저 input을 받나요?while 조건에서 score를 비교하려면 score가 이미 선언되어 있어야 해요. 처음부터 값이 없으면 NameError가 나요.

04흐름 제어: break & continue

두 코드의 결과를 비교해보세요. i == 3일 때 어떤 차이가 있나요?

break — 3을 만나는 순간 반복이 완전히 끝나요.

i = 0
while i < 5:
    i += 1
    if i == 3:
        break
    print(i)
print("반복 끝")

continue — 3만 건너뛰고 반복은 계속돼요.

i = 0
while i < 5:
    i += 1
    if i == 3:
        continue
    print(i)
print("반복 끝")
💡 기억해요break: 반복문을 완전히 종료해요.
continue: 남은 코드를 건너뛰고 다음 반복으로 넘어가요.

05무한 루프 (Infinite Loop)

아래 코드는 어떻게 종료될까요?

while True:
    code = input("암호를 입력하세요: ")
    if code == "1234":
        print("정답! 탈출!")
        break
    print("틀렸습니다. 다시 입력하세요.")
💡 기억해요while True:로 일부러 무한 반복을 만들고, 원하는 조건이 되면 break로 탈출하는 패턴이에요.
몇 번 반복할지 미리 알 수 없을 때 주로 사용해요.

while 조건식 — 끝나는 시점이 처음부터 정해진 경우

i = 1
while i <= 10:
    print(i)
    i += 1

while True + break — 끝나는 시점을 실행 중에 판단하는 경우

while True:
    pw = input()
    if pw == "1234":
        break

07while — else

두 코드를 비교해보세요. else가 언제 실행되고, 언제 실행되지 않나요?

조건이 False가 되어 정상 종료 → else 실행

i = 1
while i <= 3:
    print(i)
    i += 1
else:
    print("정상 종료")

break로 탈출 → else 실행되지 않음

i = 1
while i <= 3:
    if i == 2:
        break
    print(i)
    i += 1
else:
    print("정상 종료")
💡 기억해요else는 while 조건이 False가 되어 정상 종료될 때 실행돼요.
break로 탈출하면 else가 실행되지 않아요. 이 차이가 핵심이에요!
