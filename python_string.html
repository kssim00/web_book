CHAPTER 03. 문자열과 리스트

1. 문자열

문자열은 따옴표(' 또는 ")로 감싸진 글자들의 모임을 말합니다. 

a = "Hello World" # 큰따옴표 b = 'Python' # 작은따옴표 c = "123" # 이것은 숫자가 아니라 '문자열'입니다! print( type(c) ) # <class 'str'>

1) 문자열이란?

1. 다양한 문자열 만들기

숫자 또는 True/False라도 따옴표 안에 있으면 '문자'로 취급합니다.

print( type('3+2=5') ) print( type("python") ) print( type("False") ) print( type('"참"') ) print( type("^_^") )

2) 문자열 연산

문자열도 숫자처럼 더하거나(+) 곱할 수(*) 있습니다.

1. 연결 연산자 (+) : 문자끼리 이어 붙이기

연결 연산자(+)는 문자들을 공백 없이 연결할 수 있습니다.

first = "파이썬" second = "코딩하자!" print(first + second) # 연결 연산자(+) 사용하여 출력 print(first, second) # 인수(,)로 구분하여 출력하면 공백이 생긴다

공백 없이 연결되기 때문에 필요하면 공백을 추가해야 합니다.

first = "파이썬" second = "코딩하자!" print(first + " " + second) # 연결 연산자(+) 사용하여 공백 추가

⚠️ 주의! : 문자열과 숫자를 연결 연산자(+)를 사용할 경우 에러가 발생합니다.

math = 100 print("수학은 " + math + "점입니다.") # 문자+숫자+문자 : 에러 발생

❇️ 문자열과 숫자를 연결할 때는 숫자를 문자열로 변환해야 합니다!!!

math = 100 print("수학은 " + str(math) + "점입니다.")

2. 반복 연산자 (*) : 문자열을 반복하기

반복 연산자(*)는 문자열을 횟수만큼 반복하여 연결할 수 있습니다.

laugh = "ㅋ" print(laugh * 5) # 출력 결과: ㅋㅋㅋㅋㅋ print(5 * laugh) # 출력 결과: ㅋㅋㅋㅋㅋ

3) 문자열 인덱싱(위치)

문자열에서 글자의 위치를 나타내는 번호를 인덱스라고 해요. 앞에서 셀 때는 0부터 시작해요.
대괄호 [ ]에 인덱스를 넣어 글자 하나를 꺼내는 것을 인덱싱이라고 해요.

1. 인덱스로 출력하기

대괄호[ ] 안에 인덱스를 넣어 해당 문자를 출력할 수 있으며, 첫 문자의 인덱스는  0부터 시작합니다.

word = "Hello World!" print(word[0]) # H print(word[5]) # 공백도 하나의 문자 print(word[11]) # !

2. 뒤에서부터 인덱싱하기

 맨 마지막에서부터 거꾸로 인덱싱할 때는 -1부터 시작합니다.

# 음수 인덱스 print("hello world!"[-1]) print("hello world!"[-6])

3. ⚠️인덱스 에러(IndexError) 주의!

인덱스는 항상 0부터 시작합니다.  범위를 벗어난 인덱스를 사용하면 IndexError: string index out of range(범위를 벗어남) 가 발생함을 주의하세요!! 

예를 들면, 5층짜리 건물인데 "6층에 있는 사람을 불러와"와 같은 명령입니다.

word = "PYTHON" # P(0) Y(1) T(2) H(3) O(4) N(5) -> 번호는 5번까지만 있어요! print(word[5]) # ✅ "N"이 잘 출력돼요. print(word[6]) # ❌ IndexError 발생! (6번 글자는 없음)

6) 슬라이싱 간격 지정하기

슬라이싱에서 간격은 글자를 꺼낼 때 몇 칸씩 이동할지 정해요. 예를 들어 간격이 2이면 시작 위치의 글자를 먼저 꺼내고, 오른쪽(→)으로 두 칸씩 이동하며 다음 글자를 꺼내요.

1. 간격 지정하기

[시작:끝:간격]에서 간격은 몇 칸씩 이동할지 정해요. 생략하면 오른쪽(→)으로 한 칸씩 이동해요.

word = "hello world!" print(word[1:10:3])
word = "hello world!" print(word[1:10:2]) print(word[::2])

2. 음수 간격 지정하기

간격이 음수이면 시작 위치부터 왼쪽(←)으로 거꾸로 읽어요. 그래서 꺼낸 글자의 순서가 뒤집혀요.
이때 끝 위치는 시작 위치보다 왼쪽에 있어야 해요.

word = "hello world!" print(word[10:5:-1])
word = "hello world!" print(word[10:5:-2])

① 끝을 비우면

맨 왼쪽의 첫 글자까지 읽어요.

word = "hello world!" print(word[4::-1])

② 시작을 비우면

맨 오른쪽의 마지막 글자부터 읽어요.

word = "hello world!" print(word[:5:-1])
⚠️ 문자열 전체 뒤집기

문자열 전체를 뒤집을 때는 시작과 끝을 비우고 간격에 -1을 써요.

word = "hello world!" print(word[::-1])

7) 문자열 관련 메서드

문자열 메서드는 문자열.메서드()처럼 점을 찍어 사용해요. 메서드를 실행해도 원래 문자열은 그대로예요. 돌려받은 결과를 나중에도 쓰려면 변수에 저장해요.

1. 대소문자 바꾸기 (upper, lower)

같은 문자열로 메서드를 호출할 때와 결과를 변수에 다시 저장할 때를 비교해 봐요.

upper()는 대문자로 바꾼 새 문자열을 돌려줘요. text.upper()만 호출하면 text에 저장된 원래 값은 그대로예요.

text = "Python Is Fun" text.upper() print(text)

text의 값을 바꾸고 싶으면 text = text.upper()처럼 돌려받은 결과를 다시 저장해요.

text = "Python Is Fun" text = text.upper() print(text)

lower()는 소문자로 바꾼 문자열을 돌려줘요. text.lower()의 결과를 출력하면 소문자가 나오지만, text에 저장된 원래 값은 그대로예요.

text = "Python Is Fun" print(text.lower())

2. 문자 위치 찾기 (find, index)

find()와 index()는 찾는 글자가 처음 나오는 위치(인덱스)를 알려 줘요. 찾는 글자가 없으면 find()는 -1을 돌려주고, index()는 ValueError를 일으켜요.

msg = "banana" print(msg.find("n")) # n이 몇 번 인덱스에 처음 나올까? -> 2 print(msg.index("n")) # 2 print(msg.find("z")) # 없는 글자를 찾으면 -1을 돌려줘요!

3. 문자 개수 세기 (count)

count()는 찾는 글자가 몇 번 나오는지 세어요. 글자가 없으면 0을 돌려줘요.

msg = "banana" print(msg.count("a")) # 3 print(msg.count("z")) # 0

4. 문자열 바꾸기 (replace)

replace()는 지정한 부분을 바꾼 문자열을 돌려줘요. 예제처럼 바뀐 문자열을 변수에 저장해서 사용할 수 있어요.

school = "코딩 중학교" new_school = school.replace("중학교", "고등학교") print(new_school) # 코딩 고등학교

인덱스로 한 글자만 골라 직접 바꿀 수 없어요. 예를 들어 a[1] = "o"처럼 쓰면 TypeError가 발생해요.

a = 'cide' a[1] = 'o' # 문자열은 인덱싱으로 수정이 안돼요!! 에러발생

5. 양쪽 공백 지우기 (strip)

문자열의 양쪽 끝 또는 한쪽 끝에 있는 공백 문자(스페이스, 탭 \t, 줄바꿈 \n 등)를 제거할 수 있어요.
  strip() : 양쪽 끝의 모든 공백을 제거합니다. (가장 많이 사용!)
  lstrip() : 왼쪽(Left) 끝의 공백만 제거합니다.
  rstrip() : 오른쪽(Right) 끝의 공백만 제거합니다.

text = " 안녕하세요 " print("원본:" + text + "|") print(text.lstrip() + "|") # 왼쪽 공백 제거 print(text.rstrip() + "|") # 오른쪽 공백 제거 print(text.strip() + "|") # 양쪽 모두 제거
💡
strip() 
strip()은 '양 끝'의 공백만 제거하며, '가운데'에 있는 공백은 제거하지 않습니다.
만약 문장 사이사이의 모든 공백을 없애고 싶다면 replace() 메서드를 사용해야 합니다.
➡️ 예) text.replace(" ", "")
text = " Hello Python " # 양 끝 공백만 제거 print("[" + text.strip() + "]")

strip()은 공백뿐만 아니라 괄호 안에 특정 문자를 넣으면 그 문자를 제거할 수도 있습니다.

msg = "###중요한 소식!!!" print(msg.strip("#!")) # 양 끝에 있는 #과 !를 모두 지워줘!

6. 문자열 나누기 (split)

괄호를 비운 split()은 공백을 기준으로 문자열을 나눠요. 공백이 여러 칸 이어져도 한 번만 나누고, 결과는 리스트로 돌려줘요.

hobby = "축구 농구 야구" print(hobby.split()) # ['축구', '농구', '야구']

괄호 안에 구분할 문자열을 넣을 수도 있어요. split("-")처럼 쓰면 하이픈을 기준으로 나눠요.

hobby = "축구-농구-야구" print(hobby.split("-")) # ['축구', '농구', '야구']

split()으로 나눈 두 값을 name과 age에 하나씩 담을 수 있어요.

name, age = "홍길동 10".split() # 공백을 기준으로 나눔 print("이름 :", name) print("나이 :", age)
⚠️ 여러 변수에 나눠 담을 때는 개수를 맞춰요

나뉜 값이 2개라면 왼쪽에도 변수가 2개 있어야 해요. 값과 변수의 개수가 다르면 ValueError가 발생해요.

변수 하나에 저장하면 리스트 전체가 들어가요.
여러 변수에 하나씩 담으면 각 값은 문자열이에요. 예를 들어 age에 들어가는 "10"도 문자열이에요.

input() 명령어로 입력 받은 결과도 문자열이기 때문에 split()으로 나눌 수 있습니다.

str1, str2 = input().split() # 입력: hi python print(str1+"~", str2+"!") # 출력: hi~ python!

7. 문자열 합치기 (join)

join()은 여러 문자열을 이어 붙여 하나의 문자열을 돌려줘요. 앞에서 쉼표로 나눈 취미 목록을 이번에는 " / "로 이어 봐요.

hobbies = "축구-농구-야구".split("-") print(" / ".join(hobbies)) # 축구 / 농구 / 야구

"-".join(["A", "B", "C"])처럼 구분자를 점 앞에 써요. 구분자는 글자 사이에 들어가요.

print(" ".join(["A", "B", "C"])) # A B C print("-".join(["A", "B", "C"])) # A-B-C print(",".join(["A", "B", "C"])) # A,B,C print("".join(["A", "B", "C"])) # ABC

join()은 리스트뿐만 아니라 문자열 자체에도 사용할 수 있습니다.

print("-".join("ABC")) # A-B-C

문자열도 한 글자씩 꺼낼 수 있는 iterable이기 때문입니다.

⚠️
주의
join()에 넣는 리스트의 요소는 반드시 문자열(str)이어야 합니다.
print(",".join([1, 2, 3])) # ❌ 에러 발생! (숫자는 문자열이 아님)
print(",".join(["1", "2", "3"])) # ⭕ 1,2,3

이럴 땐 숫자를 문자열로 바꿔주면 정상적으로 연결됩니다.

8. 문자열 조건 확인하기

문자와 숫자 글자 확인하기
isalpha()는 한글이나 영문자 같은 문자만 있는지, isdigit()은 숫자 글자만 있는지 확인해요. 공백이 들어 있거나 빈 문자열이면 두 메서드 모두 False예요.

print("안녕".isalpha()) # True print("Hello World".isalpha()) # False print("123".isdigit()) # True print("-12".isdigit()) # False

시작과 끝 확인하기

filename = "photo.png" print(filename.startswith("photo")) # True print(filename.endswith(".png")) # True print(filename.endswith(".PNG")) # False

8) 문자열 포맷팅

문자열 포맷팅(formatting)은 문자열 사이사이에 내가 원하는 변수나 값을 규칙에 맞게 끼워 넣는 것을 말합니다.

1. 문자열 포맷팅 사용하는 이유

문자열과 숫자를 합칠 때 흔히 쓰는 + 연산자 는 두 가지 큰 단점이 있습니다.

⚠️
자료형의 벽
print("나이: " + 14)라고 쓰면 에러가 발생합니다. 반드시 str(14)로 바꿔야 합니다.
⚠️
가독성의 벽
변수가 많아지면 +와 "가 뒤섞여 코드가 지저분해집니다.
# ❌ 불편한 방식 name = "하루" age = 14 # + 연산자 사용하기 : age를 문자열로 변환해야 함!! print("안녕! 나는 " + name + "야. 나이는 " + str(age) + "살이야.") # 인수 활용 : sep 옵션 사용해야 함!! print("안녕! 나는 ", name, "야. 나이는 ", age, "살이야.", sep="")

2. 기본 사용 (빈 중괄호 {})

format() 함수를 사용하며, 중괄호의 개수와 format() 안에 들어갈 변수의 개수가 일치해야 합니다.

month = 5 day = 18 # 출력: 오늘은 5월 18일입니다. print("오늘은 {}월 {}일입니다.".format(month, day))

3. 순서 정하기 (인덱스 사용)

중괄호 안에 인덱스를 넣으면 데이터를 원하는 순서로 배치하거나 중복해서 사용할 수 있습니다.

# 출력: 지민은 사과을 좋아해. # 인덱스 0번: 사과 / 1번: 지민 print("{1}은 {0}을 좋아해.".format("사과", "지민"))

4. 문자열 정렬하기

데이터를 표처럼 가지런히 정렬하고 싶을 때 사용합니다.
✅ 공백 확보 : {:10} ➡️10칸 자리 배정
✅ 왼쪽 정렬 : {:<10}
✅ 오른쪽 정렬 : {:>10}
✅ 가운데 정렬 : {:^10}

print("{:<10} | {:^10} | {:>10}".format("Name", "Score", "Grade")) print("{:<10} | {:^10} | {:>10}".format("James", 95, "A+"))
💡
한글과 영어/숫자 함께 출력하면?
출력 화면에서 한글은 영어와 숫자보다 약 2배 넓은 물리적 공간을 차지합니다. 이로 인해 코드 상으로는 동일한 칸수를 지정하더라도, 한글이 포함된 행은 정렬이 어긋나 보일 수 있습니다. 

5. 공백 채우기

정렬 기호 앞에 특정 문자를 넣으면 공백 대신 해당 문자로 빈칸을 채웁니다.

# 가운데 정렬하고 남는 공간을 '-'로 채우기 print("{:-^20}".format(" 실행 결과 "))

6. 부동 소수점 출력

문자열 안에 {:.자리수f} 형식을 넣어 사용합니다. 여기서 f는 float(부동 소수점)을 의미합니다.
✅ {:f} : 소수점 여섯 자리까지 표시(기본값)
✅ {:.2f} : 소수점 둘째 자리까지 표시(세째 자리에서 반올림 됨!)
✅ {:.0f} : 소수점 없이 정수 부분만 표시

avg = 85.6789 print("평균: {:f}점".format(avg)) # 소수점 여섯 자리까지 출력 print("평균: {:.2f}점".format(avg)) # 소수점 둘째 자리까지 출력 print("평균: {:.0f}점".format(avg)) # 정수만 출력

7. 부동 소수점 정렬

정렬과 소수점 제한을 동시에 할 수도 있습니다. {전체칸수.자리수f} 순서로 적습니다.

num = 3.141592 print("[{:10.2f}]".format(num)) # 결과: [ 3.14] (10칸을 확보, 오른쪽 정렬, 소수점 2자리 표시)
