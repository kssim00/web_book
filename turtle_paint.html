🐢 파이썬 터틀 학습지

코드로 만드는 나만의 그림판!

파이썬 turtle로 마우스로 그림을 그릴 수 있는 진짜 그림판을 직접 만들어봐요.
완성하면 이렇게 예쁜 그림도 그릴 수 있어요!

1

오늘의 미션

오늘은 파이썬의 turtle(터틀)이라는 도구로, 마우스로 그림을 그릴 수 있는 나만의 그림판을 만들어볼 거예요.

1
마우스를 누른 채로 움직이면 선이 그려져요.
2
왼쪽 색깔 버튼을 누르면 붓 색깔이 바뀌어요.
3
화살표 버튼으로 선의 굵기를 바꿀 수 있어요.
4
지우개 버튼으로 그린 걸 지울 수 있어요.
미리 알아두기 — turtle은 화면 위에서 움직이며 그림을 그리는 파이썬 거북이 캐릭터예요. 우리는 이 거북이를 붓처럼 사용할 거예요! 🖌️
2

그림판 화면 만들기

가장 먼저 그림판 창을 만들고, 화면을 도구상자(왼쪽)와 그림 그리는 곳(오른쪽)으로 나누는 선을 그어요.

import turtle as t t.setup(600, 500) # 창 크기 정하기 t.title("나만의 그림판") # 창 제목 정하기 t.bgcolor("ivory") # 배경을 아이보리색으로 t.speed(0) # 제일 빠른 속도로! t.penup() t.goto(-200, 250) t.pendown() t.goto(-200, -250) # 세로선 하나 긋기
기억하기 — penup()은 "붓을 들어올려서(선 없이) 이동", pendown()은 "붓을 내려서(선을 그리며) 이동"이라는 뜻이에요.
3

붓(펜) 만들기

이제 화면 오른쪽에서 그림을 그려줄 주인공 거북이, main_pen을 만들어요. 동그란 모양으로 바꾸면 진짜 붓처럼 보여요.

main_pen = t.Turtle() main_pen.shape("circle") main_pen.speed(0) main_pen.penup() main_pen.goto(50, 0) main_pen.pendown()
비교하기 — 2번에서 만든 t는 화면 전체를 담당하고, main_pen은 그림을 그리는 진짜 붓 역할을 해요.
4

마우스로 그림 그리기

붓을 만들었으니, 이제 마우스 동작과 붓을 연결할 차례예요. 파이썬은 "드래그"와 "클릭"을 구분해서 다르게 반응하게 만들 수 있어요.

def move(x, y): main_pen.penup() main_pen.goto(x, y) main_pen.pendown() main_pen.ondrag(main_pen.goto) # 드래그하면 선이 그려져요 t.onscreenclick(move) # 클릭만 하면 붓이 순간이동해요
마우스를 누른 채 움직이면 이렇게 자유롭게 선이 그려져요.
왜 두 개나 필요할까요? — ondrag는 "누른 채 움직이기"에, onscreenclick은 "그냥 클릭"에 반응해요. 덕분에 클릭만 했을 땐 선 없이 붓만 옮겨갈 수 있어요.
5

색깔 버튼 만들기

도구상자에 작은 동그라미 거북이를 놓고, 클릭하면 main_pen의 색깔을 바꾸도록 연결해요. 이 작업을 색깔 수만큼 반복해요.

blue_pen = t.Turtle() blue_pen.shape("circle") blue_pen.color("lightblue") blue_pen.penup() blue_pen.goto(-250, 200) def blue(x, y): main_pen.color("lightblue") blue_pen.onclick(blue) # 파란 동그라미를 클릭하면 blue() 실행!
같은 방법으로 분홍(pink), 주황(orange), 검정(black) 버튼도 만들 수 있어요.
규칙 찾기 — 색깔 버튼마다 이름(blue_pen, pink_pen…)과 위치(goto)만 다르고, 하는 일은 똑같아요. "만들기 → 위치 정하기 → 함수 만들기 → onclick 연결하기" 순서를 기억하세요!
6

굵기 조절 버튼

위/아래 화살표 버튼을 눌러서 선의 굵기를 바꿀 수 있게 만들어요. 이번엔 global이라는 새로운 단어가 나와요.

pen_size = 5 def size_up(x, y): global pen_size pen_size += 1 main_pen.pensize(pen_size) def size_down(x, y): global pen_size if pen_size > 2: pen_size -= 1 main_pen.pensize(pen_size)
화살표 버튼을 눌러 굵기를 바꾸며 그린 모습이에요.
global이 뭐예요? — 보통 함수 안에서 만든 변수는 그 함수 안에서만 써요. 그런데 pen_size는 여러 함수가 함께 사용해야 하니까, "이건 우리 프로그램 전체가 같이 쓰는 변수야!" 라고 global로 알려주는 거예요.
안전장치 — if pen_size > 2: 덕분에 굵기가 2보다 작아지지 않아요. 선이 너무 얇아서 안 보이는 걸 막아주는 똑똑한 조건문이에요.
7

지우개 만들기

지우개는 사실 특별한 마법을 쓰는 게 아니에요. 배경색과 똑같은 색으로 다시 칠하는 것뿐이랍니다!

eraser = t.Turtle() eraser.shape("square") eraser.color("black", "white") eraser.penup() eraser.goto(-250, -170) def clear(x, y): main_pen.color("ivory") # 배경색과 같은 색! 지워진 것처럼 보여요 eraser.onclick(clear)
하얀 네모 버튼이 바로 지우개예요.
진짜 지우개일까요? — 사실 지우는 게 아니라, 배경색(ivory)으로 다시 그리는 거예요! 그래서 지우개를 누른 다음엔 붓 색깔도 다시 골라줘야 해요.
