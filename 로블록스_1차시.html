LESSON · 1차시

로블록스 스튜디오 첫 만남
탐색기부터 클릭 파트까지

오늘은 로블록스 스튜디오를 처음 열어보고, 게임의 지도인 탐색기와 친해진 뒤 첫 스크립트로 print를 찍어봐요. 마지막엔 클릭하면 반응하는 파트와, 밟으면 터지는 폭발 트랩까지 만들어요.

이 교재 사용법 — 완전 초보자도 이 문서만 보고 따라 할 수 있도록, 클릭 위치와 순서를 하나하나 적어뒀어요. 번호 순서대로 진행해주세요.

STEP 1

스튜디오 둘러보기

코드 없이 손으로 만져보며 스튜디오와 먼저 친해져요.

  1. 1

    홈 탭 → 파트를 눌러 파트를 추가합니다.

  2. 2

    탐색기 Workspace 안에 파트가 생깁니다.

  3. 3

    파트를 클릭해 선택합니다.

  4. 4

    속성 창에서 Color, Size, Material을 바꿔봅니다.

  5. 5

    이동(Move)·크기(Scale)·회전(Rotate) 도구를 눌러 파트를 옮기고, 늘리고, 돌려봅니다.

  6. 6

    속성 창의 Anchored를 체크하면 파트가 중력 없이 허공에 고정돼요. (자세한 원리는 11번에서 다뤄요)

탐색기에서 개체를 클릭하면, 옆의 속성 창에서 그 개체의 색깔·크기·이름 같은 세부 정보를 바꿀 수 있어요. 탐색기로 무엇을 고를지 정하고, 속성 창으로 어떻게 바꿀지 정해요.
실제 홈 탭 — 이동 · 스케일 · 회전 도구
실제 홈 탭 — 재질 · 색상 · 그룹 · 잠금 · 고정 도구
오늘 손으로 익힌 이동·크기·회전·고정은 나중에 스크립트에서 각각 Position, Size, Rotation, Anchored라는 이름으로 그대로 다시 만나요. 파트 여러 개를 하나로 묶고 싶을 땐 그룹(Group)을 쓰는데, 오늘은 몰라도 괜찮아요.
STEP 2

02탐색기, 로블록스 게임의 지도예요

탐색기(Explorer)는 게임 안에 있는 모든 것들을 종류별로 정리해서 보여주는 창이에요. 컴퓨터의 폴더처럼, 무엇이 어디에 있는지 한눈에 볼 수 있어요.

스크립트를 쓰기 전에 탐색기부터 익혀야 "이 코드가 어떤 물건을 가리키는지" 알 수 있어요.

로블록스 스튜디오 상단 홈 탭에서 탐색기 버튼을 누르면 오른쪽에 창이 열려요.

실제 로블록스 스튜디오 홈 탭 — 탐색기 · 속성 버튼 위치
창이 안 보이면 위쪽 창 메뉴에서도 탐색기를 켤 수 있어요.
STEP 3

03부모와 자식 구조

탐색기는 계층 구조예요. 폴더 안에 폴더가 있듯, 개체 안에 또 다른 개체가 들어있어요.

화살표를 눌러 펼치면 안에 들어있는 것들이 보여요. Workspace 아래에 Part가 있다면, Part는 Workspace의 자식이에요.
STEP 4

04자주 쓰는 서비스

게임(game) 아래에는 역할이 정해진 여러 서비스가 있어요.

실제 탐색기 화면 — Workspace, Lighting, ServerScriptService 등
STEP 5

05진짜 첫 스크립트를 써볼 시간이에요

탐색기에서 살펴본 서비스 중 ServerScriptService에 스크립트를 넣으면, 게임이 실행될 때 그 코드가 실제로 동작해요. 첫 번째로 배울 명령어는 print예요.

  1. 1

    탐색기에서 ServerScriptService에 마우스를 올리면 나타나는 ⊕ 버튼을 눌러 Script를 선택합니다.

실제 탐색기 화면 — ServerScriptService 아래 Script가 생성된 모습
스크립트를 만들면 스크립트 편집기 창이 자동으로 열려요. 새로 만든 스크립트에는 기본 코드가 이미 들어있어요.
실제 스크립트 편집기 — 기본으로 들어있는 코드
print("Hello world!") -- 괄호 안의 내용을 출력 창에 보여줌
  1. 2

    출력 창이 안 보이면 창 메뉴에서 출력을 켭니다.

  2. 3

    위쪽 재생 버튼을 누르면 게임이 실행되면서 스크립트도 함께 실행돼요.

실제 출력 창 — print("Hello world!")를 실행한 결과
확인했으면 정지 버튼을 눌러 테스트를 끝내요.
STEP 6

06나만의 문구 출력하기

괄호 안의 문자열을 원하는 내용으로 바꿔보세요. 문자열은 항상 따옴표로 감싸요.

print("안녕, 로블록스!")
따옴표를 빼먹으면 오류가 나요. 문자열은 꼭 " "로 감싸야 해요.

쉼표(,)로 구분하면 여러 값을 한 줄에 출력할 수 있어요.

print("점수:", 100)
→ 점수: 100
쉼표로 이어주면 문자열과 숫자를 섞어서 한 줄에 출력할 수 있어요.
STEP 7

07스크립트로 경로 찾기

탐색기에 보이는 순서 그대로 코드에 적으면 그 물건을 찾을 수 있어요.

local part = workspace.Baseplate -- Workspace 안의 Baseplate를 가리킴
print(part.Name) -- 그 개체의 이름을 출력
workspace.Baseplate는 "Workspace 안에 있는 Baseplate"라는 뜻이에요. 탐색기에서 본 순서와 똑같아요.
local part = script.Parent -- 이 스크립트 바로 위 개체를 가리킴
print(part.Name) -- 그 개체의 이름을 출력
script.Parent는 "이 스크립트가 들어있는 바로 위 개체"를 가리켜요.
HIGHLIGHT · 08

클릭 파트 ① 감지기 넣기

오늘의 하이라이트! 클릭하면 사라지거나 색이 바뀌는 파트를 만들어요. 먼저 ClickDetector를 Part 안에 넣습니다.

  1. 1

    Part를 클릭해 선택합니다.

  2. 2

    ⊕ 버튼(또는 우클릭 → 삽입 → 개체 삽입...)을 누릅니다.

  3. 3

    검색창에 ClickDetector를 입력해 선택합니다.

  4. 4

    탐색기에서 Part를 펼쳐 Part 안에 들어있는지 확인합니다.

HIGHLIGHT · 08

클릭 파트 ② 코드 작성

같은 Part 안에 Script를 추가하고, 클릭 시 실행할 코드를 작성해요.

  1. 1

    같은 Part를 선택하고 ⊕ 버튼(또는 삽입 → 개체 삽입...)을 누릅니다.

  2. 2

    검색창에 Script를 입력해 선택합니다.

  3. 3

    Script를 더블클릭해 열고 아래 코드 중 하나를 작성합니다.

버전 1 — 클릭하면 사라지기

local part = script.Parent -- 이 스크립트가 들어있는 Part
local clickDetector = part:WaitForChild("ClickDetector") -- 같은 Part 안의 ClickDetector를 찾음

clickDetector.MouseClick:Connect(function() -- Part를 클릭하면 실행됨
    part:Destroy() -- Part를 삭제함
end)

버전 2 — 클릭하면 색이 바뀌기

local part = script.Parent -- 이 스크립트가 들어있는 Part
local clickDetector = part:WaitForChild("ClickDetector") -- 같은 Part 안의 ClickDetector를 찾음

clickDetector.MouseClick:Connect(function() -- Part를 클릭하면 실행됨
    part.Color = Color3.new(1, 0, 0) -- Part 색을 빨간색으로 바꿈
end)
참고 — WaitForChild("ClickDetector")는 ClickDetector가 Part 안에 없으면 그 줄에서 계속 멈춰있어요. 그래서 08에서 ClickDetector를 먼저 넣어야 해요.
HIGHLIGHT · 08

클릭 파트 ③ 실행해서 확인

재생 버튼을 누르고 파트를 직접 클릭해봐요.

  1. 1

    재생 버튼을 누릅니다.

  2. 2

    파트를 직접 클릭합니다. 사라지거나 색이 바뀌면 성공!

  3. 3

    확인 후 정지 버튼을 누릅니다.

⚠ 클릭해도 반응이 없을 때 확인하세요
  • 탐색기에서 Part를 펼쳤을 때, ClickDetector가 Part의 자식(안쪽)으로 보이나요?
  • Script도 같은 Part 안에 있나요? ServerScriptService 안에 넣으면 작동하지 않아요.
  • ClickDetector의 이름이 정확히 "ClickDetector"인가요? (코드의 WaitForChild와 이름이 같아야 해요)
  • 출력 창(빨간 글씨)에 오류 메시지가 떠 있는지 확인해보세요.
BONUS · 09

보너스 트랩 ① 준비하기

시간이 남으면 도전! 캐릭터가 밟으면 3초 뒤 폭발해요. 08은 클릭, 이번엔 걸어가서 밟기예요.

  1. 1

    새 파트를 추가합니다. (01과 같은 방법: 홈 탭 → 파트)

  2. 2

    속성 → Anchored를 체크합니다. (안 하면 파트가 떨어져요)

  3. 3

    ⊕ 버튼(또는 우클릭 → 삽입 → 개체 삽입...)을 누릅니다.

  4. 4

    검색창에 Script를 입력해 선택합니다.

BONUS · 09

보너스 트랩 ② 코드 & 실행

Script를 더블클릭해서 열고 아래 코드를 작성합니다.

local part = script.Parent -- 이 스크립트가 들어있는 Part(트랩)
local triggered = false -- 한 번만 터지게 막는 잠금장치

part.Touched:Connect(function(hit) -- Part에 뭔가 닿을 때마다 실행됨, hit = 닿은 물체
    if triggered then return end -- 이미 터졌으면 아무것도 안 함

    local character = hit.Parent -- 닿은 물체의 부모(캐릭터일 수도 있음)
    local humanoid = character:FindFirstChild("Humanoid") -- 사람 캐릭터인지 확인

    if humanoid then -- 사람이 닿았을 때만
        triggered = true -- 잠금장치를 걸어서 중복 실행 방지

        wait(3) -- 3초 대기

        local explosion = Instance.new("Explosion") -- 폭발 효과 생성
        explosion.Position = part.Position -- 터질 위치 = Part의 위치
        explosion.BlastRadius = 10      -- 폭발 범위
        explosion.BlastPressure = 500000 -- 폭발 힘
        explosion.Parent = workspace -- 게임 화면에 등장시킴

        part:Destroy() -- 트랩 Part 제거
    end
end)
  1. 1

    재생 버튼을 누르면 캐릭터가 나타납니다.

  2. 2

    W·A·S·D로 걸어서 트랩을 밟습니다. (클릭 아님)

  3. 3

    3초 뒤 폭발과 함께 트랩이 사라지면 정지합니다.

⚠ 폭발이 안 일어날 때 확인하세요
  • 혹시 마우스로 클릭하고 있지 않나요? W·A·S·D로 캐릭터를 움직여 파트 위로 지나가야 해요.
  • Script가 트랩 파트 안에 들어있나요?
  • 트랩 파트의 CanCollide가 꺼져 있으면 Touched가 발생하지 않을 수 있어요.
  • 한 번 터진 트랩은 triggered 때문에 다시 반응하지 않아요. 재생을 껐다 켜서 다시 테스트해요.
