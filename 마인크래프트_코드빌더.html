따라 하는 수업 슬라이드

엔트리·스크래치처럼 블록을 끼우면, 에이전트 로봇이 마인크래프트 세상에서 움직입니다.
이 슬라이드는 블록을 어디서 꺼내 어떻게 끼우는지까지 그대로 따라 할 수 있게 만들었어요.

→ 방향키 또는 오른쪽 아래 버튼으로 넘기세요

선생님께 — 이 슬라이드 사용법

수업 전에 1분만 읽어주세요

구성

  • 총 9개 단원 — 단원 하나가 1~2차시(40~45분) 분량입니다.
  • 콘셉트는 코딩 세계 여행 — 초원 → 사막 → 화산섬 → 동굴 → 무지개 숲 → 폐광 → 설원 → 폭풍의 언덕, 그리고 보너스로 지구 궤도까지! 단원마다 새로운 세계에서 새 개념을 배웁니다 (다음 장 여행 지도 참고)
  • 모든 예제에 블록 조립 그림 + 꺼내는 순서가 있습니다. 화면에 띄워 놓고 아이들이 보고 따라 만들면 됩니다.

블록 색깔에 대해

슬라이드의 블록 색은 실제 메이크코드 카테고리 색과 맞춰 두었지만, 버전에 따라 살짝 다를 수 있어요. 아이들에게는 색보다 카테고리 이름(플레이어, 에이전트, 반복…)으로 찾게 지도해 주세요.

각 단원의 마지막 「도전 미션」은 빨리 끝낸 아이들용 심화 과제로 쓰시면 수준 차이를 자연스럽게 흡수할 수 있습니다.

공간 변신의 비밀 = /fill 명령어

채팅창에 /fill ~-10 ~-1 ~-10 ~10 ~-1 ~10 sand 를 입력하면 내 발밑 주변 땅이 순식간에 모래로! 물결표(~)는 "내 위치 기준"이라는 뜻이에요. 마지막 단어만 water, snow, stone 등으로 바꾸면 어떤 세계든 만들 수 있어요. 아이들 앞에서 선생님이 직접 시연해 보세요 — "코드 한 줄이 세상을 바꾼다"는 이 수업의 주제를 보여주는 최고의 오프닝입니다.

단원이 끝날 때마다 아이들이 완성 장면을 스크린샷으로 찍어 모으게 하세요. "사막 도장", "화산 도장", "지구 도장"… 10개가 모이면 코딩 여권 완성 = 학기말 포트폴리오가 됩니다. 발표 자료로도, 학부모 공유용으로도 좋아요.

준비 ① 연습용 월드 만들기

수업용 월드는 이렇게 설정하세요

새 월드 설정 (아이들과 똑같이)

  1. 마인크래프트 에듀케이션 실행 → 플레이 → 새로 만들기 → 새 월드
  2. 게임 모드: 크리에이티브 (재료 무한, 죽지 않음)
  3. 난이도: 평화로움 (몬스터가 안 나와서 코딩에만 집중)
  4. 세계 유형: 평지(Flat)를 추천 — 폭발쇼·경기장 예제가 평평한 땅에서 잘 보임
  5. 치트 활성화: 켜기 ← 이걸 꺼두면 코드빌더 명령이 안 먹는 경우가 있어요. 꼭 확인!

기본 조작 5개만 미리 연습 10분

  • WASD 이동, 마우스로 시선
  • Space 점프 (크리에이티브에선 두 번 누르면 비행)
  • E 아이템 창 / T 또는 Enter 채팅창
  • 왼쪽 클릭: 부수기 / 오른쪽 클릭: 놓기
마인크래프트가 처음인 아이는 거의 없지만, "게임 실력"과 무관하게 모두 같은 출발선이 되도록 첫 10분은 조작 연습으로 통일해 주세요.
준비 ② 코드빌더 열기

키보드 C 키 하나면 열립니다

  1. 월드에 들어간 상태에서 C 키를 누르세요 (또는 상단 코드빌더 아이콘)
  2. 편집기 선택 화면이 나오면 MakeCode(메이크코드) 선택
  3. 새 프로젝트 클릭 → 이름 짓기 (예: "1반 김코딩")
  4. 왼쪽 = 블록 서랍(카테고리), 오른쪽 = 작업 공간. 엔트리와 똑같은 구조!
  5. 다 만들면 오른쪽 아래 ▶ 실행… 이 아니라, 대부분의 코드는 채팅 명령어로 실행해요. (다음 장에서!)
C를 눌러도 안 열리면: ① 채팅창이 열려 있지 않은지 확인 ② 월드 설정에서 치트가 켜져 있는지 확인.

준비 ④ 블록 다루는 손기술

블록 끼우기 4가지 기본기

  1. 꺼내기 — 서랍에서 블록을 꾹 잡고 끌어서 작업 공간에 놓기
  2. 끼우기 — 블록 아래로 가져가면 노란 그림자가 생김 → 그때 놓으면 딸깍 붙음
  3. 버리기 — 필요 없는 블록은 다시 왼쪽 서랍 쪽으로 끌면 휴지통에 들어감
  4. 복제하기 — 블록 위에서 마우스 오른쪽 클릭 → 복제. 같은 블록을 여러 개 쓸 때 최고!

흰색 동그라미 = 바꿀 수 있는 값

에이전트를 앞으로 1 칸 이동

블록 속 1 처럼 하얀 부분은 클릭해서 값을 바꿀 수 있어요. 숫자를 직접 치거나, 앞으로 처럼 ▾가 있으면 목록에서 고릅니다.

첫 시간에 "블록 10개 꺼냈다가 전부 휴지통에 버리기" 놀이를 1분 시키면, 이후 수업 내내 손이 빨라집니다.
실전 훈련소 ① 공식 튜토리얼 월드

연습장은 이미 게임 안에 있어요 — 코드빌더 튜토리얼 월드

마인크래프트 에듀케이션에 내장된 무료 공식 월드입니다. 마을을 걸어다니며 표지판이 하나씩 알려주고, 챌린지 코스 7개가 기다리고 있어요. 우리 수업의 "단원 끝 실전 시험장"으로 쓰기 딱 좋습니다.

입장 방법 & 진행 방식

  1. 플레이 → 라이브러리 보기(View Library) → 시작하기/튜토리얼 코너에서 "Code Builder Tutorial" 월드 열기 (검색해도 됩니다)
  2. 마을 길을 따라 걸으면 표지판이 조작법·에이전트를 차례로 설명해 줍니다
  3. 각 챌린지장 입구에 시작 발판(Start Plate)이 있고, 에이전트를 코드로 움직여 금 발판(Gold Plate)을 밟게 하면 성공!
  4. 챌린지장 옆 전망대(Observation Deck)에 올라가면 에이전트가 코스를 도는 모습을 위에서 한눈에 관찰할 수 있어요 — 발표·시연할 때 최고

표지판이 알려주는 에이전트 3대 비밀

  • 불사신이다 — 물에 빠져도, 용암에 들어가도, 절대 죽지 않아요. 그래서 어떤 위험한 코스도 코드만 맞으면 통과!
  • 자기 가방(인벤토리)이 있다 — 에이전트를 우클릭하면 가방이 열립니다. 재료를 넣어줘야 블록을 놓을 수 있어요.
  • 길을 잃으면 소환하면 된다 — 텔레포트 명령(우리의 "이리와" 코드!)으로 언제든 내 옆에 부를 수 있어요.
보너스 — 코드빌더 홈 화면에도 내장 미니 튜토리얼이 있어요. 우리가 배울 닭 비(Chicken Rain)가 공식 튜토리얼로 들어있고, 언어는 블록/파이썬/자바스크립트 중 선택(우리는 블록! 6학년 심화반은 같은 코드를 파이썬으로 구경시켜 주면 눈이 커집니다).
실전 훈련소 ② 챌린지 1~7 공략 지도

어떤 챌린지를 언제 풀게 할까?

챌린지는 난이도 순서대로, 우리 커리큘럼과 정확히 맞물립니다. 해당 단원을 배운 날 마지막 10분에 도전시키고, 성공 장면 스크린샷은 여권 도장으로!

챌린지미션새로 만나는 블록풀기 좋은 때
1. 직진 코스곧게 뻗은 길 끝의 금 발판까지 — 「앞으로 이동」만으로 통과—2단원 직후
2. 꺾인 길ㄱ자·ㄷ자로 꺾이는 길 — 회전을 섞어 통과「회전」2단원 직후
3. 오르막 코스계단처럼 오르내리는 벽 코스 통과「위로/아래로 이동」 ← 슬라이드엔 없던 새 블록!2단원 심화
4. 종합 장애물물·용암 코스 속 흰 발판 4개를 밟아 탑을 모두 켠 뒤 금 발판으로 (에이전트는 불사신이라 용암도 OK!)지금까지 전부 종합3단원 들어가기 전 / 숙제
5. 광물 수집일렬로 늘어선 광물을 캐며 전진, 보너스: 모은 것을 호퍼에 납품「부수기」「모두 줍기」「전부 버리기」 + 반복3단원(반복) 직후
6. 자동 농장상자에서 에이전트 가방을 채우고, 밭을 갈고 심고 수확까지 자동화「밭 갈기(till)」「활성 슬롯 정하기」「놓기」4단원(반복 응용) 직후
7. 산악 채광산을 감지하며 뚫고 올라가 은신처 지을 재료 수집 — 조건 판단의 종합판「만약」「~하는 동안(while)」+「감지」6단원(조건문) 직후
운영 팁 — 챌린지 4·7은 어려워서 정답이 여러 가지입니다. "가장 짧은 코드로 통과하기" 대회를 열면 잘하는 아이들이 반복문·조건문을 스스로 끌어다 쓰기 시작해요. 막힌 아이에겐 전망대에서 친구 에이전트 관찰을 시키면 힌트가 됩니다.

채팅에 "안녕" 치면 인사하는 코드

블록 조립 순서

  1. 플레이어 서랍에서 「채팅 명령어 "jump" 입력하면」 블록을 꺼내 작업 공간에 놓기
  2. 블록 속 흰 칸 "jump"를 클릭해서 "안녕"으로 바꾸기
  3. 다시 플레이어 서랍에서 「말하기(say) " "」 블록을 꺼내 1번 블록 안쪽에 끼우기 (노란 그림자 확인!)
  4. 말하기 내용에 "나는 코딩왕이다!" 입력
  5. 게임 화면으로 돌아가 T로 채팅창 열고 안녕 입력 → Enter

7단원 · 변수❄️ 얼음 설원

💎 설원에 얼어붙은 다이아몬드 캐기 대회

변수 = 숫자를 넣어두는 상자. "점수"라는 상자를 만들어, 눈 속에 묻힌 다이아몬드를 캐는 진짜 게임을 만듭니다.

설원 만들기: /fill ~-15 ~-1 ~-15 ~15 ~-1 ~15 snow → 발밑 주변이 눈밭으로! 그다음 선생님이 다이아몬드 광석 15개쯤을 눈밭 여기저기에 반쯤 파묻어 숨겨 두세요. "얼음 나라에 얼어붙은 다이아몬드 구출 작전"이 됩니다.

블록 조립 순서

  1. 변수 서랍 → 「변수 만들기」 버튼 클릭 → 이름을 점수로 짓기
  2. 「채팅 명령어 "게임시작"」 블록 안에 변수의 「점수를 0으로 정하기」 끼우기
  3. 블록 서랍에서 「(블록)이 부서지면」 이벤트 블록을 꺼내 새로운 자리에 따로 놓기 → 블록 종류를 다이아몬드 광석으로 선택
  4. 그 안에 「점수를 1만큼 바꾸기」 + 「말하기: 점수」 끼우기 (말하기의 흰 칸에 변수 서랍의 점수 동그라미 블록을 끌어다 끼움!)
  5. 선생님이 미리 다이아몬드 광석을 여기저기 숨겨두면 → 1분 보물찾기 대회 시작!

완성된 코드 (덩어리 2개!)

채팅 명령어 "게임시작" 입력하면
점수 를 0 으로 정하기
💎 다이아몬드 광석 이 부서지면
점수 를 1 만큼 바꾸기
말하기 점수
다이아몬드를 캘 때마다 채팅창에 1, 2, 3… 점수가 올라갑니다. 코드 덩어리가 2개로 나뉘어 각자 다른 순간에 실행된다는 것도 중요한 배움!
논리의 「만약」+「= 비교」 블록으로 점수가 5가 되면 "우승!" 말하고 닭비 내리기 축하 이벤트 만들기.
8단원 · 함수⛈️ 폭풍의 언덕

⚡ 번개 마법사 — 나만의 마법(함수) 만들기

여행의 종착지, 폭풍의 언덕! 함수 = 코드 묶음에 이름을 붙여 두고두고 쓰는 것(엔트리의 "나만의 블록") — 즉, 나만의 마법 주문서입니다. "번개마법"이라는 주문서를 만들어 보죠.

폭풍 무대 3종 명령어 — ① /weather thunder 천둥 번개 치는 날씨 ② /time set midnight 깜깜한 폭풍의 밤 ③ /effect @a slow_falling 9999 1 true ← 공중부양 마법! 점프하면 둥실둥실 떠다니는 진짜 마법사가 됩니다 (해제는 /effect @a clear). 안전 약속: 크리에이티브라 번개에 맞아도 안 다치지만, 친구 바로 옆에 번개 조준 금지!

블록 조립 순서

  1. 서랍 맨 아래 고급 → 함수 → 「함수 만들기」 → 이름을 번개마법으로
  2. 보라색 「함수 번개마법」 틀 안에 반복 3회 넣기
  3. 플레이어 서랍 맨 아래의 「실행」 블록(상급 기술 — 게임 명령어를 코드로 쏘는 블록!)을 반복 안에 끼우고, 흰 칸에 /summon lightning_bolt ~5 ~ ~3 입력 (~숫자 = 내 위치에서 떨어진 곳 — 사막에서 배운 물결표!)
  4. 새로 「채팅 명령어 "마법"」 블록을 만들기
  5. 그 안에 반복 2회 → 반복 안에 함수 서랍의 「호출: 번개마법」 끼우기
  6. 언덕 위에서 마법 입력! ⚡⚡⚡

완성된 코드 (덩어리 2개!)

함수 번개마법 ← 나만의 주문서
반복: 3 회 실행
실행 "/summon lightning_bolt ~5 ~ ~3"
채팅 명령어 "마법" 입력하면
반복: 2 회 실행
호출 번개마법
"마법"을 외칠 때마다 주문서가 통째로 실행되어 번개 6발이 내리꽂힙니다. 주문서(함수)는 한 번 만들면 언제든, 몇 번이든 부를 수 있다 — 이게 함수의 힘!
① 좌표 숫자(~5, ~3)를 바꿔 번개 조준 연습 ② 「눈보라마법」(실행: /weather rain), 「닭소환마법」(5단원 닭비 코드!) 함수를 추가해 마법 주문서 3종 세트 완성 ③ 나만의 주문어로 바꿔 짝꿍 앞에서 마법쇼 시연.
특별 단원 · 도형 블록🌍 지구 궤도

🌍 하늘에 지구를 띄워라!

반복문으로 네모는 잘 만들었는데, 둥근 지구는 어떻게 만들까요? 서랍 맨 아래 고급 → 도형(Shapes)에 숨어 있는 구(sphere) 블록 하나가 수백 개의 블록을 저절로 쌓아 줍니다. 좌표와 반지름을 다루니 수학 시간과도 연결!

넓고 트인 하늘만 있으면 준비 끝. 딱 하나만 주의 — 반지름이 크면 완성까지 몇 분씩 걸립니다 (반지름 15짜리 속 빈 구가 7분 이상!). 수업에선 반지름 5~8 + "겉면만(속 빈)" 옵션을 추천하세요. 지우고 싶을 땐? 똑같은 구 블록의 재료를 공기(air)로 바꿔 한 번 더 실행하면 싹 사라집니다 — 코딩식 지우개!

블록 조립 순서

  1. 「채팅 명령어」 꺼내기 → "지구"로 바꾸기
  2. 서랍 맨 아래 고급을 눌러 도형(Shapes) 서랍 열기 — 처음 만나는 서랍!
  3. 「구(sphere) 만들기」 블록을 꺼내 채팅 블록 안에 끼우기
  4. 재료: 파란 양털(바다!) / 중심: ~0 ~15 ~0 (가운데 15 = 내 머리 위 15칸 — 닭비에서 배운 높이!) / 반지름: 6 / 옵션: 겉면만
  5. 채팅에 지구 입력 → 하늘에 거대한 파란 구가 떠오릅니다!
  6. Space 두 번으로 날아올라, 초록 양털로 대륙을 직접 페인팅 — 코딩과 미술이 만나는 시간 🎨 (극지방엔 흰 양털 얼음도!)

완성된 코드

채팅 명령어 "지구" 입력하면
구 만들기 🟦 파란 양털 중심 ~0 ~15 ~0 반지름 6 겉면만
블록 단 2개로 하늘에 행성이 뜹니다. "반복문으로 하려면 얼마나 걸렸을까?"를 물어보세요 — 좋은 블록 하나가 코드 백 줄을 대신한다는 걸 배우는 순간. 반 전체가 대륙을 나눠 칠하면 우리 반만의 지구 완성!
① 흰 양털 + 반지름 2로 옆에 달 만들기 (중심 ~12 ~18 ~0)
② 같은 중심에 유리 구, 반지름 7, 겉면만을 한 번 더 → 지구를 감싸는 투명 대기권!
③ 도형 서랍의 원(circle) 블록으로 구 둘레에 고리를 두르면? → 토성 완성 🪐
④ 반 전체 프로젝트: 각자 행성 하나씩 만들어 우리 반 태양계 완성 — 실제 해외 교실에서 하는 수업입니다!
9단원 · 최종 프로젝트 (2차시)🚀 자유 여행

배운 걸 몽땅 넣어 나만의 작품 만들기

여행의 마지막! 지금까지 다녀온 8개 세계 중 마음에 드는 곳을 무대로 골라, 팀(2~3명)별로 작품을 만듭니다. 기획(반 차시) → 제작(1차시) → 서로 플레이 & 발표(반 차시). (예: 마그마 미로, 설원 보물찾기, 화산섬 폭발쇼장, 마법 배틀장…)

🌀 마그마 미로 탈출

  • 반복문으로 미로 벽 세우기
  • 무지개 달리기 코드를 마그마길로 바꿔 함정 만들기
  • 도착점 금 블록이 부서지면 "탈출 성공!" 말하기 (변수·이벤트)

💎 보물찾기 대회장

  • 변수 점수게임을 크게 확장
  • 다이아·금·에메랄드 점수 다르게 (변수 여러 개 or +1/+3/+5)
  • 점수 10점 도달 시 닭비 축하 이벤트 (조건문)

⚡ 마법사 아카데미

  • 마법 함수 3종 세트: 번개마법·닭소환마법·눈보라마법
  • 각 마법마다 나만의 주문어(채팅 명령어)로 시전
  • 손님(다른 팀)을 초대해 마법쇼 시연 — "어떤 함수를 썼나요?" 인터뷰까지
발표 때 꼭 묻기 — "이 작품에서 반복 / 조건 / 변수 / 함수를 어디에 썼나요?" 아이가 자기 입으로 개념을 말하는 순간이 진짜 평가입니다.
