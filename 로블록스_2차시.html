움직이고 반응하는 세상
변수·조건문부터 Touched까지

오늘은 값을 담아두는 변수와, 조건에 따라 다르게 행동하는 if를 배워요. 그리고 1차시에서 살짝 맛본 Touched를 다시 써서 점프대·함정·코인을 만들어요. 마지막엔 AI 도우미로 진짜 에러를 직접 고쳐봐요.

이 교재 사용법 — 1차시에서 만든 폭발 트랩과 거의 같은 구조예요. Touched·hit.Parent·FindFirstChild("Humanoid")가 낯설다면 1차시 09번을 먼저 복습하고 오면 훨씬 수월해요.

STEP 1

변수: 값 담는 상자

변수는 값을 담아두는 상자예요. 이름을 붙여두면 나중에 다시 꺼내 쓰거나 바꿀 수 있어요.

local score = 0 -- score라는 상자를 만들고 0을 담음
print(score) -- 상자 안의 값을 출력

score = score + 10 -- 상자 안의 값에 10을 더해서 다시 저장
print(score) -- 늘어난 값을 다시 출력
→ 0 그리고 10이 순서대로 출력 창에 나와요.
local은 이 변수를 새로 만든다는 뜻이에요. score = score + 10처럼 자기 자신의 값에 더해서 다시 저장할 수 있어요. 이 패턴은 오늘 코인 줍기에서 그대로 다시 써요.
STEP 2

조건문 if로 비교하기

if는 조건에 따라 다른 코드를 실행해요. 숫자 맞추기로 감을 잡아봐요.

local secret = 7 -- 정답 숫자
local guess = 5 -- 내가 추측한 숫자 (바꿔가며 다시 실행해보세요)

if guess == secret then -- 두 값이 같으면
    print("정답이에요!")
elseif guess < secret then -- guess가 secret보다 작으면
    print("더 큰 숫자예요")
else -- 그 외의 경우 (guess가 더 클 때)
    print("더 작은 숫자예요")
end
  1. 1

    guess 값을 여러 개로 바꿔가며 재생 버튼을 눌러봅니다.

  2. 2

    출력 창 문구가 값에 따라 달라지는지 확인합니다.

⚠ 자주 헷갈리는 부분
  • == (두 개)는 "같다"를 비교할 때, = (한 개)는 값을 저장할 때 써요.
  • elseif는 한 단어예요. else if로 띄어 쓰면 오류가 나요.
HIGHLIGHT · 03

점프대 만들기 — 밟으면 점프

1차시에서 배운 Touched를 다시 써요. 이번엔 밟으면 캐릭터가 점프해요.

  1. 1

    새 파트를 추가하고 속성에서 Anchored를 체크합니다. (1차시 06 참고)

  2. 2

    같은 파트 안에 Script를 추가합니다.

local part = script.Parent -- 이 스크립트가 들어있는 Part(점프대)

part.Touched:Connect(function(hit) -- Part에 뭔가 닿을 때마다 실행됨
    local character = hit.Parent -- 닿은 물체의 부모
    local humanoid = character:FindFirstChild("Humanoid") -- 사람 캐릭터인지 확인

    if humanoid then -- 사람이 닿았을 때만
        humanoid.Jump = true -- 캐릭터를 점프시킴
    end
end)
humanoid.Jump = true는 딱 한 번 점프시키는 명령이에요. 계속 밟고 있으면 여러 번 반복 실행될 수 있어요.
HIGHLIGHT · 04

함정 만들기 — 되돌리기 또는 쓰러뜨리기

밟으면 정해둔 위치로 되돌리거나, 체력을 0으로 만들어 쓰러뜨려요. 두 버전을 만들어 비교해봐요.

  1. 1

    새 파트를 추가하고 Anchored를 체크합니다.

  2. 2

    같은 파트 안에 Script를 추가합니다.

버전 1 — 되돌아가기 (텔레포트)

local part = script.Parent -- 이 스크립트가 들어있는 Part(함정)
local spawnPoint = Vector3.new(0, 5, 0) -- 되돌아갈 위치 좌표
local triggered = false -- 중복 실행을 막는 잠금장치

part.Touched:Connect(function(hit)
    if triggered then return end -- 이미 작동 중이면 무시

    local character = hit.Parent
    local humanoid = character:FindFirstChild("Humanoid")

    if humanoid then
        triggered = true -- 잠금장치 걸기

        character:MoveTo(spawnPoint) -- 캐릭터를 spawnPoint 위치로 이동
        print("함정에 걸렸어요!") -- 출력 창에 메시지 표시

        wait(1) -- 1초 대기
        triggered = false -- 잠금장치 풀기 (다시 밟을 수 있게)
    end
end)
Vector3.new(x, y, z)는 3차원 좌표예요. 원하는 위치를 클릭한 뒤 속성 창의 Position 값을 참고해서 spawnPoint 숫자를 바꿔보세요.

버전 2 — 즉시 쓰러뜨리기 (Health = 0)

local killPart = script.Parent -- 이 스크립트가 들어있는 Part(함정)

killPart.Touched:Connect(function(otherPart) -- Part에 뭔가 닿을 때마다 실행됨
    print(otherPart) -- 무엇이 닿았는지 출력 창에서 확인
    local character = otherPart.Parent -- 닿은 물체의 부모
    local human = character:FindFirstChild("Humanoid") -- 사람 캐릭터인지 확인

    if human then
        human.Health = 0 -- 체력을 0으로 만들어 캐릭터를 쓰러뜨림
    end
end)
  1. 1

    human.Health = 0을 human.Health = 50으로 바꿔서 재생해보세요. 체력이 반만 줄어드는지 확인합니다.

  2. 2

    재생 중 출력 창에서 print(otherPart) 결과를 확인해보세요. 캐릭터가 아닌 다른 물체가 닿았을 땐 뭐라고 찍히는지도 살펴보세요.

HIGHLIGHT · 05

코인 줍기 — 밟을 때마다 개수 세기

밟을 때마다 score 변수가 늘어나요. 변수가 값을 "기억"하는 걸 직접 확인해요.

  1. 1

    새 파트를 추가합니다. (코인처럼 만들고 싶으면 모양을 구체(Ball)로 바꿔도 좋아요)

  2. 2

    같은 파트 안에 Script를 추가합니다.

local part = script.Parent -- 이 스크립트가 들어있는 Part(코인)
local score = 0 -- 지금까지 모은 코인 개수

part.Touched:Connect(function(hit)
    local character = hit.Parent
    local humanoid = character:FindFirstChild("Humanoid")

    if humanoid then
        score = score + 1 -- 코인 개수를 1 늘림
        print("코인 획득! 총", score, "개") -- 출력 창에 현재 개수 표시
    end
end)
일부러 part:Destroy()를 넣지 않았어요. 그래서 밟을 때마다 score가 계속 늘어나는 걸 볼 수 있어요. 진짜 코인처럼 주우면 사라지게 하고 싶다면 마지막 줄에 part:Destroy()를 추가하면 돼요.
STEP 6

AI로 에러 고치기

1차시에서 살짝 맛본 어시스턴트로, 이번엔 진짜 에러를 직접 고쳐봐요.

아래 코드를 스크립트에 붙여넣고 재생을 눌러보세요. 일부러 오타를 심어뒀어요.

local part = script.Parent

part.Touched:Conenct(function(hit) -- 오타가 숨어있어요
    local character = hit.Parent
    local humanoid = character:FindFirstChild("Humanoid")

    if humanoid then
        print("밟았다!")
    end
end)
  1. 1

    재생 버튼을 눌러 출력 창(빨간 글씨)에 뜨는 에러 메시지를 확인합니다.

  2. 2

    에러가 난 코드를 드래그해서 선택합니다.

  3. 3

    어시스턴트에 질문 (Ctrl+J)으로 "이 코드 왜 에러가 나?"라고 물어봅니다.

  4. 4

    AI 답변을 참고해 오타를 고치고, 다시 재생해서 에러가 사라졌는지 확인합니다.

⚠ 자주 나는 오타, AI에게 이렇게 물어보세요
  • Connect를 Conenct·Conect처럼 잘못 쓴 경우 — "attempt to call a nil value" 에러가 나요.
  • 괄호 ( )나 end 짝이 안 맞는 경우
  • 따옴표 " "를 한쪽만 닫은 경우
