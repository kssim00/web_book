바다와 사라지는 발판 추가하기

1차시에서 만든 점프맵에 오늘은 지형 편집기로 바다를 채우고, 밟으면 1초 뒤에 사라지는 발판을 추가해서 더 짜릿하게 바꿔봐요. 1차시에서 배운 Touched와 Transparency·CanCollide를 그대로 다시 써요.

이 교재 사용법 — 1차시 폭발 함정과 구조가 거의 같아요. Touched·hit.Parent·triggered가 낯설다면 1차시를 먼저 복습하고 오면 훨씬 수월해요.

STEP 1

지형 편집기로 바다 만들기

발판이 사라졌을 때 그 아래로 뭔가 있어야 진짜 위험하게 느껴지겠죠? 지형(Terrain) 편집기의 물 브러시로 점프맵 아래에 바다를 채워요. 코드는 필요 없어요.

  1. 1

    상단 지형(Terrain) 탭을 클릭합니다. (홈 탭 옆에 있어요)

  2. 2

    편집(Edit) → 페인트(Paint) 도구를 선택하고, 재질을 물(Water)로 바꿉니다.

  3. 3

    브러시 크기를 크게 키운 뒤, 점프맵 아래 바닥 부분을 드래그해서 칠합니다.

  4. 4

    재생 버튼을 눌러 캐릭터가 물에 빠지면 자동으로 헤엄치는지 확인합니다.

물은 스크립트 없이도 로블록스가 부력·헤엄치는 애니메이션을 자동으로 처리해줘요. 오늘은 도구로 화면만 채워보면 돼요.
HIGHLIGHT · 02

사라지는 발판 만들기

1차시 폭발 함정과 같은 원리예요. wait(1)로 1초를 기다린 다음 발판을 투명하게 만들고, 잠시 후 다시 나타나게 해요.

  1. 1

    새 파트를 추가하고 속성에서 Anchored를 체크합니다. (1차시에서 배운 것처럼)

  2. 2

    같은 파트 안에 Script를 추가합니다.

local part = script.Parent -- 이 스크립트가 들어있는 Part(발판)
local triggered = false -- 중복 실행을 막는 잠금장치

part.Touched:Connect(function(hit) -- 발판에 뭔가 닿을 때마다 실행됨
    if triggered then return end -- 이미 작동 중이면 무시
    triggered = true -- 잠금장치 걸기

    wait(1) -- 1초 대기
    part.Transparency = 1 -- 발판을 투명하게 만듦
    part.CanCollide = false -- 더 이상 밟고 설 수 없게 만듦

    wait(3) -- 3초 뒤
    part.Transparency = 0 -- 다시 보이게
    part.CanCollide = true -- 다시 밟고 설 수 있게
    triggered = false -- 잠금장치 풀기(다시 밟을 수 있게)
end)
triggered 잠금장치가 필요한 이유는 1차시와 똑같아요 — 없으면 Touched가 겹쳐 실행돼서 발판이 영영 안 돌아올 수도 있어요.
→ 3초 뒤엔 Transparency = 0, CanCollide = true로 되돌아와서, 다시 밟고 지나갈 수 있어요.
⚠ 잊지 마세요 — Transparency만 바꾸면 안 보여도 여전히 밟을 수 있어요. CanCollide = false도 꼭 같이 써야 진짜로 통과돼요.
HIGHLIGHT · 03

발판 이어 붙여 점프맵 완성하기

발판 하나를 여러 개 복제해서 이어 붙이면 오늘 영상 속 점프맵처럼 완성돼요.

  1. 1

    완성한 발판을 선택하고 Ctrl+D로 복제합니다. 안에 있는 스크립트도 함께 복사돼요.

  2. 2

    이동(Move) 도구로 복제한 발판을 다음 자리로 옮깁니다.

  3. 3

    발판 사이 간격을 점점 넓히면 뒤로 갈수록 더 어려워져요.

발판을 여러 개 이어 붙이면 이런 점프맵이 완성돼요
디자인 팁 — 발판마다 Color를 다르게 하거나 무늬를 넣어두면, 플레이어가 "이건 사라지는 발판이구나"라고 미리 알아챌 수 있어요.
무늬로 위험한 발판이라는 걸 미리 알려줄 수도 있어요
떨어졌을 때 자연스럽게 다시 시작하게 하고 싶다면, 1차시에서 만든 killPart처럼 바다 아래에 투명한 파트를 깔고 human.Health = 0을 넣어보세요. 쓰러진 캐릭터는 자동으로 스폰 위치에서 다시 시작해요.
