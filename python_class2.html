파이썬 클래스 완전 정복

1편에서 클래스 기초를 익혔다면, 여기서는 클래스 변수와 상속까지 깊이 있게 다뤄봅니다.

개요

클래스(class)는 관련된 데이터(속성)와 기능(메서드)을 하나로 묶어서, 붕어빵 틀처럼 똑같은 모양의 객체(object)를 계속 찍어낼 수 있게 해주는 설계도입니다.

예: 게임 캐릭터마다 이름·체력·공격력이 있고, "공격한다"는 똑같은 동작을 할 수 있음 → 캐릭터마다 변수를 따로따로 만드는 대신 "캐릭터" 클래스 하나로 몇 명이든 만들 수 있습니다.

💡 왜 필요할까?
학생 10명의 이름·점수를 각각 변수로 관리하면 코드가 뒤죽박죽이 됩니다. 클래스를 쓰면 "학생"이라는 틀을 하나 만들고, 그 틀로 학생 10명을 각각 독립된 객체로 깔끔하게 관리할 수 있습니다. 앞으로 배울 Pygame 게임 캐릭터도 대부분 클래스로 만듭니다.

1. 클래스와 객체의 기본 구조

class 키워드로 설계도(클래스)를 만들고, 그 설계도로 실제 객체(인스턴스)를 찍어냅니다.

class 클래스이름:
    # 클래스 내용
    pass

객체이름 = 클래스이름()  # 객체(인스턴스) 생성
class Dog:
    pass

my_dog = Dog()
print(type(my_dog))
→
<class 'Dog'>
💡 알 수 있는 것
클래스 이름은 관습적으로 첫 글자를 대문자로 씁니다. (예: Dog, Student, Character)
my_dog = Dog() 처럼 클래스 뒤에 ()를 붙이면 그 클래스로 만든 객체(인스턴스)가 하나 생성됩니다.

2. __init__ 와 self — 객체가 태어날 때 속성 넣어주기

객체가 만들어질 때 자동으로 실행되는 특별한 메서드가 __init__입니다. 여기서 객체가 가질 속성(attribute)을 초기화합니다.

class 클래스이름:
    def __init__(self, 매개변수1, 매개변수2):
        self.속성1 = 매개변수1
        self.속성2 = 매개변수2
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

my_dog = Dog("초코", 3)
print(my_dog.name, my_dog.age)
→
초코 3
💡 알 수 있는 것
self는 "이 객체 자신"을 가리킵니다. 메서드를 정의할 때는 항상 첫 번째 매개변수로 self를 씁니다.
self.name = name은 "이 객체의 name 속성에 매개변수로 받은 name 값을 저장한다"는 뜻입니다.
객체를 만들 때 Dog("초코", 3)처럼 쓰면, self는 자동으로 넘어가고 name, age에만 값을 채우면 됩니다.
⚠️ self를 빼먹으면 오류가 납니다. def __init__(name, age): 처럼 self를 빼면 첫 번째로 넘긴 값이 엉뚱하게 name 자리에 들어가버려서 오류가 발생하거나 원치 않는 결과가 나옵니다.

3. 메서드 (method) — 객체의 행동 정의하기

클래스 안에 정의한 함수를 메서드라고 부릅니다. 메서드는 그 객체의 속성(self.속성)을 이용해서 "행동"을 만듭니다.

class 클래스이름:
    def __init__(self, ...):
        ...
    def 메서드이름(self, ...):
        실행할 코드 (self.속성 사용 가능)
class Dog:
    def __init__(self, name):
        self.name = name
    def bark(self):
        print(self.name, "멍멍!")

d = Dog("초코")
d.bark()
→
초코 멍멍!
💡 알 수 있는 것
메서드를 호출할 때는 d.bark() 처럼 self 자리를 비우고 호출합니다. 파이썬이 d를 자동으로 self 자리에 넣어줍니다.
메서드 안에서는 self.name처럼 self.를 붙여야 그 객체의 속성에 접근할 수 있습니다.

4. 여러 개의 객체 만들기

같은 클래스로 만든 객체들은 각자 독립적인 속성값을 가집니다. 한 객체의 속성을 바꿔도 다른 객체는 영향받지 않습니다.

class Character:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

hero = Character("전사", 100)
enemy = Character("슬라임", 30)

hero.hp -= 10
print(hero.name, hero.hp)
print(enemy.name, enemy.hp)
→
전사 90 슬라임 30
💡 알 수 있는 것
hero의 체력을 깎아도 enemy의 체력은 그대로입니다. 이것이 클래스의 핵심 장점입니다 — 같은 틀에서 나왔지만 서로 독립적인 데이터를 가진 객체를 원하는 만큼 만들 수 있습니다.
✏️ Example — 리스트에 객체 여러 개 담기

5. 클래스 변수 vs 인스턴스 변수 (심화)

인스턴스 변수(self.속성)는 객체마다 따로 가지는 값이고, 클래스 변수는 그 클래스로 만든 모든 객체가 공유하는 값입니다.

class 클래스이름:
    클래스변수 = 값  # 모든 객체가 공유

    def __init__(self, ...):
        self.인스턴스변수 = ...  # 객체마다 따로
class Character:
    game_name = "코드엔 퀘스트"  # 클래스 변수

    def __init__(self, name):
        self.name = name  # 인스턴스 변수

hero = Character("전사")
enemy = Character("슬라임")
print(hero.game_name, enemy.game_name)
→
코드엔 퀘스트 코드엔 퀘스트
💡 알 수 있는 것
hero와 enemy는 서로 다른 name(인스턴스 변수)을 갖지만, game_name(클래스 변수)은 똑같이 공유합니다.
게임 캐릭터 수 세기처럼 "전체 객체가 몇 개 만들어졌는지"를 셀 때 클래스 변수가 유용합니다.
⚠️ 인스턴스 변수 이름과 클래스 변수 이름이 같으면 인스턴스 변수가 우선됩니다. self.게임이름 = "다른이름"처럼 인스턴스에서 값을 새로 지정하면, 그 객체에서는 클래스 변수 대신 인스턴스 변수가 사용됩니다.

6. 상속 기초 (심화)

상속(inheritance)은 이미 만든 클래스의 속성·메서드를 그대로 물려받아 새로운 클래스를 만드는 기능입니다. 공통 기능은 부모 클래스에 두고, 다른 부분만 자식 클래스에서 추가/수정합니다.

class 자식클래스(부모클래스):
    def __init__(self, ...):
        super().__init__(...)  # 부모의 __init__ 실행
        self.추가속성 = ...
class Character:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

class Warrior(Character):
    def __init__(self, name, hp, power):
        super().__init__(name, hp)
        self.power = power

w = Warrior("전사", 100, 20)
print(w.name, w.hp, w.power)
→
전사 100 20
💡 알 수 있는 것
Warrior는 Character의 name, hp를 그대로 물려받고, power라는 속성만 추가로 가집니다.
super().__init__(name, hp)는 "부모 클래스(Character)의 __init__을 먼저 실행해줘"라는 뜻입니다. 이렇게 하면 name, hp 초기화 코드를 다시 쓸 필요가 없습니다.
🎮 Pygame 미리보기
Pygame에서는 보통 class Player(pygame.sprite.Sprite): 처럼, 게임 엔진이 제공하는 클래스를 상속해서 내 캐릭터 클래스를 만듭니다. 지금 배운 상속 개념이 그대로 이어집니다!
