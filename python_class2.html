클래스,
한 단계 더 깊게

1편에서 클래스 기초를 익혔다면, 여기서는 클래스 변수와 상속까지 다뤄봐요. 앞으로 만들 Pygame 게임 캐릭터도 대부분 클래스로 만들어요.

CONCEPT 1

01클래스 변수 vs 인스턴스 변수

인스턴스 변수(self.속성)는 객체마다 따로 갖는 값이고, 클래스 변수는 그 클래스로 만든 모든 객체가 공유하는 값이에요.

class Character:
    game_name = "코드앤 퀘스트"  # 클래스 변수 (공유)

    def __init__(self, name):
        self.name = name         # 인스턴스 변수 (각자)

hero = Character("전사")
enemy = Character("슬라임")
print(hero.game_name, enemy.game_name)
→ 코드앤 퀘스트 코드앤 퀘스트
hero와 enemy는 서로 다른 name을 갖지만, game_name은 똑같이 공유해요. "지금까지 몇 명이 만들어졌는지" 셀 때도 클래스 변수가 유용해요.
EXAMPLE

02생성된 캐릭터 수 세기

클래스 변수는 객체가 새로 만들어질 때마다 값을 누적하는 용도로도 자주 써요.

class Character:
    count = 0

    def __init__(self, name):
        self.name = name
        Character.count += 1

hero = Character("전사")
enemy1 = Character("슬라임")
enemy2 = Character("고블린")
print("지금까지 만들어진 캐릭터 수:", Character.count)
→ 지금까지 만들어진 캐릭터 수: 3

03너의 차례! 자동 ID 부여하기

Player 클래스를 만들 때마다 자동으로 1번, 2번, 3번... 순서대로 player_id가 붙게 만들어보세요.

class Player:
    next_id = 1

p1 = Player("용사")  # p1.player_id == 1
p2 = Player("전사")  # p2.player_id == 2
직접 해보기

클래스 변수 next_id를 활용해서 __init__을 완성해보세요.

정답 보기 
class Player:
    next_id = 1

    def __init__(self, name):
        self.name = name
        self.player_id = Player.next_id
        Player.next_id += 1

p1 = Player("용사")
p2 = Player("전사")
print(p1.player_id, p2.player_id)
CONCEPT 2

04상속 기초

상속은 이미 만든 클래스의 속성·메서드를 그대로 물려받아 새 클래스를 만드는 기능이에요. 공통 기능은 부모 클래스에 두고, 다른 부분만 자식 클래스에서 추가해요.

class Character:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

class Warrior(Character):
    def __init__(self, name, hp, power):
        super().__init__(name, hp)  # 부모의 __init__ 실행
        self.power = power

w = Warrior("전사", 100, 20)
print(w.name, w.hp, w.power)
→ 전사 100 20
Warrior는 Character의 name, hp를 그대로 물려받고 power만 추가로 가져요. super().__init__(...)는 "부모 클래스의 __init__을 먼저 실행해줘"라는 뜻이에요. 게임을 만들 때 Player(pygame.sprite.Sprite)처럼 이 개념을 그대로 쓰게 돼요.
EXAMPLE

05몬스터 종류별로 클래스 나누기

class Character:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

    def info(self):
        print(self.name, "체력:", self.hp)

class Slime(Character):
    def __init__(self, name, hp):
        super().__init__(name, hp)
        self.exp_reward = 5

class Dragon(Character):
    def __init__(self, name, hp):
        super().__init__(name, hp)
        self.exp_reward = 100

slime = Slime("초록 슬라임", 30)
dragon = Dragon("불꽃 드래곤", 500)
slime.info()
print("처치 시 경험치:", slime.exp_reward)

06너의 차례! 마법사 클래스 만들기

Character(name, hp)를 상속받는 Mage 클래스를 만들어서 mana(마나) 속성을 추가하고, 이름·체력·마나를 출력해보세요.

class Character:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

m = Mage("마법사", 70, 50)
print(m.name, m.hp, m.mana)
직접 해보기

super().__init__(...)로 Character의 __init__을 먼저 실행해보세요.

정답 보기 
class Mage(Character):
    def __init__(self, name, hp, mana):
        super().__init__(name, hp)
        self.mana = mana
