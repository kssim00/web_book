01문자열 포맷팅 3가지 방법

문자열 안에 변수 값을 끼워 넣는 방법은 % 방식 → format() 함수 → f-string 순서로 발전해왔어요. 셋 다 알아두면 다른 사람 코드를 읽을 때 도움이 돼요.

1. % 방식 (가장 오래된 방식) — %s는 문자열, %d는 정수, %f는 실수 자리예요.
name = "민준"
score = 90

print("이름: %s, 점수: %d점" % (name, score))
# 이름: 민준, 점수: 90점
값이 여러 개면 튜플 (name, score)로 묶어서 % 뒤에 적어요. 순서대로 %s, %d 자리에 채워져요.
pi = 3.14159265
name = "민준"

print("원주율: %.2f" % pi)   # 원주율: 3.14   (소수 둘째 자리까지)
print("[%-10s]" % name)      # [민준      ]   (왼쪽 정렬, 전체 10자리)
print("[%10s]" % name)       # [      민준]   (오른쪽 정렬, 전체 10자리)
%.2f는 "소수점 아래 2자리까지"라는 뜻이에요. %10s는 오른쪽 정렬(기본)이고, %-10s처럼 - 기호를 붙이면 왼쪽 정렬이 돼요. (% 방식은 가운데 정렬 기호가 따로 없어요.)
2. format() 함수 — 문자열의 {} 자리에 값을 순서대로, 또는 번호로 채워요.
print("이름: {}, 점수: {}점".format(name, score))
# 이름: 민준, 점수: 90점

print("{0}의 점수는 {1}점, {0}은(는) 합격!".format(name, score))
# 민준의 점수는 90점, 민준은(는) 합격!
{} 안에 숫자(인덱스)를 넣으면 순서를 지정하거나 같은 값을 여러 번 쓸 수 있어요. 인덱스를 생략하면 왼쪽부터 순서대로 채워져요.
pi = 3.14159265
name = "민준"

print("원주율: {:.2f}".format(pi))     # 원주율: 3.14
print("[{:<10}]".format(name))         # [민준      ]   (왼쪽 정렬)
print("[{:>10}]".format(name))         # [      민준]   (오른쪽 정렬)
print("[{:^10}]".format(name))         # [   민준   ]   (가운데 정렬)
format()도 % 방식보다 훨씬 편하게, {} 안에 :<, :>, :^, :.nf 기호를 넣어서 정렬과 소수 자리수를 지정해요. 뒤에서 배울 f-string도 이 문법을 그대로 물려받았어요.
3. f-string (파이썬 3.6+, 가장 많이 씀) — 문자열 앞에 f를 붙이고 {} 안에 변수나 계산식을 바로 써요.
print(f"이름: {name}, 점수: {score}점")
# 이름: 민준, 점수: 90점

print(f"{name}의 점수는 {score + 10}점")   # 계산식도 바로 가능
# 민준의 점수는 100점
f-string은 가장 짧고 읽기 쉬워서 요즘 파이썬 코드의 표준처럼 쓰여요. 이 강의의 다른 예제들도 대부분 f-string을 사용해요.
방식문법특징
% 방식"%s" % 값가장 오래됨, 여러 개는 튜플로
format()"{}".format(값)순서 지정({0},{1}) 가능
f-stringf"{값}"가장 짧음, 계산식도 바로 삽입

정렬과 소수 자리수는 세 방식 모두 : 뒤에 옵션을 붙여서 지정해요. f-string 기준으로 알아볼게요.

name = "민준"

print(f"[{name:<10}]")   # 왼쪽 정렬, 전체 10자리 → [민준      ]
print(f"[{name:>10}]")   # 오른쪽 정렬             → [      민준]
print(f"[{name:^10}]")   # 가운데 정렬             → [   민준   ]
print(f"[{name:*^10}]")  # 가운데 정렬, 빈칸을 *로 채움 → [***민준***]
<는 왼쪽 정렬, >는 오른쪽 정렬, ^는 가운데 정렬이에요. 뒤의 숫자는 전체 자리수(너비)를 뜻해요. 정렬 기호 앞에 문자를 적으면 그 문자로 빈칸을 채워요.
pi = 3.14159265

print(f"{pi:.2f}")     # 3.14    (소수 둘째 자리까지)
print(f"{pi:.4f}")     # 3.1416  (소수 넷째 자리까지)
print(f"{pi:10.2f}")   #       3.14  (전체 10자리, 소수 둘째자리, 오른쪽 정렬 기본)
.2f는 "소수점 아래 2자리까지, 실수(f)로 표시"라는 뜻이에요. 정렬 너비와 소수 자리수를 10.2f처럼 같이 쓸 수도 있어요.
기호의미예시
:<n왼쪽 정렬, 전체 n자리f"{x:<10}"
:>n오른쪽 정렬, 전체 n자리f"{x:>10}"
:^n가운데 정렬, 전체 n자리f"{x:^10}"
:.nf소수점 아래 n자리까지 반올림f"{x:.2f}"

02람다함수

lambda는 이름 없이 한 줄로 만드는 함수예요. lambda 매개변수: 반환값 형태예요.

def square(x):
    return x * x

square2 = lambda x: x * x

print(square(5), square2(5))   # 25 25
두 함수는 완전히 같은 일을 해요. lambda는 def를 짧게 줄인 것일 뿐이에요. 주로 sort, max, min의 key나 map, filter처럼 함수를 잠깐 한 번만 쓸 때 사용해요.
nums = [1, 2, 3, 4, 5]

squares = list(map(lambda x: x**2, nums))
evens = list(filter(lambda x: x % 2 == 0, nums))

print(squares)   # [1, 4, 9, 16, 25]
print(evens)      # [2, 4]
map(함수, 리스트)는 리스트의 모든 값에 함수를 적용해요. filter(함수, 리스트)는 함수 결과가 True인 값만 걸러내요.

03리스트 내포 (List Comprehension)

반복문으로 리스트를 만드는 코드를 한 줄로 줄일 수 있어요. 기본 형태부터 하나씩 넓혀볼게요.

# 반복문 버전
arr = []
for i in range(5):
    arr.append(i)
print(arr)
# [0, 1, 2, 3, 4]

# 리스트 내포로 바꾸면
arr = [i for i in range(5)]
print(arr)
# [0, 1, 2, 3, 4]
[표현식 for 변수 in 반복가능객체] 구조예요. 반복문 여러 줄이 한 줄로 줄어들어요.
1. 제곱값 저장
squares = [x**2 for x in range(1, 6)]
print(squares)   # [1, 4, 9, 16, 25]
2. 조건 넣기 — 짝수만 저장
evens = [x for x in range(1, 11) if x % 2 == 0]
print(evens)   # [2, 4, 6, 8, 10]
뒤에 if 조건을 붙이면 조건에 맞는 값만 골라낼 수 있어요.
3. 문자열 변환
nums = [1, 2, 3, 4]
result = [str(x) for x in nums]
print(result)
# ['1', '2', '3', '4']
4. 문자열 길이 저장
words = ["cat", "apple", "banana"]
length = [len(word) for word in words]
print(length)
# [3, 5, 6]
5. 2차원 리스트 만들기 — 리스트 내포를 중첩해서 쓰면 2차원 리스트(표, 행렬)도 한 줄로 만들 수 있어요.
# 3행 3열, 모든 값이 0인 2차원 리스트
grid = [[0 for _ in range(3)] for _ in range(3)]
print(grid)
# [[0, 0, 0], [0, 0, 0], [0, 0, 0]]
바깥쪽 for는 행(row)을, 안쪽 for는 그 행 안의 열(column)을 채워요. 안쪽 내포 하나가 통째로 바깥 리스트의 원소 하나가 되는 거예요.
주의 [[0] * 3] * 3처럼 만들면 안 돼요! 겉보기엔 결과가 같아 보이지만, 안쪽 리스트 [0, 0, 0] 하나를 3번 복사가 아니라 3번 "참조"하는 거예요. 그래서 한 행만 바꿔도 나머지 행이 전부 같이 바뀌는 문제가 생겨요.
# 잘못된 방법
wrong = [[0] * 3] * 3
wrong[0][0] = 9
print(wrong)
# [[9, 0, 0], [9, 0, 0], [9, 0, 0]]  → 한 칸만 바꿨는데 모든 행이 바뀜!

# 올바른 방법 (리스트 내포로 매번 새로 만들기)
right = [[0] * 3 for _ in range(3)]
right[0][0] = 9
print(right)
# [[9, 0, 0], [0, 0, 0], [0, 0, 0]]  → 원하는 대로 한 칸만 바뀜
[[0] * 3] * 3은 같은 리스트를 3번 가리키기만 해서 하나를 바꾸면 다 같이 바뀌어요. 리스트 내포 [[0] * 3 for _ in range(3)]는 for가 반복될 때마다 새로운 리스트를 매번 새로 만들기 때문에 이런 문제가 없어요. 2차원 리스트는 항상 리스트 내포로 만드는 습관을 들이세요.
# 구구단표(2~4단) 만들기
table = [[row * col for col in range(1, 6)] for row in range(2, 5)]
for line in table:
    print(line)
# [2, 4, 6, 8, 10]
# [3, 6, 9, 12, 15]
# [4, 8, 12, 16, 20]
6. zip과 함께 사용
name = ["Kim", "Lee", "Park"]
score = [90, 80, 95]

arr = [[n, s] for n, s in zip(name, score)]
print(arr)
# [['Kim', 90], ['Lee', 80], ['Park', 95]]
zip으로 두 리스트를 짝지은 다음, 리스트 내포로 [이름, 점수] 형태의 2차원 리스트를 한 줄로 만들 수 있어요.
7. if ~ else 사용 — 0보다 크면 그대로, 아니면 0으로 바꾸기
nums = [-3, 5, -1, 2]
result = [x if x > 0 else 0 for x in nums]
print(result)
# [0, 5, 0, 2]
[참일 때 값 if 조건 else 거짓일 때 값 for 변수 in 리스트] 형태예요. 조건 뒤에 if만 있으면 값을 걸러내고(필터), if ~ else가 있으면 조건에 따라 값을 바꿔요(변환).

04딕셔너리 내포 (Dict Comprehension)

딕셔너리 내포는 리스트 내포와 거의 동일한 문법이에요. 차이는 [] 대신 {}를 쓰고, key : value 형태로 적는다는 것뿐이에요.

기본 형태: {key : value for 변수 in 반복가능한객체}
1. 가장 기본
dic = {i: i * i for i in range(5)}
print(dic)
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
2. 리스트를 딕셔너리로
fruits = ["apple", "banana", "orange"]
dic = {fruit: len(fruit) for fruit in fruits}
print(dic)
# {'apple': 5, 'banana': 6, 'orange': 6}
3. 조건 넣기 — 짝수만 저장
dic = {i: i * i for i in range(10) if i % 2 == 0}
print(dic)
# {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}
4. zip과 함께 사용 ⭐
name = ["Kim", "Lee", "Park"]
score = [90, 80, 95]

dic = {n: s for n, s in zip(name, score)}
print(dic)
# {'Kim': 90, 'Lee': 80, 'Park': 95}
이것은 아래 코드와 같아요. dic = dict(zip(name, score)) — 짧게 쓰고 싶을 땐 dict(zip())을, 값을 가공하면서 만들고 싶을 땐 딕셔너리 내포를 써요.
5. value 변경
score = {
    "Kim": 80,
    "Lee": 95,
    "Park": 88
}

new_score = {k: v + 5 for k, v in score.items()}
print(new_score)
# {'Kim': 85, 'Lee': 100, 'Park': 93}
6. key와 value 바꾸기
score = {
    "Kim": 80,
    "Lee": 95,
    "Park": 88
}

new_dic = {v: k for k, v in score.items()}
print(new_dic)
# {80: 'Kim', 95: 'Lee', 88: 'Park'}
7. if ~ else 사용
nums = [1, 2, 3, 4, 5]
dic = {i: "짝수" if i % 2 == 0 else "홀수" for i in nums}
print(dic)
# {1: '홀수', 2: '짝수', 3: '홀수', 4: '짝수', 5: '홀수'}

05자주 쓰는 내장함수

내장함수(built-in function)는 import 없이 바로 쓸 수 있는 파이썬 기본 함수예요.

nums = [3, 7, 1, 9, 4]

print(len(nums))    # 5  (개수)

print(max(nums))    # 9  (최댓값)
print(min(nums))    # 1  (최솟값)

함수기능예시
len()길이(개수) 구하기len("안녕") → 2
sum()합계 구하기sum([1,2,3]) → 6
max() / min()최댓값 / 최솟값max([3,7,1]) → 7

sorted()정렬된 새 리스트 반환sorted([3,1,2]) → [1,2,3]

내장함수는 괄호 안에 값(인자)을 넣어 바로 결과를 돌려받는 함수예요. 직접 함수를 만들 필요 없이 파이썬이 미리 준비해둔 도구라고 생각하면 돼요.

all() / any() — 조건을 모두 만족하는지, 하나라도 만족하는지 검사해요.
nums = [2, 4, 6, 8]

print(all(n % 2 == 0 for n in nums))   # True   (모두 짝수)
print(any(n > 5 for n in nums))         # True   (하나라도 5보다 크면)

n = 10

print(bin(n))   # 0b1010  (2진수)

print(hex(n))   # 0xa     (16진수)

print(ord("A"))   # 65   (문자 → 코드값)
print(chr(65))    # A    (코드값 → 문자)
ord()는 문자를 숫자(코드값)로, chr()는 숫자를 문자로 바꿔요. 서로 반대 방향으로 동작해요.
reversed() — 순서를 거꾸로 뒤집어요.
nums = [1, 2, 3, 4, 5]
print(list(reversed(nums)))
# [5, 4, 3, 2, 1]

filter() — 조건에 맞는 값만 걸러내요.
nums = [1, 2, 3, 4, 5, 6]
result = list(filter(lambda x: x % 2 == 0, nums))
print(result)

set() — 리스트를 집합으로 바꿔서 중복된 값을 제거해줘요.
nums = [1, 2, 2, 3, 3, 3, 4]

print(set(nums))         # {1, 2, 3, 4}
print(list(set(nums)))   # [1, 2, 3, 4]

any()하나라도 참이면 Trueany([False, True]) → True

chr()코드값 → 문자chr(65) → 'A'

06key로 비교 기준 정하기

max(), min(), sorted()에 key=를 넣으면 "무엇을 기준으로" 비교할지 정할 수 있어요.

names = ["철수", "영희", "김도현", "박"]

print(max(names, key=len))     # 김도현 (가장 긴 이름)
print(min(names, key=len))     # 박 (가장 짧은 이름)
print(sorted(names, key=len))  # ['박', '철수', '영희', '김도현']
key=len은 "이름의 길이를 기준으로 비교해줘"라는 뜻이에요. 원래 값은 그대로 두고, 비교할 때만 key 함수가 계산한 결과를 사용해요.

딕셔너리에서도 key를 활용할 수 있어요.

print(min(scores, key=scores.get))   # 지훈
scores.get은 "이름을 넣으면 점수를 돌려주는" 함수예요. 그래서 max(scores, key=scores.get)은 "점수가 가장 높은 이름"을 찾아줘요.

리스트 안에 리스트가 들어있을 때도 람다(lambda)로 key를 지정하면 원하는 위치의 값을 기준으로 비교할 수 있어요.

    ["Kim", 80],
    ["Lee", 95],
    ["Park", 88]
]

# ['Lee', 95]
key=lambda x: x[1]은 "각 리스트(x)의 두 번째 값(x[1])을 기준으로 비교해줘"라는 뜻이에요. x[0]으로 바꾸면 이름 기준, x[1]로 하면 점수 기준으로 비교돼요.

10리스트 정렬(sort/sorted)

리스트를 정렬하는 방법을 기본 정렬 → key 활용 순서로 하나씩 알아볼게요.

1. 기본 정렬 — key 없이 sort()만 쓰면 작은 값부터 큰 값 순서로 정렬돼요.
nums = [5, 2, 8, 1]
nums.sort()
print(nums)
# [1, 2, 5, 8]
.sort()는 원본 리스트를 바로 바꿔요. 반환값은 없고, nums 자체가 정렬된 상태로 바뀌어요.
2. 절댓값 기준 정렬 — key=abs를 쓰면 부호를 무시하고 크기(절댓값) 순으로 정렬해요.
nums = [-5, 2, -1, 8]
nums.sort(key=abs)
print(nums)
# [-1, 2, -5, 8]
절댓값 순으로 정렬돼요. -1(절댓값 1) → 2(절댓값 2) → -5(절댓값 5) → 8(절댓값 8) 순서예요.
3. 문자열 길이 기준 — key=len을 쓰면 글자 수가 적은 순서로 정렬해요.
words = ["banana", "cat", "apple", "kiwi"]
words.sort(key=len)
print(words)
# ['cat', 'kiwi', 'apple', 'banana']
4. 2차원 리스트 정렬 (가장 중요!) — 학생 이름과 점수처럼 리스트 안에 리스트가 있을 때도 람다(lambda)로 key를 지정하면 원하는 값 기준으로 정렬할 수 있어요.
students = [
    ["Kim", 80],
    ["Lee", 95],
    ["Park", 88]
]

# 점수(x[1]) 기준 정렬
students.sort(key=lambda x: x[1])
print(students)
# [['Kim', 80], ['Park', 88], ['Lee', 95]]

    "Lee": 95,
    "Park": 88
}

2. value(값) 기준 정렬 ⭐ 가장 중요 — .items()로 (키, 값) 쌍을 꺼내고, key=lambda x: x[1]로 값을 기준으로 정렬해요.

                key=lambda x: x[1],
                reverse=True)

# [('Lee', 95), ('Park', 88), ('Kim', 80)]

result = sorted(score.items(), key=lambda x: x[0])
print(result)
# [('Kim', 80), ('Lee', 95), ('Park', 88)]

12반올림 round와 math 함수

round(숫자, 자리수)는 반올림해요. 자리수를 생략하면 정수로 반올림해요.

1. 양수 반올림
print(round(3.456, 2))   # 3.46
print(round(3.456, 1))   # 3.5
print(round(3.5))         # 4
print(round(4.5))         # 4
주의 round(4.5)는 5가 아니라 4가 나와요! 파이썬의 round()는 .5를 무조건 올리지 않고 가장 가까운 짝수로 반올림해요(뱅커스 라운딩, Banker's Rounding). 4.5는 4와 5 중 짝수인 4로, round(3.5)는 3과 4 중 짝수인 4로 반올림돼요.
2. 음수 반올림
print(round(-2.5))         # -2
print(round(-3.5))         # -4
print(round(-3.456, 1))   # -3.5
음수에서도 뱅커스 라운딩 규칙이 그대로 적용돼요. -2.5는 -2와 -3 중 짝수인 -2로, -3.5는 -3과 -4 중 짝수인 -4로 반올림돼요.
3. 뱅커스 라운딩 대신 일반적인 반올림하기 — 학교에서 배운 것처럼 ".5는 무조건 올림"하고 싶다면, 0.5를 더한 뒤 내림(floor)하는 방법을 쓸 수 있어요.
import math

def round_half_up(x):
    return math.floor(x + 0.5)

print(round(2.5))            # 2   (뱅커스 라운딩)
print(round_half_up(2.5))    # 3   (일반적인 반올림)

print(round(4.5))            # 4
print(round_half_up(4.5))    # 5
x에 0.5를 더하면 소수점 아래가 .5 이상인 값은 항상 다음 정수 쪽으로 넘어가고, 그 상태에서 math.floor()로 내리면 ".5는 무조건 올림"하는 일반적인 반올림이 완성돼요.
4. int()로 내림할 때의 차이점 — int()도 소수점을 없애주지만, math.floor()와 동작 방식이 달라요.
import math

print(int(3.7))            # 3   (버림, 0 방향으로 자름)
print(math.floor(3.7))     # 3   (내림, 음의 무한대 방향)

print(int(-3.7))           # -3   ← 0에 가까운 쪽으로 자름
print(math.floor(-3.7))    # -4   ← 더 작은 정수(음의 무한대)로 내림
양수에서는 int()와 math.floor()가 같은 결과를 줘요. 하지만 음수에서는 결과가 달라져요. int()는 소수점 이하를 그냥 잘라내서 0에 가까운 쪽으로 가고(버림, truncate), math.floor()는 항상 더 작은 정수(음의 무한대 방향)로 내려가요.
5. 실수(float)의 오차 때문에 생기는 반올림 결과 — 컴퓨터는 실수를 2진수로 저장하는데, 0.1이나 3.45 같은 값은 2진수로 딱 맞아떨어지지 않아서 아주 살짝 다른 값으로 저장돼요.
print(round(3.45, 1))         # 3.5  (뱅커스 라운딩대로면 3.4여야 할 것 같은데?)
print(format(3.45, '.20f'))   # 3.45000000000000017764 ← 실제 저장된 값
뱅커스 라운딩 규칙만 생각하면 3.45는 3.4와 3.5 중 짝수인 3.4가 나와야 할 것 같지만, 실제로는 3.45가 컴퓨터 안에 3.45보다 아주 살짝 큰 값(3.450000000000000177...)으로 저장돼 있어요. 그래서 정확히 "반반 걸친 값"이 아니라 3.5에 더 가까운 값이 되어버려서 3.5로 반올림되는 거예요. 이런 오차는 뱅커스 라운딩과는 별개로, 실수를 2진수로 표현할 때 생기는 부동소수점 오차 때문에 생겨요. 금액 계산처럼 정확한 소수 계산이 꼭 필요하다면 decimal 모듈을 사용하는 게 안전해요.
6. 반올림해서 10 단위, 100 단위로 만들기 — round()의 자리수 자리에 음수를 넣으면 소수점이 아니라 정수 부분을 10 단위, 100 단위...로 뭉뚱그려 반올림할 수 있어요.
print(round(1234, -1))   # 1230   (10 단위로 반올림)
print(round(1256, -1))   # 1260

print(round(1234, -2))   # 1200   (100 단위로 반올림)
print(round(1256, -2))   # 1300

print(round(1500, -3))   # 2000   (1000 단위로 반올림, 뱅커스 라운딩: 1과 2 중 짝수인 2)
print(round(2500, -3))   # 2000   (뱅커스 라운딩: 2와 3 중 짝수인 2 → 3000이 아니라 2000!)
round(x, -1)은 일의 자리 값을 보고 반올림 여부를 정해서 결과를 10 단위로 만들고, round(x, -2)는 십의 자리 값을 보고 반올림해서 결과를 100 단위로 만들어요. 즉 "몇의 자리에서 반올림한다"는 건 그 자리 값을 기준으로 올릴지 버릴지 정한다는 뜻이지, 결과가 그 자리에서 끝난다는 뜻이 아니에요. n이 음수일 때도 자리수는 "소수점 기준 몇 번째 자리"라는 규칙이 그대로 적용되고(양수면 소수점 오른쪽, 음수면 소수점 왼쪽), .5가 걸치는 경우엔 여기서도 뱅커스 라운딩이 적용돼요.

math 모듈을 불러오면 올림, 내림, 제곱근 같은 함수를 쓸 수 있어요.

13global 키워드

global은 함수 안에서 전역변수(global variable)를 수정할 때 사용하는 키워드예요.

1. 전역변수란? — 함수 밖에서 만든 변수예요.
x = 10

def func():
    print(x)

func()
# 10
전역변수는 읽기만 하는 것은 global 없이도 가능해요. 함수 안에서 바깥 변수의 값을 그냥 들여다보는 건 문제가 없어요.
2. 전역변수를 수정하려면 global이 필요해요
x = 10

def func():
    global x
    x = 20

func()
print(x)
# 20
global x는 "함수 안의 x는 새로운 지역변수가 아니라 전역변수 x를 사용하겠다"는 의미예요.
3. global이 없으면?
x = 10

def func():
    x = 20

func()
print(x)
# 10
함수 안의 x는 바깥의 x와는 전혀 다른, 새로운 지역변수(local variable)가 만들어진 거예요.
# 전역: x = 10
#
# func() 실행 중에는
#   지역: x = 20   (전역 x와는 별개의 값)
#
# 함수가 끝나면 지역 x는 사라지고, 전역 x = 10 그대로 남는다
4. 가장 많이 하는 실수 — UnboundLocalError
x = 10

def func():
    x += 1

func()
# UnboundLocalError: local variable 'x' referenced before assignment
파이썬은 x += 1을 x = x + 1로 해석해요. 함수 안에 x = ... 형태가 있으니 파이썬은 "이 x는 지역변수구나"라고 먼저 판단해버려요. 그런데 오른쪽의 x를 읽으려는 순간, 아직 지역변수 x가 만들어지기 전이라 오류가 발생해요.
5. 올바른 방법
x = 10

def func():
    global x
    x += 1

func()
print(x)
# 11
6. global은 가급적 사용하지 않는 것이 좋아요
# global을 사용하는 방식
cnt = 0

def dfs():
    global cnt
    cnt += 1

# 매개변수와 반환값을 사용하는 방식 (더 안전!)
def dfs(cnt):
    cnt += 1
    return cnt
global은 함수가 어디서 어떤 값을 바꾸는지 추적하기 어렵게 만들어서, 코드가 커질수록 버그의 원인이 되기 쉬워요. 가능하면 매개변수로 값을 받고 return으로 결과를 돌려주는 방식이 더 안전하고 유지보수하기 좋아요.
7. 예외: 리스트·딕셔너리는 global 없이도 내용을 바꿀 수 있어요
scores = []

def add_score(s):
    scores.append(s)   # global 없이도 정상 동작!

add_score(90)
add_score(85)
print(scores)
# [90, 85]
append()는 리스트를 새로 만드는 게 아니라 기존 리스트의 내용만 바꾸는(mutate) 동작이에요. x = ...처럼 변수에 새 값을 다시 대입하는 게 아니기 때문에 global이 필요 없어요. list, dict처럼 변경 가능한(mutable) 객체는 안의 값만 바꿀 때는 global 없이도 함수 안에서 수정할 수 있어요.
