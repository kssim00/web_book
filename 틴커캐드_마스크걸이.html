고양이와 함께! 나만의 마스크걸이 만들기

오늘은 틴커캐드로 멋진 마스크걸이를 만들어 볼 거예요. 인터넷에서 가져온 고양이 그림 위에 마스크를 걸 수 있는 걸이대를 딱 맞게 붙여 볼게요. 그다음에는 문자 도형으로 엄마, 아빠 글자가 새겨진 마스크걸이도 만들어 볼 거예요. 자, 그럼 함께 시작해 볼까요?

1그림 파일 가져오기
✏️ 따라하기
  1. 인터넷에서 마음에 드는 그림을 찾아요.
  2. 그림 파일을 SVG 파일로 바꿔 두어요.
  3. 틴커캐드에서 새 디자인을 열어요.
  4. 오른쪽 위 가져오기를 눌러요.
2이미지 크기 조정하기
✏️ 따라하기
  1. 가져온 그림을 선택해요.
  2. 그림이 너무 크면 빨간 글씨 안내가 나와요.
  3. 중심 조정을 아트로 바꿔요.
  4. 길이 칸의 숫자를 줄이면 폭도 함께 줄어요.
3상자 두 개로 걸이대 모양 만들기
✏️ 따라하기
  1. 기본 도형에서 상자를 두 개 가져와요.
  2. 첫 번째 상자는 가로 4, 세로 4, 높이 12로 바꿔요.
  3. 두 번째 상자는 가로 4, 세로 6, 높이 4로 바꿔요.
  4. 두 상자 모두 반지름을 2로 바꿔서 모서리를 부드럽게 해요.
4정렬하고 묶어서 갈고리 만들기
✏️ 따라하기
  1. 상자 두 개를 함께 선택해요.
  2. 정렬을 눌러서 가로는 가운데로 맞춰요.
  3. 세로는 아랫점, 높이는 맨 위로 맞춰요.
  4. 모양이 갈고리처럼 되면 묶기를 눌러요.
5눈금자로 고양이 크기 재기
✏️ 따라하기
  1. 화면 오른쪽 위 눈금자를 눌러요.
  2. 고양이 그림의 끝부분을 클릭해요.
  3. 눈금자를 고양이에 가져다 대요.
6고양이 높이 확인하기
✏️ 따라하기
  1. 눈금자를 댄 채로 고양이를 클릭해요.
  2. 고양이의 높이가 36으로 나와요.
  3. 이 숫자를 기억해 두어요.
7걸이대 높이를 고양이에 맞추기
✏️ 따라하기
  1. 갈고리 도형을 클릭해요.
  2. 높이를 10으로 바꿔 줘요.
  3. 걸이대가 고양이 크기에 딱 맞아요.
  4. 다 됐으면 눈금자를 다시 눌러서 없애요.
8걸이대 회전시키기
✏️ 따라하기
  1. 갈고리 도형을 선택해요.
  2. 위쪽 회전 화살표를 눌러요.
  3. -90도로 돌려서 눕혀 줘요.
9걸이대를 고양이 위에 올리기
✏️ 따라하기
  1. 누운 갈고리를 고양이 위쪽으로 옮겨요.
  2. 갈고리 부분이 위로 보이게 자리를 맞춰요.
10한 번 더 돌려서 자연스럽게 만들기
✏️ 따라하기
  1. 걸이대를 클릭해요.
  2. 위쪽 회전 모양을 잡고 -90도 더 돌려요.
  3. 걸이대가 고양이 위에 자연스럽게 걸쳐져요.
11고정하고 묶어서 완성하기
✏️ 따라하기
  1. 걸이대 위치가 마음에 들면 그대로 두어요.
  2. 고양이와 걸이대를 함께 선택해요.
  3. 묶기를 눌러서 하나로 합쳐요.
  4. 고양이 마스크걸이가 완성됐어요!
12같은 방법으로 또 만들어 보기
✏️ 따라하기
  1. 이번에는 원통 도형으로 새로운 마스크걸이를 만들어요.
  2. 같은 방법으로 작은 상자 걸이대를 붙여요.
13문자 도형 가져오기
✏️ 따라하기
  1. 기본 도형 목록에서 문자 도형을 찾아요.
  2. 문자 칸에 원하는 글자를 적어요.
  3. 여기서는 엄마라는 글자를 써 볼게요.
14글자 크기와 위치 맞추기
✏️ 따라하기
  1. 글자 도형을 원통 위에 올려요.
  2. 크기를 원통에 맞게 줄여요.
  3. 글자가 원통 옆으로 빠지지 않게 맞춰요.
  4. 옆에서 보면서 높이도 살짝 조정해요.
15구멍으로 글자 파서 완성하기
✏️ 따라하기
  1. 글자 도형을 클릭해요.
  2. 오른쪽 메뉴에서 구멍을 선택해요.
  3. 원통과 함께 선택하고 묶기를 눌러요.
  4. 엄마, 아빠 글자가 새겨진 마스크걸이가 완성됐어요!
16완성하고 출력하기
사진이 없어요.
설명을 잘 읽고 따라해 봐요!
✏️ 따라하기
  1. 완성한 작품을 잘 살펴봐요.
  2. 마음에 들면 파일로 저장해요.
  3. 3D프린터로 출력하면 진짜 마스크걸이가 돼요.
