코드로 만드는 대포 게임! (직접 코딩해보기)

이번엔 코드를 그대로 베끼지 않아요. 힌트를 보고 스스로 빈 곳을 채워서 대포 게임을 완성해봐요.

코드를 전부 보면서 배우고 싶다면 → 정답이 모두 있는 버전

각도를 맞추고 스페이스바로 발사! 포탄이 곡선을 그리며 날아가요.
1

오늘의 미션

오늘은 각도를 조절해서 포탄을 발사하고, 목표 지점을 맞히면 성공하는 대포 게임을 만들어볼 거예요. 이번 학습지는 일부 코드만 주어지고, 나머지는 여러분이 직접 채워야 해요.

1
위/아래 화살표로 대포의 발사 각도를 조절해요.
2
스페이스바를 누르면 포탄이 곡선을 그리며 날아가요.
3
포탄이 땅에 떨어졌을 때, 목표 지점과 가까우면 명중이에요.
4
명중하면 "Good!", 빗나가면 "Bad!" 글씨가 나타나요.
이번 학습지의 규칙 — 챕터 3, 4, 5에는 코드가 일부만 주어져요. "생각해 보기"와 "메서드 힌트"를 참고해서 나머지를 스스로 완성해보세요. 막혀도 괜찮아요, 힌트 단추를 눌러보면 돼요! 💪
2

대포(거북이) 만들기

🎯 미션 · 직접 코딩

목표: 거북이 모양을 대포처럼 쓰고, 펜 굵기를 조금 두껍게 한 다음, 선 없이 발사할 자리 (-200, 10)로 이동시킵니다.

import turtle as t import random t.shape("turtle") t.pensize(3) # 여기에 코드를 작성하세요 (펜을 들고, 색을 "pink"로, (-200, 10)으로 이동)
생각해 보기
  • 거북이가 자리를 옮길 때 선이 그려지지 않도록 먼저 펜을 들어요.
  • 대포 색깔을 "pink"로 정해요.
  • 발사할 자리인 (-200, 10)으로 이동시켜요.
💡 메서드 힌트 보기
  • 펜 들기→up()
  • 색 바꾸기→color("색이름")
  • 이동하기→goto(x, y)

기억하기 · up()은 펜을 들어서, 이동해도 선이 그려지지 않게 해요. 대포가 자리를 옮길 때 괜히 선이 그려지면 안 되니까요.

2~3단계를 다 완성하면 이렇게 땅(분홍 선), 목표 지점(하늘색 구간), 대포(분홍 거북이)가 자리 잡아야 해요.
3

땅과 목표 지점 그리기

🎯 미션 · 직접 코딩

목표: 땅을 그리고, random으로 목표 지점을 무작위로 정해서 표시한 다음, 대포를 처음 자리로 되돌립니다.

# [미션 1] 땅을 그립니다 # 여기에 코드를 작성하세요 (펜을 내리고, 왼쪽 끝에서 오른쪽 끝까지 이동) # [미션 2] 목표 지점을 무작위로 정해서 그립니다 target = random.randint(50, 150) # 여기에 코드를 작성하세요 (target-25 위치에서 target+25 위치까지 다른 색 선으로 표시) # [미션 3] 대포를 처음 자리로 되돌립니다 # 여기에 코드를 작성하세요 (색을 되돌리고, 펜을 들고 처음 위치로, 각도도 20도로)
생각해 보기
  • 미션 1은 펜을 내린 다음 t.goto()로 왼쪽 끝(-300, 0)에서 오른쪽 끝(300, 0)까지 이어서 그리면 돼요.
  • 미션 2는 이미 정해진 target 값을 이용해요. 펜 굵기와 색을 바꾸고, 펜을 들고 (target-25, 2)로 이동한 다음, 펜을 내려서 (target+25, 2)까지 그어요.
  • 미션 3은 색을 다시 "pink"로 바꾸고, 펜을 들고 처음 위치(-200, 10)로 돌아간 다음, 각도를 20도로 맞추면 끝이에요.
💡 메서드 힌트 보기
  • 펜 내리기 / 들기→down() · up()
  • 이동하기→goto(x, y)
  • 펜 굵기→pensize(숫자)
  • 색 바꾸기→color("색이름")
  • 각도 정하기→setheading(각도)

팁 · 펜을 들고(up) 이동한 다음 다시 내려야(down) 선이 원하는 곳에서부터 그려져요. up과 down 순서를 잘 생각해보세요.

4

방향키로 각도 조절하기

🎯 미션 · 직접 코딩

목표: 위쪽 화살표를 누르면 각도가 왼쪽으로, 아래쪽 화살표를 누르면 오른쪽으로 2도씩 바뀌도록 함수 두 개를 만들고 키보드와 연결합니다.

이번엔 코드가 하나도 없어요! — 이미 다른 게임에서 onkeypress()와 listen()을 배웠으니, 아래 힌트만 보고 처음부터 끝까지 직접 작성해보세요.
생각해 보기
  • 함수 이름은 자유롭게 정해도 되지만, 위쪽용 함수와 아래쪽용 함수 각각 하나씩 총 2개가 필요해요.
  • 각 함수 안에서는 거북이 방향을 왼쪽으로 2도 또는 오른쪽으로 2도 트는 코드 한 줄만 있으면 돼요.
  • 함수를 다 만들었다면, 키보드와 연결하고 키보드 입력을 받겠다는 명령도 잊지 마세요.
💡 메서드 힌트 보기
  • 왼쪽으로 각도 틀기→left(2)
  • 오른쪽으로 각도 틀기→right(2)
  • 키와 함수 연결→onkeypress(함수이름, "Up")
  • 키보드 감지 시작→listen()

팁 · onkeypress()에 함수 이름을 넣을 때는 괄호를 붙이지 않아요. onkeypress(turn_up, "Up")처럼요. 괄호를 붙이면 바로 실행되어 버려서 원하는 때에 실행되지 않아요.

스페이스바로 발사하기

🎯 미션 · 직접 코딩

목표: 스페이스바를 누르면 포탄이 곡선을 그리며 날아가도록 fire() 함수를 완성합니다.

def fire(): while t.ycor() > 0: # 포탄 높이가 땅보다 높은 동안 반복 # 여기에 두 줄을 작성하세요 t.onkeypress(fire, "space")
생각해 보기
  • while t.ycor() > 0: 은 이미 완성되어 있어요. "포탄의 높이가 땅(0)보다 높은 동안 계속 반복"하라는 뜻이에요.
  • 반복문 안에는 두 가지 동작이 필요해요: 앞으로 이동하기와 오른쪽으로 조금씩 방향 틀기.
  • 이 두 동작을 한 번씩만 하는 게 아니라 while문 안에서 계속 반복되기 때문에, 갈수록 방향이 점점 아래로 휘어져서 곡선처럼 보여요.
💡 메서드 힌트 보기
  • 앞으로 이동→forward(15)
  • 오른쪽으로 방향 틀기→right(5)

팁 · 숫자를 바꿔보면서 실험해도 좋아요. right()의 숫자를 더 크게 하면 더 급하게 휘어지는 곡선이 돼요.

6

명중했는지 확인하기

🎯 미션 · 직접 코딩

목표: 포탄이 땅에 떨어지면, 목표 지점과 얼마나 가까운지 거리를 재서 명중 여부를 알려줍니다.

# fire() 함수 안, while 반복문 다음 부분이에요 # (while 반복문은 5단계에서 이미 완성했어요) d = t.distance(target, 0) if d < 25: # 여기에 코드를 작성하세요 (색을 "blue"로 바꾸고 "Good!" 쓰기) else: # 여기에 코드를 작성하세요 (색을 "red"로 바꾸고 "Bad!" 쓰기)
생각해 보기
  • d는 포탄이 떨어진 곳과 목표 지점 사이의 거리예요.
  • d가 25보다 작으면 명중, 아니면 빗나간 거예요. if / else로 나눠서 처리해요.
  • 명중이면 색을 "blue"로 바꾸고 "Good!"을, 빗나가면 색을 "red"로 바꾸고 "Bad!"를 화면에 써요.
💡 메서드 힌트 보기
  • 색 바꾸기→color("색이름")
  • 글씨 쓰기→write("글자", False, "center", ("", 15))

distance(target, 0)이 하는 일 · 지금 포탄이 있는 위치에서 좌표 (target, 0)까지의 거리를 계산해요. 이 거리가 25보다 작으면 목표 지점에 아주 가깝게 떨어졌다는 뜻이에요.

명중하면 파란색으로 "Good!"
빗나가면 빨간색으로 "Bad!"
