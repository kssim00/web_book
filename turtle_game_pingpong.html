코드로 만드는 핑퐁 게임!

빨간 공 하나를 움직이는 것부터 시작해서, 벽에 튕기고, 파란 공과 부딪히고, 마지막엔 키보드로 조종하는 진짜 핑퐁게임까지 4단계로 만들어봐요.

이 수업의 규칙 — 새로 배우는 핵심 코드는 크게 보여줄게요. 이미 배운 세팅 코드는 여러분이 직접! 막히면 그때 전체 코드를 살짝 열어 보세요. 👀

1

오늘의 미션

공을 스스로 움직이고, 튕기고, 부딪히게 만드는 4단계 여행이에요. 각 단계는 앞 단계의 코드를 그대로 이어받아 자라납니다.

1
[1단계] 오른쪽 위의 빨간 공을 움직이고 → for문으로 벽에서 튕기고 → while True + 스위치(dx)로 영원히 왕복시켜요.
2
[2단계] 왼쪽에 파란 공을 추가하고, 하나의 반복문 안에서 두 공을 동시에 움직여요.
3
[3단계] 두 공 사이의 거리(distance)를 재서, 만나면 서로 튕겨 나가게 해요.
4
[4단계] 패들 + 키보드 조작 + 점수판을 넣어 진짜 핑퐁게임을 완성해요!
먼저 알아두기 — 터틀 화면의 좌표 — 터틀 화면은 정가운데가 (0, 0)이에요. 오른쪽으로 갈수록 x가 커지고, 위로 갈수록 y가 커져요. 화면을 600×400으로 만들면 x는 −300 ~ +300, y는 −200 ~ +200이 됩니다.
2

공을 움직이는 마법의 한 줄

1단계

먼저 화면과 빨간 공을 준비하고, 공을 움직이는 딱 한 줄의 새 코드를 배워요.

✏️ 세팅은 직접! — 지난 시간에 배운 것들로 만들어 보세요

1
가로 600, 세로 400짜리 화면 만들기
2
거북이 ball 만들기 → 동그라미 모양, 빨간색
3
움직일 때 선이 안 그려지게 펜 들기
4
오른쪽 위 (200, 150)으로 순간이동시키기

🔑 힌트 — 이 함수들을 하나씩 쓰면 됩니다 : Screen()setup( , ) Turtle()shape("circle") color( )penup()goto( , )

세팅이 끝났나요? 오늘 새로 배우는 코드는 이것 하나입니다.

⭐ 오늘의 핵심 코드
ball.setx( ball.xcor() + 1 )

읽는 법 : "지금 x좌표(xcor)에 1을 더한 값으로, x좌표를 바꿔라(setx)" = 오른쪽으로 1칸 이동!

xcor()과 setx() — xcor()은 "지금 공의 x좌표가 뭐야?"라고 물어보는 함수이고, setx()는 "x좌표를 이 값으로 바꿔!"라고 명령하는 함수예요. 이 한 줄을 for문으로 여러 번 반복하면 공이 스르륵 움직입니다.

🧪 직접 실험하기

1
핵심 코드를 for문으로 300번 반복시켜 보세요. 공이 어느 쪽으로 가나요?
2
공이 왼쪽으로 가게 하려면 + 1을 어떻게 바꿔야 할까요?
3
숫자를 5로 바꾸면 무엇이 달라지나요?

🔑 힌트 : for i in range(300): 다음 줄에 들여쓰기하고 핵심 코드를 넣으세요.

👀 전체 코드 확인하기 직접 써 본 다음에 열기!
import turtle # 화면 설정 screen = turtle.Screen() screen.setup(600, 400) # 빨간 공 만들기 ball = turtle.Turtle() ball.shape("circle") ball.color("red") ball.penup() ball.goto(200, 150) for i in range(300): ball.setx(ball.xcor() - 1) # -1 이니까 왼쪽으로!

노란 줄 = 오늘의 핵심 코드가 들어간 자리

3

왜 dx가 필요할까? — 방향 전환의 비밀

1단계

공이 왼쪽으로만 가다가 화면 밖으로 사라졌죠? 벽에 닿으면 반대 방향으로 튕기게 하고 싶은데, 여기서 문제가 생겨요.

숫자를 직접 쓰면 생기는 문제 — 코드에 - 1이라고 숫자를 박아 놓으면, 공은 영원히 왼쪽으로만 갈 수밖에 없어요. 프로그램이 실행되는 도중에 우리가 코드를 지우고 + 1로 고쳐 쓸 수는 없으니까요! 그래서 "지금 어느 방향으로 가는 중인지"를 기억하는 변수가 필요해요. 그 변수가 바로 dx입니다.
dx = -1
⬅️ dx가 음수면 x가 줄어듦
= 왼쪽으로 이동 중
dx = +1
➡️ dx가 양수면 x가 늘어남
= 오른쪽으로 이동 중

벽에 닿는 순간, dx = -dx 한 줄이면 부호가 뒤집혀서 방향 전환! (−1 ↔ +1)

⭐ 오늘의 핵심 코드
ball.setx( ball.xcor() + dx ) if ball.xcor() < -290: dx = -dx

이동 거리를 숫자 대신 변수 dx로! → 왼쪽 벽(x < −290)에 닿으면 dx의 부호를 뒤집어 방향 전환

🧪 직접 만들어 보기

1
for문 위에 dx = -1을 선언하세요. (공이 왼쪽으로 출발하도록)
2
2장의 이동 코드에서 숫자 자리를 dx로 바꾸세요.
3
이동 코드 아래에 왼쪽 벽 검사 if문을 추가하세요.
4
실행! 공이 왼쪽 벽에서 한 번 튕겨서 되돌아오나요?

🔑 생각해 보기 : dx가 −1일 때 dx = -dx를 지나면 dx는 몇이 될까요? 그럼 그 다음엔 공이 어느 쪽으로 갈까요?

👀 전체 코드 확인하기 직접 써 본 다음에 열기!
# ... 화면·공 세팅은 2장과 같음 ... dx = -1 # 방향을 기억하는 변수 (−니까 왼쪽으로 출발) for i in range(1000): ball.setx(ball.xcor() + dx) # 숫자 대신 dx만큼 이동 if ball.xcor() < -290: # 왼쪽 벽에 닿았으면 dx = -dx # 부호 반전 = 방향 전환!

노란 줄 = 이번 장에서 새로 추가·바뀐 코드

4

영원히 반복하기 — while True

1단계

for문은 정해진 횟수가 끝나면 멈춰 버려요. 게임 속 공은 멈추면 안 되죠! while True:는 "조건이 항상 참이니까 영원히 반복해"라는 뜻이에요.

⭐ 오늘의 핵심 코드
while True: ball.setx( ball.xcor() + dx ) if ball.xcor() < -290 or ball.xcor() > 290: dx = -dx

for → while True로 바꾸고, or로 오른쪽 벽 조건까지 추가 → 좌우로 영원히 왕복!

🧪 직접 만들어 보기

1
3장 코드에서 for i in range(1000): 줄만 while True:로 바꾸세요.
2
if문에 or를 써서 오른쪽 벽(x > 290) 조건을 추가하세요.
3
실행하면 공이 좌우로 계속 왔다갔다! 이게 1단계 완성입니다 🎉
여기까지 정리 — dx는 방향을 기억하는 스위치, while True는 게임의 심장 박동(게임 루프)이에요. 앞으로 만들 모든 게임이 이 두 재료로 돌아갑니다.
👀 1단계 완성 코드 확인하기 직접 써 본 다음에 열기!
import turtle screen = turtle.Screen() screen.setup(600, 400) ball = turtle.Turtle() ball.shape("circle") ball.color("red") ball.penup() ball.goto(200, 150) dx = -1 while True: # 영원히 반복! ball.setx(ball.xcor() + dx) if ball.xcor() < -290 or ball.xcor() > 290: dx = -dx

노란 줄 = 이번 장에서 새로 추가·바뀐 코드

🏆 1단계 도전 과제

5

왼쪽에 파란 공 추가하기

2단계

왼쪽에 파란 공을 하나 더 만들어서, 두 공이 동시에 좌우로 튕기며 움직이게 해요. 공이 두 개면 변수도 두 벌!

✏️ 세팅은 직접! — 1단계에서 했던 그대로, 이름만 바꿔서

1
기존 빨간 공의 이름을 ball → ball1, dx → dx1로 바꾸기
2
파란 공 ball2 만들기 → circle 모양, blue, 펜 들기, (−200, −150) 왼쪽 아래에서 출발
3
파란 공의 방향 변수 dx2 만들기 → 빨간 공과 반대 방향이니까 dx2 = dx1 * -1

🔑 스스로 점검 : 공이 2개면 "방향 기억 스위치"도 왜 2개 필요할까요? (두 공의 방향은 서로 다를 수 있으니까!)

진짜 중요한 건 이것 — 반복문은 하나만! 그 안에서 두 공을 번갈아 움직입니다.

⭐ 오늘의 핵심 코드 : 하나의 게임 루프
while True: # 빨간 공 한 칸 → 파란 공 한 칸 ball1.setx( ball1.xcor() + dx1 ) ball2.setx( ball2.xcor() + dx2 )

한 바퀴에 두 공을 1칸씩 번갈아 움직이면, 사람 눈에는 동시에 움직이는 것처럼 보여요!

dx2 = dx1 * -1 의 의미 — 어떤 수에 −1을 곱하면 부호가 뒤집혀요. dx1이 −1이니까 dx2는 +1이 되죠. 어디서 본 것 같지 않나요? 맞아요, 벽에서 튕길 때 쓴 dx = -dx와 완전히 같은 원리예요! (사실 -dx는 dx * -1을 짧게 쓴 것이랍니다.) 단, 이 계산은 그 순간의 값을 한 번 복사하는 것이라서, 나중에 dx1이 바뀌어도 dx2가 저절로 따라 바뀌지는 않아요. 그래서 두 스위치는 만들어진 뒤엔 각자 따로 움직입니다.
왜 while True를 두 개 쓰면 안 될까요? — 첫 번째 while True는 영원히 끝나지 않으니, 두 번째 반복문은 영영 실행될 기회가 없어요. 그래서 하나의 반복문 안에서 모든 공을 관리해야 해요. 이 반복문을 게임 프로그래밍에서는 게임 루프(game loop)라고 부릅니다.

🧪 직접 만들어 보기

while True 안에 빨간 공의 이동 + 벽 검사(1단계에서 만든 것)를 넣으세요.
2
그 바로 아래에 파란 공의 이동 + 벽 검사를 똑같은 모양으로 추가하세요. (dx2 사용!)
3
실행하면 두 공이 동시에 좌우로 튕겨 다닙니다.
👀 2단계 완성 코드 확인하기 직접 써 본 다음에 열기!
import turtle screen = turtle.Screen() screen.setup(600, 400) # 빨간 공 (오른쪽 위에서 출발, 왼쪽으로) ball1 = turtle.Turtle() ball1.shape("circle") ball1.color("red") ball1.penup() ball1.goto(200, 150) # 파란 공 (왼쪽 아래에서 출발, 오른쪽으로) ball2 = turtle.Turtle() ball2.shape("circle") ball2.color("blue") ball2.penup() ball2.goto(-200, -150) dx1 = -1 # 빨간 공 스위치 dx2 = dx1 * -1 # 파란 공 스위치 (빨간 공과 반대 방향 = +1) while True: # 빨간 공 ball1.setx(ball1.xcor() + dx1) if ball1.xcor() < -290 or ball1.xcor() > 290: dx1 = -dx1 # 파란 공 ball2.setx(ball2.xcor() + dx2) if ball2.xcor() < -290 or ball2.xcor() > 290: dx2 = -dx2

🏆 2단계 도전 과제

6

두 공이 만나면 튕기기

3단계

두 공 사이의 거리를 계산해서, 서로 부딪히면 둘 다 반대 방향으로 튕겨 나가게 해요. 충돌 검사는 distance() 한 줄이면 끝!

✏️ 세팅은 직접! — 2단계 코드에서 딱 하나만 수정

1
파란 공의 시작 위치를 (−200, 150)으로 바꾸세요. → 빨간 공과 같은 높이가 되어야 마주 보고 달려와 부딪힙니다!
⭐ 오늘의 핵심 코드
if ball1.distance(ball2) < 20: dx1 = -dx1 dx2 = -dx2

distance() = 두 거북이 사이의 직선 거리. 공 지름이 약 20이니, 거리가 20보다 작으면 충돌! → 둘 다 방향 전환

벽에 튕길 때와 원리가 똑같아요 — "조건을 검사하고 → 스위치의 부호를 뒤집는다." 벽 대신 상대 공과의 거리를 조건으로 쓴 것뿐이에요. 이 세 줄을 while True 안, 두 공의 이동 코드 아래에 넣으세요.
버그 주의! 부들부들 현상 — 공이 겹친 채로 다음 반복에서 또 거리가 20보다 작으면, 방향이 다시 뒤집혀서 공 두 개가 딱 붙어서 부들부들 떠는 현상이 생길 수 있어요. 해결법: 충돌 직후 ball1.setx(ball1.xcor() + dx1)처럼 한 칸 밀어내 주기. 직접 실험해 보세요!
👀 3단계 완성 코드 확인하기 직접 써 본 다음에 열기!
# ... 공 만드는 세팅은 2단계와 같음 ... ball1.goto(200, 150) # 빨간 공: 오른쪽 ball2.goto(-200, 150) # 파란 공: 왼쪽, 같은 높이! dx1 = -1 dx2 = dx1 * -1 # 빨간 공과 반대 방향으로 출발 while True: ball1.setx(ball1.xcor() + dx1) if ball1.xcor() < -290 or ball1.xcor() > 290: dx1 = -dx1 ball2.setx(ball2.xcor() + dx2) if ball2.xcor() < -290 or ball2.xcor() > 290: dx2 = -dx2 # ⭐ 두 공이 부딪혔나? (중심 거리 < 20) if ball1.distance(ball2) < 20: dx1 = -dx1 # 둘 다 방향 전환! dx2 = -dx2

🏆 3단계 도전 과제

7

진짜 핑퐁게임 완성하기

4단계

공 1개 + 패들 2개 + 키보드 조작 + 점수판! 지금까지 배운 스위치 · 게임 루프 · 충돌 검사를 총동원해요.

1
공은 대각선으로 움직인다 → dx, dy 스위치 두 개 (1단계 도전 과제!)
2
위·아래 벽에서 튕긴다 → 벽 검사 + 부호 반전 (1단계)
3
패들에 닿으면 튕긴다 → distance 충돌 검사 (3단계)
4
패들 뒤로 빠지면 상대 득점, 공은 가운데서 다시 출발 → 벽 검사의 응용
5
키보드로 패들 조작 → 오늘 새로 배우는 것!
조작파란 패들 (왼쪽)빨간 패들 (오른쪽)

화면이 뚝뚝 끊긴다면? tracer와 update — 터틀은 움직일 때마다 화면을 다시 그려서 느려요. 세팅 부분에 screen.tracer(0)을 쓰면 자동 그리기가 꺼지고, 게임 루프 맨 위에서 screen.update()를 부르면 한 프레임씩 직접 그려서 훨씬 부드러워져요.

import turtle screen = turtle.Screen() screen.title("나의 핑퐁게임") screen.bgcolor("black") screen.setup(600, 400) screen.tracer(0) # 자동 그리기 끄기 (직접 update로 그림) # 왼쪽 파란 패들 left_pad = turtle.Turtle() left_pad.shape("square") left_pad.shapesize(4, 1) # 세로 4배로 길쭉하게! left_pad.color("blue") left_pad.penup() left_pad.goto(-260, 0) # 오른쪽 빨간 패들 right_pad = turtle.Turtle() right_pad.shape("square") right_pad.shapesize(4, 1) right_pad.color("red") right_pad.penup() right_pad.goto(260, 0) # 공 ball = turtle.Turtle() ball.shape("circle") ball.color("white") ball.penup() ball.goto(0, 0) # 점수판 pen = turtle.Turtle() pen.hideturtle() pen.up() pen.color("white") pen.goto(0, 160) dx = 1 # 좌우 스위치 dy = 1 # 위아래 스위치 score_blue = 0 score_red = 0 def write_score(): pen.clear() pen.write("파랑 "+str(score_blue)+" : "+str(score_red)+" 빨강", align="center", font=("맑은 고딕", 16, "bold")) # 키보드로 패들 움직이기 def left_up(): if left_pad.ycor() < 150: left_pad.sety(left_pad.ycor() + 25) def left_down(): if left_pad.ycor() > -150: left_pad.sety(left_pad.ycor() - 25) def right_up(): if right_pad.ycor() < 150: right_pad.sety(right_pad.ycor() + 25) def right_down(): if right_pad.ycor() > -150: right_pad.sety(right_pad.ycor() - 25) screen.listen() # 키보드 입력 듣기 시작 screen.onkeypress(left_up, "w") screen.onkeypress(left_down, "s") screen.onkeypress(right_up, "Up") screen.onkeypress(right_down, "Down") write_score() while True: # 게임 루프 screen.update() # 이번 프레임 그리기 # 공 움직이기 (대각선) ball.setx(ball.xcor() + dx) ball.sety(ball.ycor() + dy) # 위·아래 벽에서 튕기기 if ball.ycor() > 180 or ball.ycor() < -180: dy = -dy # 패들에 맞으면 튕기기 if ball.distance(right_pad) < 45 and dx > 0: dx = -dx if ball.distance(left_pad) < 45 and dx < 0: dx = -dx # 패들 뒤로 빠지면 득점 → 공 리셋 if ball.xcor() > 290: # 오른쪽으로 빠짐 → 파랑 득점 score_blue = score_blue + 1 write_score() ball.goto(0, 0) dx = -dx if ball.xcor() < -290: # 왼쪽으로 빠짐 → 빨강 득점 score_red = score_red + 1 write_score() ball.goto(0, 0) dx = -dx
