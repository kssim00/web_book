1. 출력 print()

print()는 괄호 안의 값을 화면에 보여 주는 함수예요.

1) 문자열 출력하기

1. 문자열 출력하기

2. 에러가 발생하는 경우

⚠️ 주의! 아래처럼 따옴표 없이 문장을 입력하면 문법 오류(invalid syntax)가 발생해요.

❌ 왜 에러가 날까요?

3. 여러 값을 한 번에 출력하기

print("hello", "world")
💡
인수란?

  3. 인수가 여러 개면 쉼표(,)로 구분해요.

print()처럼 괄호 안에 아무런 내용을 넣지 않으면 '한 줄 띄우기' 역할을 합니다.

3) 여러 줄로 출력하기

1. print()를 여러 번 사용하기

print()는 기본적으로 출력한 뒤 줄을 바꿔요. 따라서 print()를 여러 번 사용하면 여러 줄로 출력할 수 있어요.

print("Hi!") print("I like Python.") print("Let's code!")

2. 따옴표 3개로 여러 줄 문자열 만들기

큰따옴표나 작은따옴표를 3개씩 사용해 문자열의 시작과 끝을 감싸면 줄바꿈도 문자열에 포함돼요. 그래서 print() 하나로 여러 줄을 출력할 수 있어요. 아래 코드는 위 예제와 같은 결과를 출력해요.

print("""Hi! I like Python. Let's code!""")

3. 한 줄에 여러 명령 쓰기

세미콜론(;)으로 명령을 구분하면 코드 한 줄에 여러 명령을 쓸 수 있어요. 코드가 한 줄이어도 각 print()가 줄을 바꾸므로 출력은 세 줄이 됩니다.

print("Hi!"); print("I like Python."); print("Let's code!")

처음에는 읽기 쉽도록 한 줄에 명령 하나씩 쓰는 습관을 들여요.

4) 숫자 출력하기

숫자는 따옴표 없이 입력하며, 컴퓨터가 바로 계산 결과를 출력할 수 있습니다.

1. 숫자와 문자열 비교하기

따옴표 밖의 식은 계산하고, 따옴표 안의 내용은 그대로 출력해요.

print(2 + 3) # 숫자: 계산 결과 출력 print("2 + 3") # 문자열: 적힌 내용 그대로 출력

예: 6 / 3 → 2.0

6) 공백 출력하기

코드에서 띄운 칸과 화면에 나오는 빈칸은 다를 수 있어요. 공백이 어디에 있는지 살펴봐요.

1. 따옴표 안의 공백은 그대로 나와요

따옴표 안의 빈칸도 문자열의 일부예요. 한 칸 넣으면 한 칸, 세 칸 넣으면 세 칸이 출력돼요.

print("Hi Python") print("Hi Python")

2. 쉼표로 나눈 값 사이에는 기본 한 칸이 생겨요

쉼표로 구분한 값을 출력하면 print()가 값 사이에 공백 한 칸을 넣어 줘요. 아래 세 코드의 결과는 같을까요, 다를까요?

print("Hi", "Python") print("Hi","Python") print("Hi", "Python")
기억해요
  1. 세 코드의 출력 결과는 같아요.
  2. 따옴표 밖의 쉼표 뒤 공백 수는 출력에 영향을 주지 않아요.
  3. 읽기 쉽게 쉼표 뒤는 한 칸 띄워 써요.

3. 두 공백이 만나면 더해져요

"Hi " 안의 공백 한 칸에 print()가 넣는 공백 한 칸이 더해져, 두 단어 사이가 두 칸이 돼요.

print("Hi ", "Python")
기억해요
Hi□□Python
"Hi " 안의 공백 1칸 + print()가 넣는 공백 1칸
→ 두 단어 사이에 공백 2칸이 생겨요.

7) 이스케이프 코드

이스케이프 코드는 역슬래시(\)와 문자를 조합해 특별한 기능을 넣는 방법이에요.

⌨ 역슬래시 입력하기

한국어 키보드에서는 보통 ₩ 표시가 있는 키를 눌러요.
글꼴에 따라 \가 ₩처럼 보일 수도 있어요.

1. \n : 줄바꿈

문자열 안에서 다음 줄로 내려가요. 따옴표 3개 대신 \n으로도 줄을 바꿀 수 있어요.

print("Hi\nPython")

2. \t : 탭(tab)

\t는 글자 사이를 다음 기준 위치까지 띄우는 탭이에요.
여러 줄의 글자를 같은 위치에 맞출 때 사용해요.

print("1234567812345678") print("Hi\tPython") print("Hello\tPython")
기억해요
탭 간격: 8칸 기준
Hi□□□□□□Python빈칸 6칸
Hello□□□Python빈칸 3칸
□ = 빈칸 1칸 · 이해를 돕기 위한 표시

앞의 글자 수가 달라도, 탭이 간격을 맞춰 주어 Python이 나란히 시작해요.

3. \\ : 역슬래시 

역슬래시 자체를 출력하려면 \\처럼 두 번 써요. 화면에는 역슬래시가 하나만 나와요.

print("Hi\\Python")

4. \' 또는 \" : 따옴표

① 앞에서 배운 방법: 다른 따옴표로 감싸기

바깥을 큰따옴표로 감싸면, 안쪽의 작은따옴표를 그대로 쓸 수 있어요.

print("Let's code!")

② 새로운 방법: 역슬래시 붙이기

바깥을 작은따옴표로 감쌌다면, 안쪽 작은따옴표 앞에 역슬래시(\)를 붙여요.

print('Let\'s code!')

두 방법 모두 같은 결과가 나와요. 역슬래시는 안쪽 따옴표가 문자열을 끝내지 않도록 해 줘요.

5. 활용 예시: 탭으로 메뉴판 만들기

8) 인수 구분자와 출력 끝 설정하기

sep는 값 사이, end는 출력 끝에 넣을 문자를 바꿔요.

1. sep 옵션: 값 사이에 넣을 문자 정하기

sep로 값 사이에 넣을 문자를 정해요. 아래 세 가지 출력 결과를 비교해 보세요.

기본: 공백 한 칸

print("Hi", "Python")

원하는 문자로 구분

print("Hi", "Python", sep="~")

공백 없이 붙여 출력

print("Hi", "Python", sep="")

2. end 옵션: 출력 끝에 붙일 문자 정하기

print()는 기본적으로 출력 뒤에 줄을 바꿔요. end로 줄바꿈 대신 붙일 문자를 정할 수 있어요. 아래 세 가지 출력 결과를 비교해 보세요.

기본: 줄바꿈

print("Hi") print("Python")

공백으로 이어 출력

print("Hi", end=" ") print("Python")

느낌표로 이어 출력

print("Hi", end="!") print("Python")
기억해요

sep는 한 print() 안의 값 사이를, end는 그 print()의 출력 끝을 바꿔요.

MISSION
전화번호 출력하기

아래 코드에 sep를 추가해, 번호 사이에 하이픈(-)이 들어가도록 수정하세요.

print("010", "1234", "5678")
출력
010-1234-5678
정답
print("010", "1234", "5678", sep="-")
