1. 출력 print()

print()는 괄호 안의 메시지(인수)를 화면에 출력하는 명령어입니다.

print("hello world")
💡
예약어(Reserved word) 또는 키워드(Keyword)
- print와 같이 특정한 의미가 약속된 단어를 예약어라고 합니다. 
- 예약어는 용도가 정해져 있어 다른 목적으로 사용할 수 없습니다.
  예) print, if, while, for

1) 문자열 출력하기

1. 문자열 출력하기

⚠️ 주의! 따옴표 없이 글자만 입력하면 에러(invalid syntax)가 발생해요.

3) 문장 구분과 멀티 라인

1. 한 줄에 여러 명령 쓰기

파이썬은 원칙적으로 한 줄에 하나의 명령을 쓰지만, 세미콜론(;)을 사용하면 여러 명령을 한 줄에 나열할 수 있습니다.

print("파");print("이");print("팅")

2. 여러 줄 문자열 출력하기

큰따옴표나 작은따옴표를 3개 연속으로 쓰면 문장 안에서 줄 바꿈을 자유롭게 할 수 있습니다.

4) 숫자 출력하기

숫자는 따옴표 없이 입력하며, 컴퓨터가 바로 계산 결과를 출력할 수 있습니다.

💡
나누기(/) 연산자의 결과는 항상 실수
나누기(/)의 결과는 항상 실수(소수점이 있는 수)로 나옵니다.
➡️예) 6 / 3 같이 딱 나누어 떨어져도 결과는 2.0이 됩니다.

6) 공백 출력하기

파이썬은 쉼표와 문자열 내부의 공간을 통해 공백을 조절할 수 있습니다.

1. 문자열 안의 공백

공백도 하나의 문자열이므로, 문자열 안의 공백은 그대로 출력됩니다.

print("파 이 썬")

2. 인수 공백

쉼표로 구분된 인수는 기본적으로 한 칸의 공백을 만듭니다.

print("파","이","썬")

3. 쉼표 뒤의 공백

💡 쉼표 뒤의 물리적 공백은 출력 결과에 영향을 주지 않습니다. 단, 가독성을 위해 쉼표 뒤에 한 칸을 띄웁니다.

print("파","이","썬") print("파", "이", "썬") print("파", "이", "썬")

4. 문자열 내부 공백과 인수 공백 구분하기

문자열 내부 공백과 인수 공백으로 2개의 공백이 출력됩니다.

print("파 ", "이 ", "썬 ")

7) 이스케이프 코드

이스케이프 코드는 특수한 역할을 하는 문자 조합으로, 역슬래시(\)는 키보드의 ₩ 키를 누르면 입력됩니다.

1. \n : Enter

 다음 줄로 줄을 바꿀 때 사용합니다.

print("하이\n파이썬")

2. \t : 탭(tab)

탭(tab)만큼 간격을 띄울 때 사용합니다. 기본 8칸

print("1234567890") print("하이\t파이썬")

3. \\ : 역슬래시 

역슬래시 문자 자체를 출력하고 싶을 때 사용합니다.

print("하이\\파이썬")

4. \' 또는 \" : 따옴표

따옴표를 출력할 때 사용합니다.

print('Python\'s favorite subject.') print("\"나는 파이썬을 좋아해\"")

5. 활용 예시

메뉴판처럼 정렬할 때 아주 유용해요!

print("-"*30) print("아메리카노\t2000원") print("카푸치노\t\t5000원") print("라떼\t\t2000원") print("-"*30)

8) 인수 구분자 설정하기

sep와 end옵션을 사용하면 출력물의 사이와 끝을 내 마음대로 조절할 수 있습니다.

1. sep 옵션 

sep(separator)은 인수를 구분하는 문자를 설정합니다. 기본값은 공백 하나('  ')입니다.

print("Hello", "Python") # 기본값은 인수 사이에 공백 추가 print("naver", "com", sep=".") # 인수 사이에 마침표(.)추가 print("010", "1234", "5678", sep="-") print("하이", "파이썬", sep="")

2. end 옵션

end는 출력을 마친 후 끝에 붙일 문자를 설정합니다. 기본값은 줄바꿈 문자('\n')입니다.

print("Hello", end=" ") print("World") print("Python", end="!")
