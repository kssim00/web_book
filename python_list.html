CHAPTER 03. 문자열과 리스트

2. 리스트

💡 학습 포인트
리스트는 여러 개의 데이터를 하나의 이름으로 묶어 관리하는 자료형으로, 대괄호 [ ]를 사용합니다.

1) 리스트 생성

1. 리스트 생성

리스트는 대괄호[ ]를 이용하여 요소들을 묶어 줍니다.

colors = ["red", "blue", "green"] # 리스트 만들기 print(colors)
nums = [ 2, 4, 6, 8 ] # 리스트 만들기 print(nums)

2. 빈 리스트 생성 - 1

빈 리스트를 만든 후, 나중에 데이터를 채울 수 있습니다.

empty_list = [] # 빈 리스트 생성 - 대괄호 이용 print( empty_list )

3. 빈 리스트 생성 - 2

list() 함수를 이용하여 빈 리스트를 만들 수 있습니다.

empty_list = list() # 빈 리스트 생성 - list 함수 이용 print( empty_list )

4. 리스트 생성 

리스트의 초기값과 갯수가 정해진 리스트를 만듭니다.

my_list = [0] * 5 # 요소가 0이고 길이가 5인 리스트 생성 print( my_list )

2) 리스트 변환

1. 문자열을 리스트로 변환하기

list() 함수는 문자열을 하나씩 쪼개어 리스트로 만들어준다.

list1 = list("hello") # 문자열을 리스트로 변환 print(list1)
list1 = list("12345") # 문자열을 리스트로 변환 print(list1)

3) 요소 추가/삭제하기

1. 요소 추가 : append(값)

리스트의 맨 마지막 위치(인덱스)에 값(요소)를 추가합니다. 

a = [1,2,3,4] a.append(5) # 리스트 마지막에 5 추가 a.append(6) # 리스트 마지막에 6 추가 print(a)

2. 요소 추가 : insert(인덱스, 값)

지정한 위치(인덱스)에 값(요소)을 추가합니다.

a = [1,2,3,4] a.insert(2, 0) # 인덱스 2 위치에 0을 추가 print(a)

3. 요소 삭제 : remove(값)

괄호 안에 입력한 값(요소)의 첫번째 요소를 제거합니다.

a = [1, 2, 3, 4, 5] a.remove(2) print(a)

⚠️ 주의 : 삭제할 요소가 없으면 에러 발생

a = [1, 2, 3, 4, 5] a.remove(8) # 에러 발생 : list.remove(x): x not in list

삭제할 요소가 여러 개일 경우 첫번째 요소만 제거합니다.

a = [1, 2, 5, 3, 4, 5] a.remove(5) # 첫번째 요소만 삭제합니다. print(a)

4. 요소 삭제 : pop(인덱스)

지정한 위치(인덱스)의 값(요소)을 제거합니다.

a = [5,6,7,8,9] a.pop(2) print(a)

⚠️ 삭제할 인덱스의 범위가 넘어가면 에러 발생

a = [1, 2, 3, 4, 5] a.pop(5) # 에러 발생 : pop index out of range

4) 인덱싱/슬라이싱

1. 인덱싱

리스트이름[인덱스] : 특정 위치(인덱스)에 있는 값을 추출합니다.

n = [1,2,3,4,5,6] print( n[2] ) # 인덱스 2 위치의 값

리스트의 마지막 인덱스는 -1부터 시작됩니다.

n = [1,2,3,4,5,6] print( n[-2] ) # 인덱스 -2 위치의 값

⚠️ 인덱스의 범위를 벗어나면 에러 발생

n = [1,2,3,4,5,6] print( n[6] ) # 에러 발생 list index out of range

2. 슬라이싱

리스트이름[ 시작인덱스 : 끝인덱스 : 간격 ] : 특정 범위에 있는 값을 추출합니다.

n = [1,2,3,4,5,6] print( n[2:4] ) print( n[-4:-2] ) print( n[1:5:2] )

5) 리스트 함수

1. 요소 바꾸기

지정한 위치(index)의 요소 값을 바꿉니다.

n = list("python class") n[6] = "-" print(n)
n = list("python class") n[0], n[7] = "P", "C" print(n)

2. 요소의 위치 찾기 : index

요소의 첫번째 위치(인덱스)를 반환합니다. 

n = list('python class') print(n.index("p")) print(n.index("s"))

⚠️ 요소가 없으면 에러 발생

n = list('python class') print(n.index("k")) # 에러 발생 'k' is not in list

요소가 리스트에 있는지 확인하고 사용해야 합니다.

n = list('python class') if "k" in n: # 요소가 리스트에 있는지 확인 print(n.index("k")) else: print("k는 없습니다.")

3. 요소 삭제 : del

지정한 위치에(인덱스)에 있는 요소를 삭제합니다.

n = list("python class") del n[6] # 인덱스 6 위치 값을 삭제 print(n)

지정한 인덱스 범위의 요소들을 삭제합니다.

n = list("python class") del n[1:10] # 인덱스 위치 1~9까지 삭제 print(n)

4. 요소 삭제 : remove

요소를 삭제합니다.

n = list("python class") n.remove("s") print(n)

5. 요소 삭제 : pop

지정한 인덱스를 삭제합니다.

n = list("python class") n.pop(0) print(n)

6. 요소 추가 : append

마지막에 요소를 추가합니다.

n = list("python class") n.append("!!!") print(n)

7. 요소 추가 : insert

지정한 위치에(인덱스)에 요소를 추가합니다.

n = list("python class") n.insert(6, "-") print(n)

8. 리스트 갯수 : len(리스트이름)

리스트의 갯수를 구합니다.

n = list("python class") print( len(n) )

9. 요소의 갯수 : count

특정 요소의 개수를 구합니다.

n = list("python class") print( n.count("s") ) print( n.count("z") )

8) 숫자 리스트 정렬

리스트를 역순으로 뒤집거나 오름차순/내림차순으로 정렬해주는 함수가 있다

1. 역순으로 뒤집기 : reverse()

요소들의 순서만 역순으로 뒤집어줍니다. 정렬이 아님!!

n = [1,0,3,2,5,8,7,11,9] n.reverse() print(n)
n = [1,0,3,2,5,8,7,11,9] print(n[::-1]) # 슬라이싱으로 뒤집기

2. 리스트 정렬 : sort()

요소의 크기에 따라 오름차순 또는 내림차순으로 정렬한다.

n = [1,0,3,2,5,8,7,11,9] n.sort() # 정렬하기(오름차순) print(n)
n = [1,0,3,2,5,8,7,11,9] n.sort(reverse=True) # 정렬하기(내림차순) print(n)

3. 정렬 : sorted(리스트이름)

내장 함수로 리스트를 오름차순 또는 내림차순으로 정렬합니다. 정렬된 결과를 꼭 다시 저장해야 합니다.

n = [1,0,3,2,5,8,7,11,9] sorted(n) print(n) # 정렬된 결과 저장하지 않으면 정렬되지 않습니다!!
n = [1,0,3,2,5,8,7,11,9] n = sorted(n) # 정렬된 결과를 n에 다시 저장해야합니다. print(n)

원본 리스트를 유지하려면 sorted() 함수를 사용해야 하며, 새로운 리스트에 저장합니다.

n = [1,0,3,2,5,8,7,11,9] n1 = sorted(n) # 정렬된 결과를 새로운 리스트 n1에 저장합니다. print(n, n1) # n은 원본 리스트, n1은 정렬된 리스트
n = [1,0,3,2,5,8,7,11,9] n = sorted(n, reverse=True) # 내림차순 정렬 print(n)

9) split()과 map()

1. split()

문자열을 특정 문자를 기준으로 나누어 리스트로 만들어주는 함수이다.

data = "apple banana orange" result = data.split() # 공백을 기준으로 나누기 print(result)

split(구분자)처럼 구분자를 입력하면 문자열을 구분자를 기준으로 나누어 줍니다.

data = "10,20,30,40" result = data.split(",") # 쉼표(,)를 기준으로 나누기 print(result)

input()으로 입력 받은 문자열을 구분할 때 자주 사용합니다.

name = input("이름 3개 입력 : ") # 하준 민준 서진 result = name.split() # 공백을 기준으로 나누기 print(result)

2.  map()

리스트의 모든 요소를 한 번에 변환해 주는 함수이다.


➡️ map(함수이름, 리스트이름)

리스트의 각 요소의 타입을 문자열에서 정수(int)로 변환해줍니다. 

map으로 변환한 결과

data = ['10', '20', '30', '40'] # 리스트 각 요소는 문자열 result = list(map(int, data)) # 리스트 각 요소를 int로 변환 print(result)

리스트의 각 요소의 타입을 정수에서 실수(float)로 변환해줍니다.

data = [10, 20, 30] result = list(map(float, data)) # 리스트 각 요소를 float로 변환 print(result)

3. split() + map() 함께 사용하기

코딩 문제에서 가장 많이 사용하는 형태입니다.

한 번에 숫자 여러 개를 입력 받으면 리스트의 각 요소의 타입은 문자열이 됩니다.  이 문자열을 정수로 변환할 때 map함수를 사용합니다.

# 숫자 여러 개를 한 번에 입력 받아 리스트로 저장 # 입력: 10 20 30 numbers = input().split() # 리스트 요소의 타입이 문자열이 됩니다. # 결과 : ['10', '20', '30'] print(numbers) # 리스트의 각 요소의 타입을 한 번에 int로 변환합니다. # 이 때 꼭 리스트로 변환해야 합니다!!! numbers = list(map(int, numbers)) # 결과 : [10, 20, 30] print(numbers)

위 코드를 한 줄로 만들 수 있습니다.

# 두 수를 입력 받아 a, b변수에 저장 # 리스트로 변환하지 않습니다. a, b = map(int, input().split()) # 입력: 10 20 print(a+b)

4. 자주하는 실수

split()만 사용하면 리스트의 요소가 문자열입니다. 문자열이 합쳐지는 결과가 나옵니다.

numbers = input().split() # 입력: 10 20 print(numbers[0] + numbers[1]) # 결과 : 1020

map 객체를 list로 변환하지 않으면 인덱싱이 불가능하여 에러가 발생합니다.

numbers = map(int, input().split()) # numbers는 리스트가 아니고 map객체입니다. 따라서 인덱싱이 불가!! # TypeError: 'map' object is not subscriptable print(numbers[0])
