코드로 만드는 도망 게임! (직접 코딩해보기)

이번엔 코드를 그대로 베끼지 않아요. 힌트를 보고 스스로 빈 곳을 채워서 도망 게임을 완성해봐요.

코드를 전부 보면서 배우고 싶다면 → 정답이 모두 있는 버전

빨간 적은 항상 나를 향해 다가와요. 방향키로 도망 다니며 최대한 오래 버텨보세요!
1

오늘의 미션

오늘은 방향키로 도망 다니면서, 나를 쫓아오는 적을 피해 얼마나 오래 버티는지 시간을 재는 도망 게임을 만들어볼 거예요. 이번 학습지는 일부 코드만 주어지고, 나머지는 여러분이 직접 채워야 해요.

1
방향키(↑↓←→)로 나의 거북이(me)를 자유롭게 이동시켜요.
2
빨간 적 거북이(enemy)는 항상 나를 향해 조금씩 다가와요.
3
화면 위쪽엔 버틴 시간이 초 단위로 계속 표시돼요.
4
적과 나의 거리가 너무 가까워지면 "Game Over"가 떠요.
이번 학습지의 규칙 — 챕터 2, 3, 5, 6, 7에는 코드가 일부만 주어져요. "생각해 보기"와 "메서드 힌트"를 참고해서 나머지를 스스로 완성해보세요. 막혀도 괜찮아요, 힌트 단추를 눌러보면 돼요! 💪
🆕 오늘 처음 만나는 함수
setheading(), towards(), distance(), ontimer(), time.time() — 이 다섯 개는 오늘 처음 배우는 함수예요.
각 챕터에서 "어떤 일을 하는 함수인지" 먼저 그림처럼 쉽게 설명해줄게요.
코드보다 먼저 개념부터 천천히 읽어보세요!
2

화면과 거북이 만들기

🎯 미션 · 직접 코딩

목표: 검은 배경의 게임 창을 만들고, 나의 거북이(me)는 흰색으로 (100, -200)에, 적 거북이(enemy)는 빨간색으로 (-100, 200)에 놓습니다.

import turtle import time # 1. 윈도우(배경 창) 설정 screen = turtle.Screen() # 여기에 코드를 작성하세요 (제목은 "Turtle Game!!", 화면 크기는 500×500, 배경색은 "black") screen.tracer(0) # 화면 자동 갱신 끄기 (나중에 update()로 직접 그려요) # 2. 나의 터틀(me) 만들기 me = turtle.Turtle() # 여기에 코드를 작성하세요 (모양은 "turtle", 색은 "white", 펜은 들고, (100, -200)으로 이동) me.speed(0) # 3. 적 터틀(enemy) 만들기 enemy = turtle.Turtle() # 여기에 코드를 작성하세요 (모양은 "turtle", 색은 "red", 펜은 들고, (-100, 200)으로 이동) # 지금까지 만든 화면을 한 번 그려서 확인해보기 screen.update() turtle.mainloop()
생각해 보기
  • 창 제목, 창 크기, 배경색을 정하는 명령 세 가지가 필요해요. 자동 갱신을 끄는 tracer(0)은 이미 코드에 준비되어 있어요.
  • me와 enemy 둘 다 먼저 모양(turtle)을 정해야 화면에 거북이 아이콘이 보여요. 그다음 자리를 옮길 때 선이 그려지지 않도록 펜을 들어요.
  • me와 enemy 둘 다 모양 정하기 → 색 정하기 → 펜 들기 → 이동하는 순서는 같아요. 모양은 둘 다 같고, 색과 좌표만 다르게 넣으면 돼요.
  • 맨 아래 screen.update()와 turtle.mainloop()는 이미 준비되어 있어요. 코드를 완성하면 바로 실행해서 화면에 거북이가 잘 나오는지 확인해보세요.
💡 메서드 힌트 보기
  • 창 제목 정하기→title("글자")
  • 창 크기 정하기→setup(너비, 높이)
  • 배경색 정하기→bgcolor("색이름")
  • 모양 정하기→shape("turtle")
  • 펜 들기→up()
  • 색 바꾸기→color("색이름")
  • 이동하기→goto(x, y)

기억하기 · screen.tracer(0)은 화면 자동 갱신을 꺼서, 나중에 screen.update()를 직접 부를 때만 화면이 새로 그려지게 해요. 코드 맨 아래 있는 screen.update()와 turtle.mainloop()는 이미 준비되어 있으니, 완성하면 바로 실행해서 결과를 눈으로 확인해보세요.

점수판(타이머) 거북이 만들기

🎯 미션 · 직접 코딩

목표: 글씨만 쓰는 거북이 pen을 만들어서, 화면에는 보이지 않고 흰 글씨만 쓸 수 있게 준비합니다.

# 4. 점수 및 타이머 표시용 거북이 pen = turtle.Turtle() # 여기에 코드를 작성하세요 (거북이 숨기기, 펜 들기, 색은 "white", (0, 210)으로 이동)
생각해 보기
  • 이 거북이는 움직이는 모습을 보여줄 필요가 없어요. 아이콘을 숨기는 명령이 필요해요.
  • 나머지는 앞에서 했던 것과 똑같아요: 펜 들기 → 색 정하기 → 이동하기.
💡 메서드 힌트 보기
  • 거북이 숨기기→ht()
  • 펜 들기→up()

ht()가 하는 일 · hideturtle()의 줄임말로, 거북이 아이콘을 화면에서 숨겨요. 글씨만 쓰는 용도라 아이콘은 필요 없어요.

4

방향키로 나의 거북이 움직이기

🎯 미션 · 직접 코딩

목표: 방향키 4개(위/아래/오른쪽/왼쪽)에 각각 함수를 하나씩 연결해서, 누른 방향으로 거북이가 10만큼 이동하도록 만듭니다.

🆕 새로 배우는 함수 · setheading(각도)
거북이의 머리 방향을 그 각도로 딱 고정시켜요.
0은 오른쪽, 90은 위, 180은 왼쪽, 270은 아래예요.
대포 게임의 left()·right()처럼 "조금씩 도는" 것이 아니라, 방향을 한 번에 딱 정하는 방식이에요.

아래처럼 go_up()은 이미 완성해 뒀어요. 이 코드를 참고해서 go_down(), go_right(), go_left()도 같은 방식으로 만들고, 각 방향키에 연결해보세요.

def go_up(): me.setheading(90) # 위쪽(90도)을 바라보고 me.forward(10) # 10만큼 이동 # 여기에 go_down(), go_right(), go_left() 함수를 go_up()처럼 만드세요 # (아래=270도, 오른쪽=0도, 왼쪽=180도) # 키보드 이벤트 연결 screen.onkeypress(go_up, "Up") # 여기에 go_down, go_right, go_left도 각각의 방향키와 연결하세요 screen.listen() # 키보드 입력을 받기 시작해요
생각해 보기
  • go_up()과 똑같은 모양으로, 각도만 바꿔서 go_down(270도), go_right(0도), go_left(180도)를 만들어요.
  • 함수 4개를 다 만들었다면, 각 방향키와 연결하는 onkeypress() 줄도 4개가 필요해요.
  • 맨 마지막의 screen.listen()은 딱 한 번만 있으면 돼요.
💡 메서드 힌트 보기
  • 방향 딱 정하기→setheading(각도)
  • 앞으로 이동→forward(10)
  • 키와 함수 연결→onkeypress(함수이름, "Down")

팁 · 방향 키 이름은 "Up", "Down", "Right", "Left"예요. onkeypress()에 함수 이름을 넣을 때는 괄호를 붙이지 않아요. onkeypress(go_down, "Down")처럼요.

5

적이 나를 쫓아오게 만들기

🎯 미션 · 직접 코딩

목표: 적 거북이가 나의 위치를 겨냥해서 한 걸음 다가오도록 만듭니다. 이제부터 만드는 코드는 play()라는 함수 안에 쌓아갈 거예요.

🆕 새로 배우는 함수 · towards(좌표)
"지금 위치에서 그 좌표를 바라보려면 몇 도를 향해야 하는지"를 계산해서 각도로 알려주는 함수예요.
enemy.towards(me.pos())라고 쓰면, "적이 지금 자리에서 나를 바라보려면 몇 도로 돌아야 하는지"를 구해줘요.
이 각도로 setheading()한 다음 forward()로 한 걸음 다가가면, 적이 나를 따라오는 것처럼 보여요.
🆕 새로 배우는 개념 · playing, global, play() 함수
지금부터 코드는 전부 play()라는 함수 안에 모아둘 거예요. 게임이 "한 번 똑딱"할 때 해야 할 일들을 이 함수 안에 계속 쌓아가요.
playing은 "게임이 진행 중인지"를 저장하는 변수예요. 처음엔 True(진행 중)로 시작해요.
함수 안에서 playing 값을 바꾸려면 미리 global playing이라고 알려줘야 해요. 6단계에서 이 값을 False로 바꾸게 될 거예요.
screen.update()는 지금까지 움직인 거북이를 화면에 실제로 그려주는 명령이에요. tracer(0)으로 자동 갱신을 껐기 때문에, 이 명령이 없으면 거북이가 움직여도 화면엔 안 보여요.
이 다섯 가지(def play():, global playing, screen.update(), play() 호출, turtle.mainloop())는 오늘 처음 보는 구조라서 코드에 이미 다 채워져 있어요. 여러분이 채울 곳은 딱 3줄이에요.
playing = True def play(): global playing # 적 터틀이 나(me)의 위치(pos)를 향한 각도를 계산 # 여기에 코드를 작성하세요 (me가 있는 방향의 각도를 구해서, 그 방향으로 7만큼 이동) screen.update() # 게임 시작 (아직은 한 번만 실행돼요, 계속 반복시키는 건 7단계에서 배워요) play() turtle.mainloop()
생각해 보기
  • def play():, global playing, screen.update(), 맨 아래 play() 호출과 turtle.mainloop()는 이미 다 준비되어 있어요. 이 구조는 손대지 말고, 함수 안의 빈 곳 3줄만 채우면 돼요.
  • 먼저 "enemy가 me를 바라보려면 몇 도로 돌아야 하는지"를 towards()로 구해서 변수(ang)에 저장해요.
  • 그다음 enemy의 방향을 그 각도로 딱 맞추고(setheading), 7만큼 앞으로 이동시켜요(forward).
  • 완성하고 실행하면 적 거북이가 나를 향해 한 걸음 다가오는 게 보여요. 쉬지 않고 계속 쫓아오게 만드는 건 7단계에서 배워요!
💡 메서드 힌트 보기
  • 상대 방향 각도 구하기→towards(다른거북이.pos())
  • 방향 딱 정하기→setheading(각도)
  • 앞으로 이동→forward(7)

towards()가 하는 일 · enemy.towards(me.pos())는 "지금 enemy 자리에서 me를 바라보려면 몇 도가 필요한지"를 계산해줘요. 나중에 이 코드가 반복 실행되면(7단계), 적은 매번 나의 새 위치를 다시 겨냥하게 돼요.

6

충돌을 확인하고 게임 오버 처리하기

🎯 미션 · 직접 코딩

목표: 적과 나 사이 거리가 20보다 가까워지면, 게임을 멈추고 "Game Over"를 화면 가운데에 보여줍니다. 5단계에서 만든 play() 함수 안에 이어서 코드를 씁니다.

🆕 새로 배우는 함수 · distance(거북이)
두 거북이 사이의 거리를 숫자로 계산해주는 함수예요.
me.distance(enemy)라고 쓰면 "나와 적 사이의 실제 거리"가 나와요.
이 숫자가 작을수록 두 거북이가 가깝다는 뜻이에요.
if 조건:은 조건이 맞을 때만 아래 들여쓰기된 코드를 실행하는 명령이에요 — 여기서는 "적과의 거리가 20보다 가까우면"이 조건이에요.
playing = True def play(): global playing # (아래 적 추적 코드는 5단계에서 이미 완성했어요) ang = enemy.towards(me.pos()) enemy.setheading(ang) enemy.forward(7) # 거리(distance)가 20보다 작으면 충돌! if me.distance(enemy) < 20: # 여기에 코드를 작성하세요 # (playing을 False로, 내 색을 "blue"로, pen을 (0,0)으로 옮기고 "Game Over" 쓰기) screen.update() # 게임 시작 (아직은 한 번만 실행돼요, 계속 반복시키는 건 7단계에서 배워요) play() turtle.mainloop()
생각해 보기
  • 위쪽 적 추적 코드와 맨 아래 screen.update() / play() 호출 / turtle.mainloop()는 5단계에서 만든 그대로예요. if me.distance(enemy) < 20: 아래 들여쓰기된 4줄만 새로 채우면 돼요.
  • 충돌했으니 게임 반복을 멈춰야 해요 → playing 변수를 False로 바꿔요.
  • 내 거북이 색을 "blue"로 바꿔서 "잡혔다"는 걸 보여줘요.
  • pen을 화면 가운데 (0, 0)으로 옮긴 다음, "Game Over"를 크게 써요.
  • 숫자 20을 다른 숫자로 바꿔보면 충돌 범위가 어떻게 달라지는지도 실험해보세요.
💡 메서드 힌트 보기
  • 색 바꾸기→color("색이름")
  • 이동하기→goto(x, y)
  • 글씨 쓰기→write("글자", align="center", font=("Arial", 30, "bold"))

distance()가 하는 일 · me.distance(enemy)는 나와 적 사이의 실제 거리를 계산해요. 20보다 작다는 건 두 거북이가 거의 맞닿았다는 뜻이에요.

7

반복해서 실행되게 만들기

🎯 미션 · 직접 코딩

목표: 지금까지 만든 부분을 play() 함수 하나로 모으고, 타이머를 계산해서 점수판에 표시한 다음, 이 함수가 스스로 계속 반복되게 만듭니다.

🆕 새로 배우는 함수 · time.time(), ontimer()
time.time()은 지금까지 흐른 시간을 초 단위 숫자로 알려줘요.
게임이 시작된 시간을 미리 저장해두고, 지금 시간에서 그 값을 빼면 "지난 시간(버틴 시간)"을 구할 수 있어요.
screen.ontimer(함수, 100)은 "100밀리초(0.1초) 뒤에 그 함수를 딱 한 번 실행해줘"라는 명령이에요.
play() 함수 맨 끝에서 이 명령으로 자기 자신을 다시 호출하기 때문에, 게임이 끝나지 않는 한 0.1초마다 계속 반복 실행돼요.
🆕 새로 배우는 방법 · 경과 시간 계산하고 글씨 만들기
경과 시간(초) = 지금 시간 − 시작 시간이에요. 코드로는 time.time() - start_time이라고 써요.
이 값은 3.7823...처럼 소수점이 있는 숫자라서, int()로 한 번 감싸서 정수(3)로 바꿔줘요 → int(time.time() - start_time)
write()는 문자열(글자)만 이어붙일 수 있어요. 그런데 경과 시간은 숫자(정수)라서 +로 문자열에 바로 합칠 수 없어요 — 먼저 str()로 문자열로 바꿔야 해요.
그래서 완성된 글씨는 "버틴 시간 :" + str(경과시간) + "초" 처럼, 문자열 3개를 +로 이어붙이는 모양이 돼요. 예를 들어 경과시간이 7이면 "버틴 시간 :7초"가 완성돼요.
playing = True start_time = time.time() # 게임 시작 시간 저장 def play(): global playing # 여기에 코드를 작성하세요 # (경과 시간을 계산하고, pen을 지운 다음 "버틴 시간 :N초" 쓰기) # (아래 적 추적 코드는 5단계에서 이미 완성했어요) ang = enemy.towards(me.pos()) enemy.setheading(ang) enemy.forward(7) # (아래 충돌 확인 코드는 6단계에서 이미 완성했어요) if me.distance(enemy) < 20: playing = False me.color("blue") pen.goto(0, 0) pen.write("Game Over", align="center", font=("Arial", 30, "bold")) screen.update() if playing: # 여기에 코드를 작성하세요 (0.1초 뒤 play를 다시 실행) # 게임 시작 play() turtle.mainloop()
생각해 보기
  • 1단계 (경과 시간 구하기) · time.time() - start_time으로 "지금까지 흐른 시간"을 구하고, int()로 감싸서 정수로 바꿔요. 이 결과를 변수(elapsed_time)에 저장해두면 다음 줄에서 쓰기 편해요.
  • 2단계 (글씨 지우기) · pen.clear()로 이전에 썼던 글씨를 먼저 지워요. 지우지 않으면 숫자들이 겹쳐서 보여요.
  • 3단계 (글씨 만들어 쓰기) · elapsed_time은 숫자라서 str()로 문자열로 바꾼 다음, "버틴 시간 :" + str(elapsed_time) + "초"처럼 +로 이어붙여 pen.write()에 넣어요.
  • 맨 아래 if playing: 안에는, 0.1초 뒤에 play 함수 자기 자신을 다시 실행하는 명령 한 줄이 필요해요. 이게 바로 게임이 멈추지 않고 반복되는 이유예요.
💡 메서드 힌트 보기
  • 지금 시간→time.time()
  • 정수로 바꾸기→int(값)
  • 숫자를 문자열로 바꾸기→str(값)
  • 문자열 이어붙이기→"글자1" + "글자2"
  • 글씨 지우기→clear()
  • 글씨 쓰기→write("글자", align="center", font=("Arial", 15, "bold"))
  • 잠시 뒤 다시 실행→screen.ontimer(함수이름, 100)

정리하면 · elapsed_time = int(time.time() - start_time) 한 줄, pen.clear() 한 줄, pen.write("버틴 시간 :" + str(elapsed_time) + "초", align="center", font=("Arial", 15, "bold")) 한 줄. 총 3줄이면 완성이에요.

global playing이 필요한 이유 · playing은 함수 바깥에서 만든 변수예요. 함수 안에서 이 값을 바꾸려면 global로 미리 알려줘야 해요. 이미 global playing이 맨 위에 있어서, 아래에서 playing = False가 잘 동작하는 거예요.
