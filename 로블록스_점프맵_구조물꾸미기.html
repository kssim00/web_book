흔들다리부터 도구상자 꾸미기까지
타워를 더 다채롭게

지금까지 만든 타워형 점프맵에 밧줄(Rope) 제약으로 흔들리는 구조물을 추가하고, 도구상자의 완성품 모델로 리더보드・컨베이어 같은 기능을 손쉽게 꾸며봐요.

지난 시간에 만든 타워 안에 이어서 만들어도 되고, 새 장소에 연습해봐도 좋아요.

STEP 1

밧줄(Rope)로 흔들리는 구조물 만들기

파트 2개를 밧줄(Rope) 제약으로 연결하면, 한쪽은 고정되고 다른 쪽은 중력에 따라 흔들리는 구조물을 만들 수 있어요.

1파트를 2개 만들고, 하나는 위쪽・하나는 아래쪽에 대충 배치합니다
2위쪽 파트는 Anchored를 체크, 아래쪽 파트는 Anchored를 해제합니다
3파트를 선택한 상태에서 제약 목록을 열고 밧줄(Rope)을 선택합니다

모델 탭 → 제약 그룹에서 밧줄을 만들면, 두 파트가 이렇게 연결돼요

파트를 선택하고 제약 목록에서 밧줄을 선택해요

4위쪽 파트를 먼저 클릭해서 매달고, 이어서 아래쪽 파트를 클릭해서 원하는 곳에 연결합니다

먼저 위쪽 파트를 클릭해서 매달아요 (여기 생기는 Attachment0은 그대로 둬도 돼요)

아래쪽 파트를 원하는 곳에 클릭해서 연결해요 — 여기 생기는 Attachment1의 Position에서 X, Z 값을 0으로 맞추면 평평하게 매달려요

5재생(▶)을 눌러 아래쪽 파트가 흔들리는지 확인합니다 — 위쪽 파트와 아래쪽 파트가 밧줄로 이렇게 연결돼요

Attachment를 중앙(0,0)으로 맞추면 평소엔 평평하게 있다가, 캐릭터가 올라갔을 때만 자연스럽게 움직여요

💡 참고하세요

  • Anchored를 제대로 껐는데도 가만히 매달려만 있다면 정상이에요! 밧줄이 팽팽한 상태로 중력과 딱 균형을 이루면 그 자리에 조용히 멈춰요 — 실제 그네도 가만히 두면 안 흔들리는 것과 같아요.
  • 흔들리는 모습을 보고 싶다면 캐릭터가 위에 올라가서 옆으로 걸어보거나, 처음 파트를 놓을 때 위쪽 파트 바로 아래가 아니라 살짝 옆으로 어긋나게 배치해보세요. 떨어지면서 자연스럽게 흔들려요.
STEP 2

밧줄 응용하기 — 흔들다리・그네

같은 원리를 여러 번 반복하면 다양한 구조물을 만들 수 있어요. 파트 개수와 밧줄 길이만 바꿔도 느낌이 완전히 달라져요.

발판 여러 개 + 밧줄
→ 흔들다리
넓은 파트 1개 + 밧줄 2개
→ 그네
킬파트 + 밧줄
→ 흔들리는 함정
밧줄을 여러 개 만들고 싶으면, 파트를 선택하고 Ctrl+D로 복제한 뒤 각각 새로 연결해주면 돼요.
STEP 3

도구상자에서 완성품 모델로 꾸미기

도구상자(Toolbox)에는 스크립트가 이미 들어있는 완성품 모델이 많아요. 직접 코딩하지 않아도 가져와서 배치만 하면 바로 작동해요.

  • 1뷰 → 툴박스를 열고 검색창에 원하는 기능을 검색합니다
  • 2마음에 드는 모델을 화면으로 드래그해서 배치합니다
  • 3크기・위치를 조절해서 내 타워에 자연스럽게 어울리게 맞춥니다

검색창에 원하는 기능을 입력하면 이렇게 여러 모델이 검색돼요

conveyor 컨베이어 벨트

teleporter / stage button 스테이지 이동버튼

item / gamepass 아이템・게임패스

⚠ 안전하게 쓰는 법
  • 모델 안의 스크립트는 함부로 열어서 고치지 않기 — 다른 부분이 같이 망가질 수 있어요.
  • 평가(👍/👎)가 좋고 무료인 모델 위주로 골라요.
STEP 4

게시하고 마무리

밧줄 구조물과 꾸미기 아이템까지 넣었다면, 오늘 만든 것도 게시해서 실제로 플레이해봐요.

  • 1파일 → Publish to Roblox As...로 게임을 업데이트합니다
  • 2로블록스 웹사이트에서 플레이 버튼을 눌러 실제로 테스트합니다
밧줄에 매달려서 떨어지거나 흔들릴 때 너무 어렵지 않은지 직접 플레이하면서 확인해보세요.
